## 摘要
多模态目标重识别（ReID）旨在通过整合多种模态的互补信息来检索特定目标。然而，现有的多模态ReID方法未能有效处理背景干扰抑制或实现三模态对齐，而是侧重于成对特征融合。此外，许多当前的聚合方法存在较高的计算复杂度。为解决这些局限性，我们提出了PRISM，一种基于Prompt-S6（PS6）和语义感知知识引导的新型多模态ReID框架。PS6保持了Mamba的线性复杂度和强序列建模能力，同时实现了高效的跨模态交互。利用这些优势，我们设计了两个关键组件：语义驱动令牌剪枝（SDTP）和渐进融合网络（PFN）。SDTP从分割基础模型中解析语义先验，随后利用这些先验进行动态令牌剪枝，以抑制背景噪声并细化特征表示。PFN逐步聚合多模态特征，以实现三模态对齐并充分利用模态互补性。借助所提出的模块，PRISM在复杂场景下生成了更鲁棒的多模态表示。在四个多模态目标ReID基准上的大量实验证明了我们方法的有效性和效率。源代码可在https://github.com/zw-absin/PRISM获取。

## Abstract
Multi-modal object Re-Identification (ReID) aims to retrieve specific objects by integrating complementary information from multiple modalities. However, existing multi-modal ReID methods do not effectively address background interference suppression or achieve tri-modal alignment, instead focusing on pairwise feature fusion. Moreover, many current aggregation approaches suffer from high computational complexity. To address these limitations, we propose PRISM, a novel multi-modal ReID framework built upon Prompt-S6 (PS6) and semantic-aware knowledge guidance. PS6 maintains the linear complexity and strong sequence modeling capability of Mamba while enabling efficient cross-modal interaction. Leveraging these advantages, we design two key components: Semantic-Driven Token Pruning (SDTP) and Progressive Fusion Network (PFN). Parsing semantic priors from the segmentation foundation models, the SDTP then leverages these priors and applies dynamic token pruning to suppress background noise and refine feature representations. The PFN progressively aggregates multi-modal features to achieve tri-modal alignment and fully exploit modality complementarity. With the proposed modules, PRISM generates more robust multi-modal representations under complex scenarios. Extensive experiments on four multi-modal object ReID benchmarks demonstrate the effectiveness and efficiency of our approach. The source code is available at https://github.com/zw-absin/PRISM.

## 一、核心问题与整体含义（研究动机与背景）

多模态目标重识别（Multi-modal Object Re-Identification, ReID）旨在通过整合来自多个传感器（如 RGB、近红外 NIR、热红外 TIR）的互补信息，在跨视角、跨摄像头的场景中检索同一目标。该技术广泛应用于智慧安防、自动驾驶和智慧城市等实际系统。

**研究动机与存在的问题：**

- 传统基于 RGB 的单模态 ReID 方法对环境变化（如低光照、强光、遮挡）高度敏感，在恶劣条件下性能显著退化。
- 现有多模态 ReID 方法存在三个关键不足：
  1. **背景干扰抑制不足**：现有方法直接从原始多光谱输入提取特征，未有效分离前景目标与噪声背景，在真实成像条件下（杂波背景、遮挡）鲁棒性差。
  2. **三模态对齐缺失**：多数方法采用成对特征融合（如 Multi-Head Cross-Attention），由于第三模态被隔离，无法实现 RGB、NIR、TIR 三模态间的全面对齐。
  3. **计算复杂度过高**：基于注意力机制的聚合方法通常具有二次复杂度，部署效率受限。

**核心思路**：作者提出 PRISM 框架，基于新的 Prompt-S6（PS6）算子，结合语义感知知识引导，同时解决背景干扰抑制、三模态对齐和计算效率三大问题。

## 二、方法论：核心思想、关键技术细节与流程

### 1. 整体框架
PRISM 由三个关键组件构成：
- 视觉特征提取器（基于 CLIP 的视觉编码器）
- 语义驱动令牌剪枝模块（SDTP）
- 渐进融合网络（PFN）

### 2. 语义信息提取
- 对行人目标：使用 OpenPifPaf 进行人体骨骼关键点检测并聚合部件级掩码，实现鲁棒的人物分割。
- 对车辆目标：使用 SAM2 结合自适应提示（框/中心先验）生成精确的车辆掩码。
- 掩码生成过程离线完成，与模型训练/推理解耦，不引入运行时开销。

### 3. Prompt-S6（PS6）——核心创新算子

PS6 是在 Mamba 选择性状态空间模型（SSM）基础上的改进，其关键创新在于 ** 解耦提示条件化机制（Decoupled Prompt Conditioning）**：

- 给定主输入序列 x（如 RGB 特征），引入两个辅助提示序列 t 和 t_p（来自其他模态或语义掩码）。
- **输入投影矩阵 B** 仅由门控提示 t 通过线性投影生成：B = Linear_B(t)，控制信息如何写入隐状态。
- **输出投影矩阵 C** 仅由投影提示 t_p 通过线性投影生成：C = Linear_C(t_p)，控制信息如何从隐状态读出。
- 这种设计使外部信号能够独立、非对称地调制 SSM 的状态动力学，实现细粒度的跨模态交互，同时保持线性计算复杂度。

**与现有 SSM 方法的区别**：不同于 MambaPro、S2CrossMamba 等通过早期特征融合（求和或拼接）共同生成 B 和 C 的方式，PS6 显式解耦了 B 和 C 的生成，实现更灵活、独立的模态控制。

### 4. 语义驱动令牌剪枝（SDTP）

SDTP 采用级联两阶段架构，确保令牌剪枝在语义增强的表示上进行：

**阶段一：目标感知特征增强（TAFE）**
- 使用共享的 PS6 模块，将每个模态的特征 F_m 与其对应的语义掩码 M_m 进行细粒度融合，生成语义增强表示。
- 融合后通过残差连接和 FFN 输出，公式为：F_m^i = FFN(LN(F_m) + F_m^M)

**阶段二：尾部丢弃模块（TDM）**
- 包含三个独立评分器 Θ_m（每个模态一个）和跨模态联合（CMU）机制。
- 对各模态令牌进行评分，选择 Top-k 令牌，取三个模态索引的并集 i_patch = i_R ∪ i_N ∪ i_T，保证跨模态一致性。
- 只丢弃最低分的令牌（保留率 0.5），保留更多有价值的信息，避免过度剪枝。

### 5. 渐进融合网络（PFN）

PFN 采用三阶段渐进式融合策略：

**阶段一：模态内建模（IM）**
- 使用 MHSA 和 FFN 组成编码器 E，对每个模态的特征进行独立增强。

**阶段二：模态间交互（IT）**
- 每个模态与其他两个模态分别配对（如 RGB 与 NIR、RGB 与 TIR），通过 PS6 进行交叉交互，输出取平均。

**阶段三：三模态聚合（TA）**
- 共享 PS6 模块，通过两次循环排列（RNT 和 RTN），实现三个模态同时交互，最终取平均获得综合表示。

### 6. 目标函数
- 采用标签平滑交叉熵损失 + 三元组损失的组合。
- 总损失 = 骨干网络输出上的损失 + PFN 最终表示上的损失。

## 七、优点

1. **创新性强的核心算子**：PS6 解耦了 SSM 中 B 和 C 矩阵的生成，实现非对称的跨模态状态控制，区别于现有融合式 SSM 设计，具有理论清晰性和技术新颖性。

2. **问题定位精准**：论文明确指出现有方法在背景干扰、三模态对齐和计算复杂度三个层面的不足，并有针对性地提出解决方案。

3. **语义引导与令牌剪枝的巧妙结合**：SDTP 利用分割模型的语义先验进行令牌级剪枝，不同于简单的注意力权重选择，通过级联设计（TAFE → TDM）确保剪枝在语义增强后的特征上进行，提升鲁棒性。

4. **渐进式融合设计合理**：PFN 的 IM → IT → TA 三阶段设计逐步深入，从单模态特征增强到成对交互再到三模态同时聚合，逻辑清晰且可解释性强。

5. **轻量化与高效率并重**：PS6 仅 0.79M 参数，PRISM 总参数 109.25M，内存消耗最低（1718 MB），同时性能最优。通过实验证明 PS6 的线性复杂度（与注意力的二次复杂度形成对比）。

6. **实验设计全面**：数据集覆盖行人/车辆、不同规模、不同退化条件，对比方法覆盖面广。鲁棒性评估直接面向实际部署痛点。

7. **掩码生成策略的工程实用性**：针对不同目标结构自适应选择掩码生成方法，且仅从 RGB 模态生成掩码，避免复杂度和模态错位风险。

8. **量化分析工具创新**：论文设计了分离度指标（Separation Metric）和重叠面积估计（基于 KDE），用于量化特征分布的判别性，比仅观察峰值差异更全面。

## 八、不足与局限

1. **鲁棒性评估覆盖面有限**：
   - 像素错位和遮挡实验仅在 RGBNT201 行人数据集上开展，未在车辆数据集上进行同等评估。
   - 缺少对更多退化类型（如低光照、夜间、雨雾）的系统评估。

2. **严重遮挡下优势减弱**：
   - 在遮挡比例 0.3 和 0.4 时，IDEA 的 mAP 超过 PRISM（64.8 vs 63.9、49.8 vs 49.7），说明在极端信息丢失下，纯视觉语义引导仍有不足，可能需要文本等其他模态信息补充。

3. **对掩码质量存在一定依赖**：
   - 虽然设计了对掩码瑕疵的鲁棒性，但不同掩码生成方法对结果影响显著（如 RGBNT100 上 OpenPifPaf 仅 82.9% vs SAM2 86.1% mAP），在掩码严重失效时性能可能退化。

4. **训练细节报告不完整**：
   - 未报告训练时长、GPU 数量、总计算量等关键训练效率信息。
   - 不同数据集间的超参数调整策略描述有限。

5. **泛化性验证不足**：
   - 仅使用 CLIP（ViT-B）作为 backbone，未验证在不同 backbone（如 ViT-S、ViT-L、ResNet）上的泛化。
   - 未在更广泛的开放世界 ReID 场景（无约束采集、跨域泛化）中验证。

6. **复杂性与公平性考量**：
   - PRISM 引入预训练分割网络（OpenPifPaf/SAM2）作为外部依赖，与其他不依赖外部语义模型的方法相比，在公平性对比上存在争议空间（虽然推理时无额外开销，但离线掩码生成需要额外资源）。

7. **深度扩展性受限**：
   - PFN 中模块堆叠深度超过 2 层后性能不再提升（甚至下降），表明渐进融合策略的扩展性有上限，深层融合可能存在冗余或优化困难。

8. **缺少失败案例分析**：
   - 论文主要展示了成功案例和整体统计指标，对方法失效的具体场景和原因缺乏深入分析。
