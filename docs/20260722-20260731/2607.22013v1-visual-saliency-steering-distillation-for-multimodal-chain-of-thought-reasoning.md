## 摘要
多模态思维链推理通过逐步推理整合视觉与文本线索。在令牌预算有限的小模型中，模态交互融合往往会抑制微小的跨模态差异。特别是，当不同图像与相同文本配对或不同文本与相同图像配对时，多模态思维链常常难以区分，使得此类输入在融合后几乎无法辨别。本研究提出视觉显著性引导蒸馏（VSSD）。VSSD利用多模态大语言模型的注意力图生成捕获任务敏感特征方向的扰动图像，然后应用奇异值分解提取主要引导向量以指导层间蒸馏。在ScienceQA和M$^3$CoT上的实验表明，VSSD改进了理由生成和答案推断。代码可在https://github.com/BGWH123/VSSD获取。

## Abstract
Multimodal chain-of-thought (CoT) reasoning integrates visual and textual cues through step-by-step inference. In small models with limited token budgets, modality-interaction fusion often suppresses tiny cross-modal differences. In particular, multimodal CoT often struggles when different images pair with identical text or different texts pair with an identical image, making such inputs nearly indistinguishable after fusion. This study proposes Visual Saliency Steering Distillation (VSSD). VSSD leverages the attention maps of multimodal large language models to generate perturbed images that capture task-sensitive feature directions, and then applies singular value decomposition to extract dominant steering vectors to guide inter-layer distillation. Experiments on ScienceQA and M$^3$CoT demonstrate that VSSD improves rationale generation and answer inference. The code is available at https://github.com/BGWH123/VSSD.

## 2. 方法论：视觉显著性转向蒸馏（VSSD）
### 2.1 总体框架
- VSSD 包含两个核心部分：
  1. 基于注意力的扰动图像生成，用于凸显关键视觉线索；
  2. 从原始与扰动图像的特征差异中提取主导转向向量，通过层间蒸馏注入解码器。
- 模型采用两阶段推理：先生成理由，再预测答案。
  - 公式：`r = f(x, v)`，`a = g(x ∘ r, v)`，其中 `x = Q ∘ C ∘ M`（问题、上下文、选项），`v` 为图像。

### 2.2 跨模态融合
- 图像特征 `Hv`（DETR）与文本特征 `Hl`（T5）通过交叉注意力对齐：
  - `Ĥv = softmax((WQ Hl)(WK Hv)^T / √d)(WV Hv)`
- 进一步使用门控融合得到编码器输出：
  - `σ = sigmoid(Wl Hl + Wv Ĥv)`
  - `HEnc = (1 - σ)·Hl + σ·Ĥv`
- 训练采用标准负对数似然损失 `LNLL`。

### 2.3 图像扰动构造（Algorithm 1）
- 利用 MLLM（如 Qwen2.5-VL）提取图像与问题/答案之间的交叉注意力图。
- 将注意力图跨层、跨 token 聚合，reshape 并上采样为 2D 空间图。
- 经归一化、高斯平滑后，通过 top-k 选择和阈值生成二值掩码。
- 将高注意力区域从原图中掩码掉，得到“扰动图像”，仅保留信息量较低的视觉内容，作为反事实样本。

### 2.4 转向向量提取与层间蒸馏
- 从解码器最后 L 层分别提取原始图像和扰动图像对应的隐状态 `{H+_l}` 与 `{H-_l}`。
- 计算每层差分张量 `E_l = H+_l - H-_l`，对 batch 内每个样本做 SVD：
  - `E_l^(b) = U Σ V^T`
- 取 top-1 右奇异向量作为该样本的转向向量 `v_steering^(b)`，代表由反事实视觉信息引起的主导语义变化方向。
- 对原始隐状态做 mean pooling 得到 `z+_l`，然后注入转向向量并做模长归一化：
  - `ẑ_l = z+_l + α·v_steering`
  - `ž_l = ẑ_l · ||z+_l||_2 / (||ẑ_l||_2 + ε)`
- 蒸馏损失：
  - `L_distill = (1/L) Σ ||z+_l - ž_l||_2^2`
- 总训练目标：
  - `L = LNLL + β·L_distill`
