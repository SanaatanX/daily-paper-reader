## 摘要
开放词汇3D场景理解旨在通过从视觉-语言模型迁移语义知识，分割超出预定义类别的3D场景。现有方法通过将语言对齐的2D特征提升到3D，推动了这一任务的发展，但它们通常依赖于上下文无关的语义表示，未充分利用物体关系进行上下文精炼。我们提出了RelGraphOV，一个关系感知框架，利用3D场景图增强开放词汇3D理解。我们的方法通过利用视觉-语言推理推断物体关系并剪枝几何上不合理的连接，从多视图观测中构建关系场景图，无需手动标注关系。为了聚合关系上下文同时避免特征干扰，我们引入了一种自适应门控双流上下文图注意力网络（Adaptive Gated Dual-Stream Contextual GAT），它分离密集几何特征和语义CLIP嵌入，执行边引导的消息传递，并自适应融合互补语义。一种分层对比目标进一步提升了实例级一致性和类别级判别性。在ScanNetV2、ScanNet200、ScanNet++和Replica上的实验展示了强大的性能和泛化能力。项目页面：https://cxavireh.github.io/relgraphov-projectpage。

## Abstract
Open-vocabulary 3D scene understanding aims to segment 3D scenes beyond predefined categories by transferring semantic knowledge from vision-language models. Existing methods have advanced this task by lifting language-aligned 2D features into 3D, yet they often rely on context-independent semantic representations, leaving object relationships underexplored for contextual refinement. We propose RelGraphOV, a relationship-aware framework that uses 3D scene graphs to enhance open-vocabulary 3D understanding. Our method constructs relational scene graphs from multi-view observations by leveraging vision-language reasoning to infer object relationships and prune geometrically implausible connections, without manual relationship annotations. To aggregate relational context while avoiding feature interference, we introduce an Adaptive Gated Dual-Stream Contextual GAT that separates dense geometric features and semantic CLIP embeddings, performs edge-guided message passing, and adaptively fuses complementary semantics. A hierarchical contrastive objective further promotes instance-level consistency and category-level discrimination. Experiments on ScanNetV2, ScanNet200, ScanNet$++$, and Replica demonstrate strong performance and generalization ability. Project Page: https://cxavireh.github.io/relgraphov-projectpage

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的开放词汇3D场景理解方法（如OpenScene、OpenMask3D等）通常将物体视为独立实体，依赖上下文无关的语义表示。这导致在区分易混淆类别时性能受限（例如“curtain”与“shower curtain”仅靠外观难以区分）。
- **研究动机**：物体周围的上下文关系（如同现关系、空间关系）能为语义歧义消解提供关键线索。但将这些关系显式引入3D开放词汇分割面临两大挑战：
  1. 开放词汇场景中物体和关系多样性剧增，大规模关系标注稀缺。
  2. 将不同类型特征（密集几何特征与CLIP语义特征）直接混合在图神经网络中易产生特征干扰，导致语义空间被污染。
- **整体含义**：提出一种关系感知的开放词汇3D场景理解框架**RelGraphOV**，利用自动构建的3D场景图进行上下文推理，从而强化物体语义特征，在多个数据集上取得最优结果。

### 2. 方法论：核心思想与关键技术细节

RelGraphOV由三个主要阶段构成：**场景图构建**、**节点标注生成**和**上下文特征精炼**。

#### 2.1 关系感知场景图构建（无人工标注）

- **节点定义与关键帧提取**：基于MaskClustering获取类别无关的3D物体提案。对每个节点，利用统一评分函数 \(S(I_k, W)\)（综合考虑完整度、投影面积、中心度和清晰度）从RGB-D序列中选取最佳视角关键帧，并剔除地板、墙壁等大型背景节点。
- **特征初始化**：将节点投影到关键帧提取像素对齐的LSeg密集特征 \(f_l\) 和实例级CLIP特征 \(f_c\)。
- **边初始化**：基于空间邻近性（最近邻或包围盒相邻/重叠）形成初步稠密几何边集 \(E_{\text{geom}}\)。
- **VLM边精炼与编码**：对每条候选边，利用视觉语言模型（VLM）结合链式思维（Chain-of-Thought）描述物体间关系。通过视觉提示（Set-of-Mark）引导VLM判断关系类型，无关系则剪枝。有效边使用VLM生成不对称描述（如“人坐在椅子上”），解析主语-动词-宾语三元组，分别用CLIP文本编码后拼接为结构化边特征 \(F_e\)。

#### 2.2 VLM场景图标注引擎

- 为每个节点选取两个互补视角，利用SAM生成2D掩码，再通过Describe Anything模型生成视图特定描述。
- 利用轻量级LLM判定多视图描述的核心类别是否一致：一致则融合属性；冲突则依据视觉内容裁决，最终生成统一的开放词汇文本标签，并用CLIP文本编码为监督信号 \(f_i^{\text{anno}}\)。

#### 2.3 自适应门控双流上下文图注意力网络（Adaptive Gated Dual-Stream Contextual GAT）

为解决特征干扰，网络设计为双流解耦架构：

- **模态特定初始化**：主路径使用坐标编码器 + LSeg特征 ⇒ \(h_{m,i}^{(0)}\)；辅助路径使用坐标编码 + CLIP特征 ⇒ \(h_{a,i}^{(0)}\)。
- **全局上下文注入**：引入虚拟超节点连接所有节点，通过标准GAT得到全局特征 \(G_{\text{global}}\)。仅注入主路径，以交叉注意力（主路径状态为Query，全局特征为Key/Value）增强局部特征的全局感知能力。
- **边特征引导的消息传递**：两个路径独立执行邻居聚合，关键点在于将边特征 \(f_{e_{ij}}\) 拼接到Key中，使注意力权重依据关系语义动态调整，强化相关邻居、抑制无关邻居。
- **自适应门控融合**：通过可学习的门控机制，选择性将辅助路径的高层语义注入主路径：
  \[
  \text{Gate} = \sigma(\text{MLP}([\hat{h}_{m,i}^{(l)} \| \hat{h}_{a,i}^{(l)}])), \quad h_{m,i}^{(l+1)} = \hat{h}_{m,i}^{(l)} + \alpha \cdot \text{Gate} \odot \hat{h}_{a,i}^{(l)}
  \]
  辅助路径自身状态不更新，保持纯净的CLIP先验。

#### 2.4 训练目标

总损失：\(L_{\text{total}} = \lambda_{\text{hie}} L_{\text{hie}} + \lambda_{\text{reg}} L_{\text{reg}} + \lambda_{\text{aux}} L_{\text{aux}}\)。

- **分层对比损失 \(L_{\text{hie}}\)**：增强节点特征与自身标注的对齐，同时利用标注特征间的相似度构建正向掩码，鼓励同类实例特征一致、异类特征分离。并在自身对中加入边缘惩罚。
- **双对齐正则化 \(L_{\text{reg}}\) 和 \(L_{\text{aux}}\)**：统一的设计为 \(L_{\text{align}}(F, f_{\text{init}}, \gamma)\)，平衡适应标注特征与保留原始模态先验（LSeg或CLIP），避免灾难性遗忘。
