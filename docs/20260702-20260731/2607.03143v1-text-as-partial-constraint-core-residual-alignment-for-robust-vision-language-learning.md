## 摘要
视觉-语言对齐驱动了开放词汇识别、检索和大型视觉语言模型（LVLM）的接地，然而自然描述往往规格不足，使得相似性在释义和省略细节下变得脆弱且过度自信。我们旨在学习这样的表示：其匹配在不同描述视图下保持稳定，且其置信度能反映文本对图像的约束强度。我们提出文本作为部分约束（TPC），一种核心-残差对齐框架，将多视图描述视为不完整监督。它蒸馏出一个共识语义核心作为对齐目标，学习一个单视图核心预测器用于标准单查询推理，并明确阻止视觉-语言相似性依赖于正交的未言说残差。不确定性感知对比目标进一步在描述视图不一致时软化对齐，减少弱语言约束下的过度自信更新。在零样本识别和对抗鲁棒性上，TPC在ImageNet上达到81.42/64.05的Top-1干净/鲁棒准确率，在Avg-14迁移套件上达到76.19/52.03，同时在LLaVA-1.5-7B栈下改善了LVLM迁移，取得了85.16的POPE F1和59.57的OKVQA准确率。这些结果说明，将文本建模为部分约束是在不充分指定的语言监督下获得更可靠视觉-语言表示的一条实用且原则性的途径。

## Abstract
Vision-language alignment powers open-vocabulary recognition, retrieval, and LVLM grounding, yet natural captions are often underspecified, making similarity brittle and overly confident under paraphrase and omitted details. We aim to learn representations whose matching is stable across caption views and whose confidence reflects how strongly text constrains an image. We propose Text as Partial Constraint (TPC), a core-residual alignment framework that treats multi-view captions as incomplete supervision. It distills a consensus semantic core as the alignment target, learns a single-view core predictor for standard inference with one query, and explicitly discourages vision-language similarity from depending on the orthogonal unsaid residual. An uncertainty-aware contrastive objective further softens alignment when caption views disagree, reducing overconfident updates under weak language constraints. Across zero-shot recognition and adversarial robustness, TPC achieves 81.42/64.05 Top-1 clean/robust accuracy on ImageNet and 76.19/52.03 on an Avg-14 transfer suite, while improving LVLM transfer with 85.16 POPE F1 and 59.57 OKVQA accuracy under an LLaVA-1.5-7B stack. These results suggest that modeling text as a partial constraint is a practical and principled route to more reliable vision-language representations under underspecified language supervision.

### 论文核心问题与整体含义  
现有视觉-语言对齐方法（如 CLIP 系列）在训练时往往将每条自然语言描述视为完整的语义目标，然而真实场景中的字幕通常是不完整的：同一张图片的不同描述（多视角）共享一个稳定的语义核心，但在细节、视角、遗漏信息上存在分歧。这种“监督不充分”会导致模型对某些表述过度自信，而在面对同义改写或缺失细节时表现脆弱，尤其在检索、对抗鲁棒性和下游 LVLM 任务中引发幻觉与错误排序。  
本工作旨在学习一种更可靠的视觉-语言表示，使得：  
- 匹配得分在不同字幕版本下保持稳定；  
- 置信度能够反映文本对图像约束的强弱（即当语言约束较弱时，相似性不应过于尖锐）。  

### 方法论核心思想与技术细节  
**总体框架：Text as Partial Constraint (TPC) – 核心‑残差对齐**  
将多视角字幕视为“不完整约束”，通过显式分解共识核心与视图专属残差，抑制模型对残差的过度依赖，并引入基于视图分歧的不确定性来校准对比损失的锐度。

1. **多视角共识核心与分歧度量**  
   - 给定同一图像的 \(K\) 个标准化的文本嵌入 \(\mathbf{t}_{i,k}\)，定义共识核心为它们的归一化均值：  
     \[
     \mathbf{c}_i = \text{norm}\left(\sum_{k=1}^K \mathbf{t}_{i,k}\right)
     \]
   - 视图分歧（不确定性）通过每个文本嵌入与核心的余弦平方偏差平均值的补数来度量：  
     \[
     u_i = \frac{1}{K}\sum_{k=1}^K \left(1 - (\mathbf{t}_{i,k}^\top \mathbf{c}_i)^2\right) \in [0,1]
     \]
   - \(u_i\) 越大，表示不同字幕视图之间越分散，语言约束越弱。

2. **单视图核心过滤器 \(\psi_\theta\)**  
   - 为支持推理时仅使用单条查询文本，训练一个轻量线性映射 \(\psi_\theta(\mathbf{t}_{i,k}) = \text{norm}(W_c \mathbf{t}_{i,k} + \mathbf{b}_c)\)，预测出其到共识核心的方向 \(\hat{\mathbf{c}}_{i,k}\)。  
   - 通过均方误差损失 \(\mathcal{L}_{\text{agree}}\) 拉近 \(\hat{\mathbf{c}}_{i,k}\) 与 \(\mathbf{c}_i\)，使该过滤器能在仅给出一条文本时近似出共享语义。

3. **未言说残差与非承诺惩罚**  
   - 将每个文本嵌入在核心方向上的正交分量定义为“未言说残差”：  
     \[
     \mathbf{r}_{i,k} = \mathbf{t}_{i,k} - (\mathbf{t}_{i,k}^\top \hat{\mathbf{c}}_{i,k})\,\hat{\mathbf{c}}_{i,k}
     \]
   - 设计非承诺项 \(\mathcal{L}_{\text{nc}} = \frac{1}{BK}\sum_{i,k}(\mathbf{v}_i^\top \mathbf{r}_{i,k})^2\)，明确抑制图像嵌入与视图专属残余方向的相关性，防止模型对缺失细节过度对齐。

4. **不确定性感知的核心对齐损失**  
   - 使用共识核心 \(\mathbf{c}_i\) 与图像嵌入 \(\mathbf{v}_i\) 进行对称的 InfoNCE 对比学习，但为每个实例引入与视图分歧相关的温度：  
     \[
     \tau_i = \tau_0 (1 + \gamma u_i)
     \]
   - 当 \(u_i\) 较大（约束弱）时，温度升高，softmax 分布更平滑，从而减少过度自信的梯度更新。

5. **整体训练目标**  
   \[
   \mathcal{L} = \mathcal{L}_{\text{core}} + \lambda_{\text{agree}} \mathcal{L}_{\text{agree}} + \lambda_{\text{nc}} \mathcal{L}_{\text{nc}}
   \]
   联合优化图像编码器、文本编码器和核心过滤器。

6. **推理与校准**  
   - 给定查询文本 \(\mathbf{t}\)，输出核心嵌入 \(\hat{\mathbf{c}} = \text{norm}(\psi_\theta(\mathbf{t}))\) 用于相似性排序。  
   - 利用预测的残差能量 \(\hat{u}(y) = 1 - (\mathbf{t}^\top \hat{\mathbf{c}})^2\) 计算校准的温度 \(\tau(y) = \tau_0(1+\gamma\hat{u}(y))\)，将相似度转换为校准后的概率，改善检索或分类的置信度。

**理论支撑**  
- Theorem 5.1 证明：在残差方向上的敏感性越低、核心对齐越高，对字幕视图偏移的鲁棒性越好。  
- Theorem 5.2 给出 PAC 界：多视图共识相当于对噪声文本嵌入的去噪，视图数 \(K\) 越大，估计的核心越接近潜在语义核心，所需样本复杂度满足 \(K = \Omega(\sigma^2\log(n/\delta)/\epsilon^2)\)。

- TPC 通过显式建模文本的不完整约束，在零样本识别和对抗鲁棒性上大幅领先同类方法（ImageNet 干净/鲁棒：81.42/64.05；Avg‑14：76.19/52.03）。

- 理论分析和诊断实验共同表明：对齐到共享语义核心、抑制视图专属残余、根据语言约束强弱校准置信度，是提升视觉‑语言对齐可靠性的原则性方法。

### 优点  
- **问题洞察深刻**：首次将多视角字幕分歧正式化为不完整语言约束，指出“过度对齐未言说细节”是脆弱的根源。

- **实用性高**：训练可利用现有多字幕数据或通过合成视图生成，推理时仅需单条文本，不增加硬件负担。

### 不足与局限  
- **多视图依赖**：训练需要同一图像的多个描述，对于单标注数据集需额外生成合成视图（如 LLM 删除/改写），这可能引入噪声或与真实分布不一致。  
- **对比范围**：虽然比较了多种鲁棒对齐方法，但并未在极大规模（数十亿图文对）的预训练基础上验证 TPC 的可扩展性。

- **超参数**：虽然敏感性显示鲁棒，但 \(\lambda_{\text{nc}}、\gamma\) 等仍需根据数据集调整，可能影响零样本泛化。  
- **LVLM 迁移**：仅测试了 vision encoder 替换，未探索 TPC 与 connector/decoding 端方法的深入组合。
