## 摘要
在本报告中，我们介绍了 Ovis-Embedding，一个基于文本、图像、视频和音频原生集成构建的最先进全模态嵌入系列。Ovis-Embedding 不是组装独立的模态塔，而是使用共享多模态主干在公共表示空间中对不同模态进行编码。具体而言，我们取得了三项关键进展：(1) 原生全模态初始化：我们采用预训练的 Qwen-omni 模型作为嵌入主干，并通过低秩初始化的对比训练对其进行适配；(2) 以数据为中心的全模态训练：我们构建了涵盖文本、图像、视频、音频和交错多模态数据的广泛高质量语料库。为提高数据效率，我们引入同源采样以形成任务一致的批次，并带有信息丰富的批内负例；(3) 面向嵌入的训练与推理优化：我们使用 focal loss 强调困难样本，并使用基于相似度的 Embedding Distillation 从互补专家中迁移细粒度相似度结构。推理时，低秩特征分解可实现具有灵活维度的紧凑嵌入，且性能损失最小。实证评估表明，Ovis-Embedding 系列在 MMEB-v3、MMEB-v2、MVEB、MAEB 和 RTEB 上达到最先进性能，证明其在文本、图像、视频和音频模态上的有效性。这些结果凸显了统一全模态训练在克服模态碎片化和推进面向任意到任意检索的通用嵌入模型方面的潜力。

## Abstract
In this report, we introduce \textbf{Ovis-Embedding}, a state-of-the-art omni-modal embedding family built on native integration of text, image, video, and audio. Instead of assembling separate modality towers, Ovis-Embedding uses a shared multimodal backbone to encode different modalities in a common representation space. Specifically, we make \textbf{three key advances}: (1) \textbf{native omni-modal initialization}: we adopt a pretrained Qwen-omni model as the embedding backbone and adapt it through contrastive training with low-rank initialization; (2) \textbf{data-centric omni-modal training}: we construct a broad, high-quality corpus spanning text, images, video, audio, and interleaved multimodal data. To improve data efficiency, we introduce homogeneous-source sampling to form task-consistent batches with informative in-batch negatives; and (3) \textbf{embedding-specific training and inference optimization}: we use focal loss to emphasize hard examples and similarity-based Embedding Distillation to transfer fine-grained similarity structure from complementary experts. At inference time, low-rank feature decomposition enables compact embeddings with flexible dimensionality and minimal performance loss. Empirical evaluations show that the \textbf{Ovis-Embedding} family achieves state-of-the-art performance on \textbf{MMEB-v3}, \textbf{MMEB-v2}, \textbf{MVEB}, \textbf{MAEB}, and \textbf{RTEB}, demonstrating its effectiveness across text, image, video, and audio modalities. These results highlight the potential of unified omni-modal training to overcome modality fragmentation and advance universal embedding models for any-to-any retrieval.

# Ovis-Embedding 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：稠密嵌入是搜索、RAG、推荐与智能体系统的核心检索层。现代信息库越来越混合文本、图像、视频、音频、视觉文档与界面状态，检索不再局限于少数预定义模态对（如文-图）。
- **核心问题**：作者将这一广义场景定义为 **any-to-any retrieval（任意到任意检索）**——查询本身可能由多模态构成，候选也跨模态，且所有向量必须处于同一可比较、可校准的语义空间中，同时保留模态内的细粒度区分能力。
- **现有方案不足**：
  - 视觉-语言专用嵌入模型（VLM2Vec、Qwen3-VL-Embedding 等）不支持音频；
  - 现有多模态系统（e5-omni、Omni-Embed-Nemotron、LCO-Embedding-Omni、jina-embeddings-v5 等）通常是在已预训练的文-图嵌入器上"加装"音频通路，或将独立音频编码器对齐到既有嵌入空间。这两种做法都把音频适配到一个**未曾见过音频的几何结构**上，限制了跨模态细粒度对齐。
- **整体含义**：论文主张以**原生全模态理解骨干**（而非模态塔拼装）作为通用嵌入基础，验证统一全模态训练能突破"模态碎片化"，为任意到任意检索提供可行路径。

## 2. 方法论

### 2.1 核心思想：原生全模态初始化 + 极简适配

- 基于 **Qwen2.5-Omni-3B**（Thinker-Talker 架构）构建 **Ovis-Embedding-Omni-3B**：丢弃语音生成通路 Talker，保留文本 tokenizer、视觉编码器、音频编码器与共享因果 Transformer（Thinker），并使用 TMRoPE 对齐音视频时间位置。
- 基于 **Qwen3.5-2B / 9B** 构建 **Ovis-Embedding-VL-2B/9B**：Qwen3.5 语言骨干采用混合栈（每 3 层 Gated DeltaNet 线性注意力 + 1 层完整门控注意力），原生支持交错文本/图像/视频。
- **嵌入提取**：移除语言建模输出头，直接取最后一层、最后一个非 padding token 的隐状态作为嵌入，不做额外投影头或模态专属输出头；嵌入维度直接继承骨干（Omni-3B 与 VL-2B 为 2048，VL-9B 为 4096），相似度用 L2 归一化后的余弦相似度。

### 2.2 数据构建（约 5000 万 query-target 对）

- **图像**：分类（ImageNet/CUB-200/SUN397 + 用 Qwen3.5-Plus 标注的网图扩充）、图像 QA（TextVQA/DocVQA/InfoVQA + 长尾合成）、图像检索（新闻图文、文搜图、图搜图）、视觉定位（MS-COCO）、开放世界检索（夸克搜索真实查询）。
- **视频**：collect–filter–organize 流程，用 VLM 对均匀采样帧做语义验证；分类数据强调"验证后的视频-类别对齐"，检索数据强调相关性过滤 + 保守的查询改写（只修正可观察的事实错误）。
- **音频**：识别（环境事件、城市场景、乐器、口语命令）、音频-语言匹配（非语音描述 + 语音转写）、双向检索（音频→文本、文本→音频），负例尽量限制在同任务族内。
- **文本**：按五种任务范式构建——通用检索、指令跟随检索（q = x ⊕ c，负例满足 x 但不满足 c）、推理检索（q →r→ d+，需多跳推理）、多条件检索（基于 MultiConIR，每个负例只违反一个条件）、长上下文检索（|d+| ≫ |q|，相关性局部而表示全局）；并纳入 RTEB 相关领域数据（法律、金融、编程、医疗）与 MTEB 风格数据（分类/聚类/检索/句对分类）。
- **智能体**：工具检索、GUI 检索（目标↔轨迹/状态，状态↔状态，轨迹↔状态）、知识检索（科学文档问题↔证据段落），负例结合 BM25 难负例与随机采样。
- 所有数据统一为 query–positive–negative 三元组，经过去重与多阶段质量过滤，并对评测集做严格去重（文本用归一化匹配，视觉用感知哈希）。

### 2.3 四阶段训练流程

**Stage-1：低秩预训练（LoRA + 批内混合）**

- 所有模态/任务实例在同一全局 batch 内混合，候选跨数据并行 rank 汇聚，负例跨越模态与任务边界。
- 候选集 C 由 batch 内所有正例与显式难负例合并（大小 N(1+K)），用温度 τ 下的余弦相似度计算 InfoNCE。
- **焦点加权对比损失**：用正例概率 πi 作为检索置信度，焦点系数 aᵢ = sg[(1−πᵢ)^γ]，按批内均值归一化后重加权每查询损失，使未解决查询主导更新（γ=0 退化为均匀权重）。
- **嵌入蒸馏损失**：离线预计算教师模型在候选集上的完整 softmax 分布 tᵢ(c)，与学生的 qᵢ(c) 做前向 KL 散度，提供对正负候选的梯度化排序监督，而非 one-hot 目标。
- 最终目标：L = λ_focal·L_focal + λ_dist·L_dist，实验统一取 λ_focal = λ_dist。
- **关键观察**：全参数更新在初期明显劣于低秩更新，原因是初始嵌入空间无序，全参数训练的不稳定梯度会破坏预训练语义结构，LoRA 起到"稳定先验"作用。

**Stage-2：全参数同源微调（Homogeneous-Source Sampling）**

- 仍用 InfoNCE + 批内负例，但**每个 micro-batch 只从同一数据集采样**，候选按哈希去重以防假负例。
- 动机：随机混合 batch 中，批内负例常来自不同模态/任务，模型易学"模态、句长、语言风格"等浅层捷径；同源采样提供任务一致的难负例，强化细粒度判别。
- 附带收益：同源 batch 形状规整，在 MS-SWIFT 等框架中带来显著训练加速；同质性仅在 micro-batch 内强制，优化步仍可平均不同数据集的梯度，减少更新震荡与灾难性遗忘。

**Stage-3：退火嵌入蒸馏（Annealing Embedding Distillation, ED）**

- 教师先在 Stage-2 语料上运行，仅保留教师答对的实例；再用学生评估，把学生失败的样本上采样构成 ED 训练集。
- 用**前向 KL**（而非反向 KL）：因为主 InfoNCE 已把概率集中在正例上，反向 KL 的 mode-seeking 特性与之重复；前向 KL 才能传递教师在整个候选集上的更软排序。
- **自适应逐查询蒸馏权重**：查询难度 dᵢ = (1−πᵢ)^γ ∈ [0,1]，λᵢ = λ_min + (λ_max − λ_min)·sg[dᵢ]。学生越不确定，教师监督越强；越自信则趋近 λ_min。总目标为 L_sNCE + (1/N)Σλᵢℓᵢ^KD，KL 权重按固定 batch 大小取平均而非归一化，使教师总影响力随学生掌握程度下降。

**Stage-4：弹性嵌入推理（Elastic Embedding Inference）**

- 目标：单一编码器支持多种嵌套宽度 D = {128, 256, 512, 1024, 2048}，且不损害全维性能（作者指出把 MRL 直接嵌入多目标训练会降低全维表现，因此选择在 Stage-2 之后外挂轻量适配器）。
- **混合 PCA 变换**：对每个模态候选池做均衡下采样后估计无中心二阶矩，按权重 p 混合（Σ = Σpₘ·E[yyᵀ]），只做**一次**特征分解得到共享正交基 V。V 是正交的，因此 Vᵀv 是等距变换，全宽几何完全不变。作者发现各模态 PCA 子空间只在少数前几个主方向上一致，之后迅速分叉——p 正是在分配"前缀容量"，消融显示均匀权重是稳健默认值。
- **残差适配器**：在旋转空间中用零初始化的线性残差映射 f_d(ṽ) = ṽ + W_d·ṽ，仅在候选语料上无监督训练（查询只在评测时进入），采用 Matryoshka-Adaptor 的全局成对相似度保持损失 L_pair 与 top-k 近邻保持损失 L_topk 之和（目标值 detach，L1 度量）。
- 线性性使适配器可折叠为单个 d×D 矩阵 P_d = [(I+W_d)Vᵀ]_{1:d,:}，服务某一宽度只需一次矩阵乘法。
