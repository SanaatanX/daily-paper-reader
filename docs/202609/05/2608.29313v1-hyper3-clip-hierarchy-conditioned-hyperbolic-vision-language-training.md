## 摘要
类CLIP的视觉-语言模型（VLM）通过对比目标训练可获得强大的全局图像-文本表示，但其欧几里得嵌入和全局池化无法编码部分-整体、父-子等关系结构。双曲VLM通过蕴含目标弥补了这一不足，文本条件变体则借助句子级和短语级查询改善了细粒度对齐。然而，这两类工作仍然彼此分离：双曲VLM使用静态图像与区域特征，而查询条件方法缺乏层次化几何结构。我们提出Hyper3-CLIP，一种层次条件双曲VLM，将全局、局部及全局-局部对比学习与查询条件视觉池化相结合。为训练该模型，我们从文本构建轻量级查询层次，包含完整标题、句子片段、局部部件描述以及抽取短语。每个查询对视觉补丁的池化进行条件化，所得表示支持图像-文本、整体-部分和父-子蕴含损失。查询条件池化仅在训练期间生效。Hyper3-CLIP在COCO和Flickr上提升了R@5与R@10检索性能，在VOC和COCO上改善了多标签分类，同时在层次指标上保持竞争力。我们还对固定提示模式下的零样本提示敏感性进行了审计，并研究了训练中使用的局部GRIT部件预算的影响。代码见 https://github.com/Hyper3Labs/hyper3-clip 。

## Abstract
CLIP-like vision-language models (VLMs) trained with contrastive objectives learn strong global image-text representations, but their Euclidean embeddings and global pooling fail to encode relational structure such as part-whole and parent-child relations. Hyperbolic VLMs address this gap with entailment-based objectives, and text-conditioned variants improve fine-grained alignment through sentence- and phrase-level queries. However, these two lines of work remain separate: hyperbolic VLMs use static image and region features, while query-conditioned methods lack hierarchical geometric structure. We present Hyper3-CLIP, a hierarchy-conditioned hyperbolic VLM that combines global, local, and global-local contrastive learning with query-conditioned visual pooling. To train the model, we construct lightweight query hierarchies from text, comprising full captions, sentence fragments, localized part descriptions, and extracted phrases. Each query conditions the pooling of visual patches, and the resulting representations support image-text, whole-part, and parent-child entailment losses. Query-conditioned pooling is active only during training. Hyper3-CLIP improves R@5 and R@10 retrieval on COCO and Flickr, as well as multi-label classification on VOC and COCO, while remaining competitive on hierarchy metrics. We also audit zero-shot prompt sensitivity under fixed prompt regimes and study the effect of the localized GRIT part budget used during training. Code is available at https://github.com/Hyper3Labs/hyper3-clip.

# Hyper3-CLIP 论文总结

## 1. 核心问题与研究动机

- **问题背景**：现有 CLIP 式视觉-语言模型（VLM）广泛使用欧几里得空间中的单一全局嵌入向量来表示图像和文本。这种设计虽然能实现良好的实例级对齐（如检索），但**缺乏对层级关系（部分-整体、父-子等）的显式建模能力**。例如，一张企鹅图片中包含身体、雪地等组成部分，一段描述中包含句子、短语等多粒度语义，现有方法难以捕捉这些天然存在的从属结构。
- **研究缺口**：此前存在两条并行但未相交的研究路线：
  - **双曲 VLM**（如 MERU、ATMG、HyCoCLIP、UNCHA、PHyCLIP）：利用双曲几何的指数式空间来编码树状/层级结构，但依赖静态的图像与区域特征，缺乏动态的、文本引导的视觉表示；
  - **查询条件方法**（如 β-CLIP）：让文本查询引导视觉池化以实现细粒度对齐，但缺乏层级的几何结构来建模部分-整体关系。
- **核心问题**：能否将这两条思路相融合，使模型既能动态生成多粒度的文本条件视觉表示，又能在双曲几何中显式地建模层级蕴含关系？
- **论文答案**：**Hyper3-CLIP** 通过将查询条件的视觉池化与双曲层级表示学习结合，在检索、多标签分类和层级对齐指标上同时取得改进。

## 2. 方法论

### 2.1 核心思想
以 UNCHA 的“全局 + 局部（grounded box 级）” 双曲训练为基础，借鉴 β-CLIP 的查询条件池化机制，在训练时为每张图片构造**多粒度的文本查询层级**，每个查询生成一个**独立的查询条件视觉节点**，该节点被映射到共享双曲空间并与对应文本节点配对，通过三种蕴含关系进行监督。

### 2.2 查询层级构造（Query Hierarchy Construction）
输入为图片-标题对 `(I, T)` 及配对好的图像框/文本框对 `{(Ibox_j, Tbox_j)}`。对每个样本额外构造查询集 `Q`，查询类型如下：

| 查询类型 | 来源 | 父节点 | 权重 w(q) |
|---|---|---|---|
| 标题根（Caption root） | 完整标题 | 无 | 0.0 |
| 句子（Sentence） | 标题按句号等切分 | 标题根 | 1.0 |
| 文本框（Text box） | 本地化的文本框 | 标题根 | 0.75 |
| 短语（Phrase） | 按逗号、连接词等抽取 | 句子/标题 | 0.5 |

权重编码了可靠性先验：越完整、上下文越丰富的文本单元权重越高。查询构造完全基于规则字符串处理，无学习解析器。实际训练中每个图像最多取 6 个查询。

### 2.3 查询条件视觉池化（Query-Conditioned Visual Pooling）
给定图片 patch 令牌序列 `Z_I ∈ R^{N×d_v}` 和查询 `q` 的文本表示 `h_q ∈ R^{d_t}`，通过交叉注意力生成查询特定的视觉嵌入：
```
e_vq = MHA(Q = W_Q h_q, K = Z_I, V = Z_I)
v_q = e_vq + MLP(LN(e_vq))
```
其中 `W_Q ∈ R^{d_v × d_t}` 是学习的线性投影。视觉节点 `v_q` 再经共享图像投影层与 Lorentz 提升进入双曲空间。**注意**：该池化模块仅在训练时启用；推理时保持标准双塔编码器结构，不增加额外计算。

### 2.4 训练目标
总损失由三部分组成：
```
L = L^con_UNCHA + λ_ent (L^ent_UNCHA + L^ent_query)
```
- **L^con_UNCHA**：继承的 UNCHA 全局、局部、全局-局部对比损失，含不确定性校准；
- **L^ent_UNCHA**：继承的底层蕴含关系（I⪯T、I_box⪯T_box、I⪯I_box、T⪯T_box）；
- **L^ent_query**（新增）：对每个非根查询 `q`（w(q) > 0）施加三种蕴含约束：
  1. **I_q ⪯ T_q**：查询条件的视觉节点蕴含于其查询文本（图像到文本的蕴含）；
  2. **I ⪯ I_q**：完整图像节点比查询条件的视觉节点“更具体”，因为完整图像包含更多上下文（视觉层级）；
  3. **T_π(q) ⪯ T_q**：父查询文本比子查询文本“更具体”，因父级包含额外上下文信息（文本侧层级保持）。

三种蕴含损失均以权重 `w(q)` 加权，并用与 UNCHA 相同的**不确定性校准机制**进行调节。

- **架构**：CLIP 式双塔编码器 —— ViT-B/16 图像编码器 + CLIP-B/32 文本编码器架构，512 维多模态嵌入，Lorentz 投影，两塔均随机初始化。

## 6. 主要结论与发现

1. **查询条件池化与双曲蕴含损失互补**：结合两者可在不牺牲检索性能的前提下显著提升层级敏感的图像-文本对齐（AP 提升 +3.64）；
2. **文本父-子蕴含（T_π(q)⪯T_q）是最有效的单项关系**，单独启用能恢复 73% 的完整增益（+2.65/+3.64）；
3. **正确的层级方向至关重要**：将 I⪯I_q 反转为 I_q⪯I 会完全消除层级收益（AP 从 79.85 降至 76.06），证实了方法设计的必要性而非简单添加约束；
4. **均质池化无法替代文本条件的注意力池化**：替换为均值池化同样消除 AP 增益；
5. **文本父链接被打乱会显著损害性能**（AP 下降 2.63），说明构造的文本层级具有信息价值；
6. **GRIT 每图像限定 5 个局部部件是最优折衷**：保留 99.38% 的部件实例并带来最佳 Avg R@1；
7. **训练时的多词查询可能与推理时简洁的类名提示不匹配**，导致提示敏感性问题凸显。

## 7. 方法/实验设计的优点

- **融合创新**：将此前分离的两条研究路线（双曲 VLM 与查询条件 VLM）有机结合，模块复用成熟组件（β-CLIP 池化、UNCHA 损失），是清晰且合理的设计。
- **推理零开销**：查询条件池化仅在训练中使用，推理仍为标准双塔结构，无额外计算成本，易部署。
- **查询层级构造的轻量化**：基于规则、无学习解析器，避免额外标注/训练成本。
- **消融设计严谨**：不仅逐一消融损失项，还设置了方向反转、父链接打乱、池化替换等对照实验来**验证设计选择的必要性**，论证强度较高。
- **构建了层级 AP 评估协议**：通过构造正/负层级配对来衡量不同于传统检索的层级对齐能力。
- **对已发表基线的诚实标注**：明确指出不同评估协议间数值不可直接混用，并额外做提示审计展示基线也有敏感性问题。

## 8. 不足与局限

- **提示敏感性偏大**：在官方模板下 Food/CUB/Flowers 性能几乎崩溃（3.26），仅在某些提示模式下方能恢复——这一脆弱性对零样本部署是明显阻碍，论文也未提出解决方案，仅作诊断说明；
- **层级指标未有实质改进**：TIE/LCA 未比 UNCHA 更好，方法对纯类别标签语义结构的帮助有限；
- **单消融项在独用时无增益**：I_q⪯T_q 和 I⪯I_q 单独启用均有负面效果（AP 下降），仅在全目标联合训练时有效，这为复现时的超参数调节带来不确定性；
- **架构消融不完全**：仅用 ViT-B/16 出主结果，未在更大骨干（如 ViT-L）上验证可扩展性；
- **训练资源细节缺失**：未报告 GPU 数量/类型/训练时长，影响可复现性与成本比较；
- **评估基准年份注释异常**：引用的部分参考文献（如 PHyCLIP、UNCHA CVPR 2026）为未来年份，推测属预印本/提前发表情形，时间上可能存在审阅风险；
