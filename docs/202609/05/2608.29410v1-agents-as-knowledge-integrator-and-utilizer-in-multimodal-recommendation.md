## 摘要
在线平台日益依赖多模态推荐系统来对产品、媒体及其他Web内容进行排序。现有方法通常将视觉和文本特征注入物品表示，或基于模态级相似性构建同质图，但所产生的信号可能与推荐目标不一致。我们从知识整合的角度研究这一语义鸿沟：多模态内容应在用于构建推荐图或调整排序之前，与用户行为一起被解读。我们提出了AgentMMRec，一种基于智能体的多模态推荐框架，包含两个协同角色。整合者智能体从训练交互和物品内容中推断出行为和模态感知的用户偏好及物品属性，并将其存储在可复用的知识记忆中。利用者智能体利用该记忆来细化模态特定的物品-物品图、构建行为感知的同质图，并在评估时冻结的记忆下对候选列表进行重排序。这一设计不同于直接的LLM特征增强和纯LLM重排序，因为生成的知识首先被转化为图结构和模型表示，然后再用于推荐。在三个Amazon多模态推荐数据集上的实验表明，AgentMMRec在Recall和NDCG上持续优于近期多模态基线，在稀疏性和物品冷启动设置下保持有效，并可将构建的知识迁移到现有骨干模型中。

## Abstract
Online platforms increasingly rely on multimodal recommender systems to rank products, media, and other Web content. Existing methods usually inject visual and textual features into item representations or build homogeneous graphs from modality-level similarity, but the resulting signals can remain misaligned with the recommendation objective. We study this semantic gap from a knowledge-integration perspective: multimodal content should be interpreted together with user behavior before it is used to construct recommendation graphs or adjust rankings.   We propose AgentMMRec, an agent-based multimodal recommendation framework with two coordinated roles. The Integrator Agent infers behavior- and multimodal-aware user preferences and item properties from training interactions and item content, then stores them in a reusable knowledge memory. The Utilizer Agent consumes this memory to refine modality-specific item-item graphs, construct behavior-aware homogeneous graphs, and rerank candidate lists under a frozen evaluation-time memory. This design differs from direct LLM feature augmentation and pure LLM reranking because the generated knowledge is first converted into graph structure and model representations before recommendation. Experiments on three Amazon multimodal recommendation datasets show that AgentMMRec consistently improves Recall and NDCG over recent multimodal baselines, remains effective under sparsity and item cold-start settings, and can transfer its constructed knowledge to existing backbones.

## 1. 核心问题与整体含义（研究动机与背景）

- **语义鸿沟问题**：现有大多数多模态推荐模型将视觉/文本特征直接注入物品表示，或基于模态级相似度构建物品-物品图；但商品图片、描述中的颜色、品牌、风格等信息可能与用户“为何交互”这一推荐目标关联很弱，导致内容相似却不代表行为相关。
- **LLM 使用范式不完整**：已有 LLM 推荐工作主要做三类事情——做数据增强、作为微调骨干、做列表重排序。论文指出：数据增强仍只产生内容侧特征，微调成本高且数据饥饿，纯重排序只修改候选列表末端，尤其图构建通常与可复用的用户/物品记忆脱节。
- **核心观点**：多模态内容应当先与用户行为一起被“解读”，再转换成推荐图结构或表示；LLM 产生的语义知识应该被当作一种“可复用的中间记忆”，而不是直接替换推荐器。论文强调这一设计与“LLM 特征增强”和“纯 LLM 重排序”本质不同。
- **整体含义**：验证了“先通过智能体生成知识，再把知识转化为图结构与模型表示，最后才用于推荐”的可行性，为多模态推荐中融合 LLM 语义提供了一种更结构化的范式。

## 2. 方法论：AgentMMRec

### 2.1 总体流程
- 框架包含三个核心部件：
  - **整合者智能体（Integrator Agent, IAgent）**：从训练交互与多模态内容中提取用户偏好和物品属性并写入记忆。
  - **利用者智能体（Utilizer Agent, UAgent）**：读取记忆后执行三类操作——优化模态特定物品图、构建行为感知同质图、重排序候选列表。
  - **知识记忆（Knowledge Memory, KMemory）**：以键-值形式存储偏好与属性。
- 整个训练/推理协议分为三个阶段：知识提取与图预计算、带知识增强的训练、冻结记忆的验证与测试。

### 2.2 构建行为感知的同质图
- **用户偏好提取（3 组提示模板）**：
  - 对每个用户，从该用户训练交互物品中采样至多 Υ 个物品，让 IAgent 分别提取文本偏好 P_ut、视觉偏好 P_uv 和跨模态偏好 P_um（式 1-3）。
  - 存入 KMemory：`Key:(pref|u), Value:(P_ut|P_uv|P_um)`；再用文本/多模态编码器 tθ 对偏好编码，按余弦相似度取 top-k，构造“行为-多模态感知”用户-用户图 G_bmu（式 5-6）。
- **物品属性提取（对每个物品）**：
  - 从购买物品 i 的用户所购的其他训练物品集合 N_2(i) 中采样，让 IAgent 提取 P_it、P_iv、P_im（式 7-9），存为 `Key:(prop|i)`。
  - 按相同方式构造“行为-多模态感知”物品-物品图 G_bmi（式 11-12）。
- **关键设计**：图中加入“行为上下文”，而非仅靠内容相似度；图在推荐器训练前一次性构建，不增加每轮图构建开销。

### 2.3 利用原始模态图谱的优化与统一
- 为保留原有模态关联，传统基于 e_i_t / e_i_v 计算出 top-k 的模态特定物品图（式 13-14）。
- UAgent 对每个物品 i，同时输入文本邻居、视觉邻居、物品属性以及购买用户偏好，根据提示重选 top-k 邻居，输出统一的物品-物品图 G_rti（式 15）。
- 无效物品 ID 会在存储邻接矩阵前被丢弃。

### 2.4 表示增强与模型优化
- 采用 LightGCN 对用户-物品交互图做 L 层传播（默认 L=3），初始表示拼接为：
  - `e^u_0 = (e_ut | e_uv | tθ(P_ut|P_uv|P_um))`
  - `e^i_0 = (e_it | e_iv | tθ(P_it|P_iv|P_im))`
- 图卷积后，再将用户同质图、物品同质图、统一物品图各加入一层对称归一化的邻域聚合，缓解梯度爆炸/消失（式 19-20）。
- 训练损失使用经典 BPR loss。
- 默认版本不添加额外自监督目标以保效率，但可以和 InfoNCE/DisAlign 等 SSL 目标兼容。

### 2.5 候选重排序与记忆更新
- 对每个用户，先从 backbone 取 top-50 候选列表（大于评估所需的 N=10/20），由 UAgent 根据用户偏好 + 物品属性重排序。
- 训练阶段若重排序反而降低了由训练集可获得的 NDCG 反馈，则 IAgent 基于训练集 ground-truth 更新该用户的 KMemory；随后重新重排序，直到反馈不再变差或达到更新预算 B（默认每 E=10 epoch 尝试一次）。
- 验证和测试阶段记忆完全冻结，任何验证/测试 ground-truth 都不会用于更新记忆、构图或触发重排序，避免数据泄漏。

### 3.4 主要结果与发现

- 在三个数据集上，AgentMMRec 的 Recall@10/20 与 NDCG@10/20 均显著优于全部 17 个 baseline，平均相对提升约 5%–12%（具体数值见论文表 2）。

- 稀疏度分析显示：在训练交互数少于 5 的用户组中，AgentMMRec 相对最强 baseline 的 Recall@20 提升最大，表明通过 LLM 从少数交互中提炼偏好并构造同质图，能有效缓解冷启动问题。
- 效率方面：图构建和知识提取全部在训练前离线完成；在线重排序仅对 top-50 列表调用 UAgent，且记忆在测试阶段冻结，单次推理开销可接受。

## 4. 主要贡献总结

1. **提出新范式**：将 LLM 从“特征工程工具”或“末端重排器”升级为“先整合、再利用”的推荐知识中枢，把多模态内容与用户行为的语义转化为可复用的结构化记忆。
2. **设计双层智能体框架**：IAgent 负责知识抽取与记忆更新，UAgent 负责图优化、表示增强与候选重排序，各司其职、协同工作。
3. **构建行为感知多模态图**：首次将“行为上下文”引入 LLM 驱动的同质图构建，使模态相似度与用户交互意图对齐，而非单纯依赖内容语义。
4. **提出可迁移的知识记忆机制**：KMemory 中的偏好/属性键值对可被不同推荐器读取，实现了跨模型的 LLM 知识迁移，且训练/验证/测试阶段分离，避免信息泄漏。
5. **全面的实验验证**：在三个 Amazon 子集上与 17 个 SOTA 方法对比，覆盖总体性能、消融、迁移、稀疏度和效率，证明方法的有效性与普适性。

## 5. 局限性与未来方向

- **依赖 LLM 质量与成本**：知识提取需要调用 Qwen2.5-VL-7B 等大模型，若使用更大模型，离线构建成本会显著上升；论文未提供详细的 API/GPU 时间成本分析。
- **图构建规模受限**：当前用户/物品同质图、统一物品图均需先采样邻居并生成 top-k 邻接结构，当数据规模扩展到百万级物品时，提示词数量与存储开销可能成为瓶颈。
- **记忆更新策略较保守**：训练阶段仅在用户级 NDCG 反馈变差时更新记忆，更新频率低且依赖早期模型信号，可能无法充分挖掘 LLM 的纠错潜力。
- **跨模态偏好的粒度**：目前偏好提取被简单地分为文本、视觉、跨模态三类标签，未对“何时使用哪种模态”进行显式建模；在模态缺失或不平衡时，提示模板的鲁棒性有待加强。
- **缺少在线增量学习**：记忆一旦在测试阶段冻结，无法适应新产生的用户交互，推荐系统在真实动态环境中的长期表现尚未评估。

## 6. 总体评价

AgentMMRec 是一篇设计精巧、实验扎实的多模态推荐 + LLM 工作。它的核心贡献不在于“用 LLM 再生成一些特征”，而是提出了一套“知识整合 → 图结构优化 → 表示增强 → 候选重排序”的完整闭环，并且通过行为信息引导语义知识落地，有效缓解了内容与行为之间的语义鸿沟。其“智能体 + 可迁移记忆”的架构具有较好的扩展性，也为后续在推荐系统中引入规划、反思等更复杂智能体行为提供了基线。若能在大规模数据效率、记忆动态更新和模态缺失场景上进一步优化，该范式有望成为多模态推荐中融合 LLM 的标准组件之一。
