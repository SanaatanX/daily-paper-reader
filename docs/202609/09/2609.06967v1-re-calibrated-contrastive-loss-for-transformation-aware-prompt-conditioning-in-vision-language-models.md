## 摘要
确保视觉-语言模型在不损害其泛化性能的前提下进行有效的迁移学习至关重要。然而，许多现有方法忽略了数据特征，简单地重新采用预训练期间使用的训练策略。具体而言，它们将同类别样本视为不同实例，并独立于配对的文本提示对图像进行变换，这增加了模型学习的难度。我们通过变换感知的提示条件化和重新校准的对比损失来解决这些局限性。固定的文本描述符识别应用于配对图像的变换，提供变换级别的一致性而不改变类别语义。该设计在变换级别上将图像分支与文本分支对齐，使模型能够在保持泛化能力的同时学习更丰富的表示。此外，我们的损失函数缓解了每个锚点具有多个有效正样本时软目标交叉熵中的正梯度稀释问题。在迁移过程中，我们的方法将同类别样本视为正样本而非不同实例，使模型能够更有效地学习领域特定特征。跨分布偏移、迁移学习和少样本设置的实验表明，与现有方法相比，我们的方法取得了持续改进。我们方法的源代码可在 https://github.com/SoongE/ReCalCon 获取。

## Abstract
Ensuring effective transfer learning for vision-language models without compromising their generalization performance is crucial. However, many existing methods overlook data characteristics and simply reuse the training strategies adopted during pre-training. Specifically, they treat same-class samples as distinct instances and transform images independently of their paired text prompts, which makes model learning more difficult. We address these limitations through transformation-aware prompt conditioning and a re-calibrated contrastive loss. Fixed text descriptors identify the transformations applied to paired images, providing transformation-level consistency without altering class semantics. This design aligns the image and text branches at the transformation level, enabling richer representations while preserving the models' ability to generalize. In addition, our loss function mitigates positive-gradient dilution in soft-target cross-entropy when each anchor has multiple valid positives. During transfer, our approach treats same-class samples as positives rather than distinct instances, enabling the model to learn domain-specific features more effectively. Experiments across distribution shift, transfer learning, and few-shot settings demonstrate consistent improvements over existing approaches. Source code for our method is available at https://github.com/SoongE/ReCalCon.

# 论文总结：Re-calibrated Contrastive Loss for Transformation-Aware Prompt Conditioning in Vision-Language Models

## 1. 论文核心问题与整体含义

- **研究背景**：视觉-语言模型（如 CLIP）具有很强的零样本泛化能力，但在迁移到特定下游任务时，常出现两个问题：
  1. 对目标域过拟合，导致在其他分布上性能下降（ID-OOD 权衡）；
  2. 图像增强与文本提示之间存在不对齐：图像经过随机增强，而文本提示没有描述这些变换，导致图文匹配关系被破坏。
- **核心动机**：现有迁移学习方法大多直接复用预训练阶段的对比学习策略，忽略了数据特征，例如：
  - 将同类别样本当作独立负样本；
  - 对图像进行增强时，文本端不感知变换；
  - 使用软目标交叉熵时，多个正样本会稀释每个正样本的学习信号。
- **整体含义**：本文旨在解决上述问题，提出一种**变换感知的提示条件化**与**重新校准的对比损失**，在保持模型泛化能力的同时，实现更稳健、更有效的 VLM 迁移学习。

## 2. 方法论

### 2.1 核心思想

- 构造一个**扩展的对比空间**，包含：
  - 干净图像-干净文本匹配；
  - 增强图像-变换条件化文本匹配；
  - 干净与增强之间的交叉匹配；
- 利用**变换级一致性**：每个增强图像都配对一个固定的文本描述符（如“RandomResizedCrop”等），使文本分支也能感知图像变换，但不改变类别语义。
- 提出**重新校准的对比损失**，缓解多个正样本导致的“正梯度稀释”（positive-gradient dilution）问题。

### 2.2 关键技术细节

#### (1) 变换感知提示条件化（Transformation-Aware Prompt Conditioning）

- 文本提示构造为：`M = [V, A, CLS]`
  - `V`：可学习的上下文向量（CoOp 风格）；
  - `A`：固定的变换描述符嵌入（来自 RandAug 字典，不可学习）；
  - `CLS`：类别词嵌入。
- 图像增强后，用对应的固定文本描述符（如 RandAug 操作名）作为提示的一部分，使得文本描述与图像变换保持一致。
- 为避免复杂的多图像混合提示歧义，在文本端不进行 prompt 级 MixUp，而是在特征级使用多样本融合（Multi-sample Fusion）。

#### (2) 重新校准的对比损失（Re-calibrated Contrastive Loss）

- 传统 CLIP 损失（InfoNCE）：每个锚点只有一个有效正样本。
- 软目标交叉熵（SoftCE / SupCon 形式）：将同类别样本都当作正样本，每个正样本的权重为 `1/|P(i)|`，正样本数增多时梯度被稀释。
- 本文损失形式：

  \[
  L_{ours} = -\sum_{i=1}^{B} \frac{1}{|P(i)|} \sum_{k \in P(i)} \log(\sigma_I(i,k) \cdot \psi(i))
  \]

  其中：
  \[
  \psi(i) = \frac{\sum_{k \in P(i)} \exp(s_{i,k})}{\sum_{t \in N(i)} \exp(s_{i,t})}
  \]
  - `P(i)` 是正样本集合，`N(i)` 是负样本集合；
  - `ψ(i)` 衡量正样本证据对负样本干扰的相对强度；
  - 损失能分解为“软目标交叉熵”和“自适应边距”两部分；分母仅含负样本，因此 `ψ(i)` 无上界，当正样本主导时边距增强，而非消失。

- 由于 `ψ` 不除以 `|P(i)|`，边距强度不会随正样本数增加而稀释，从而缓解正梯度稀释问题。
- 损失在 CLIP 的 L2 归一化和 logit scale 有界条件下有下界，训练稳定。
- 提供的 PyTorch 伪代码演示了实现只需几行代码。

#### (3) 扩展对比空间

- 将干净与增强图像特征拼接：`[I, I']`，文本侧拼接 `[T, T']`；
- 构成 `2B x 2B` 的相似度矩阵；
- 支持四种匹配：干净-干净、增强-增强、干净-增强、增强-干净。

#### (4) 多样本融合（Multi-sample Fusion）

- 在特征层面进行 MixUp 风格融合：`x̂_m^i = λ x_m^i + (1 - λ) x_m^{B-i+1}`；
- 同时作用于图像和文本特征，避免文本提示级融合的语义歧义；
- 只在训练时使用，推理时无额外开销。
