## 摘要
记忆通过提取和检索事实，使多模态大语言模型（MLLMs）能够在有限上下文窗口内对长视频进行问答。现有解决方案通常从固定长度的视频片段中提取独立的记忆条目，因此无法捕获需要在较长时间段内总结的高层语义，例如角色特征和关系。此外，它们仅依赖基于相似性的检索，可能无法检索到回答问题所需的细粒度细节。为解决这些问题，我们提出了CAM，其特点是对高层语义进行连续提取，并对细粒度细节进行自适应查询。具体而言，CAM将从视频片段中提取的实体和关系存储到知识图谱中。为捕获每个实体或关系的高层语义，当目标实体或关系的局部子图达到预定义大小后，CAM会汇总该局部子图。为检索回答问题所需的细粒度细节，CAM支持多种搜索方法，包括知识图谱遍历、重新观看视频和收听音频。它利用规划器-执行器-验证器流水线，根据问题意图自适应地组合这些搜索方法。在三个基准上的评估表明，CAM超越了最先进的基线，并将其准确率提高了最多23个百分点。代码可在 https://github.com/Jake-Tian/CAM 获取。

## Abstract
Memory facilitates question answering over long videos by extracting and retrieving facts to fit within the limited context windows of multimodal LLMs (MLLMs). Existing solutions typically extract independent memory entries from fixed-length video clips and thus cannot capture high-level semantics that need to be summarized over extended time periods, such as character traits and relations. Moreover, they rely solely on similarity-based retrieval and may fail to retrieve the fine-grained details required for question answering. To tackle these problems, we propose CAM, featuring continuous extraction for high-level semantics and adaptive querying for fine-grained details. In particular, CAM stores the entities and relations extracted from video clips in a knowledge graph. To capture the high-level semantics of each entity or relation, CAM summarizes the local subgraph of the target entity or relation once the subgraph reaches a predefined size. To retrieve the fine-grained details required for question answering, CAM supports multiple search methods, including knowledge graph traversal, video re-watching, and audio listening. It utilizes a planner-executor-verifier pipeline to adaptively compose these search methods according to question intent. Evaluations on three benchmarks show that CAM outperforms SOTA baselines and improves their accuracy by up to 23 percentage points. Code is available at https://github.com/Jake-Tian/CAM.

## 1. 核心问题与研究动机

随着多模态大语言模型（MLLMs）的发展，模型已能在视频理解上展现出较强能力，但由于上下文窗口有限，直接处理长视频仍然非常困难。为缓解这一瓶颈，**视频记忆系统**被提出，通过先从视频中提取事实、在问答阶段只检索相关片段来缩减输入规模。

论文指出，现有视频记忆系统存在两大关键缺陷：

- **无法捕捉高层语义**：现有系统多将视频切为固定长度片段，独立提取低层事件（如"某角色拿起了杯子"），但像角色性格、人物间社会关系、叙事结构等需跨长时段积累、提炼的抽象语义无法从单一片段读出；此外，固定间隔的紧凑记忆难以持续演化，缺乏在跨片段验证下的语义抽象能力。
- **细粒度信息检索不足**：一方面，即使少数系统采用知识图谱组织记忆，检索仍退化为对节点描述的"平面文本相似度匹配"，没有利用图拓扑结构，难以支持关系链引导的多跳推理；另一方面，记忆构建本身是有损的——将原始视频压缩为文本时会丢失大量细节，且"什么细节重要"取决于具体问题，只检索预建记忆无法补救在构建阶段已丢失的关键证据。

针对以上问题，论文提出了 **CAM（Continuous Adaptive Memory）** 框架，以"连续提取 + 自适应查询"的方式，为视频构建支持高层语义涌现和细粒度动态检索的时间锚定、异构关系记忆，从而支撑复杂多跳实体中心视频问答。

## 2. 方法论

### 2.1 记忆构建（Memorization): 时间锚定异构知识图谱

- 将长视频切分为固定长度片段（30秒/clip），每段输入 MLLM，并附带**来自前一帧的外观描述符**（跨片段人物身份连续性追踪）。
- 通过 MLLM 提取互补的流式信息：**行为（Bi）、对话（Si）、外观（Ai）、辅助语境（Ki）**。
- 将行为描述经 LLM 转为结构化关系三元组 `（source, relation, target）`，并引入**会话节点**与**物品节点**一起融入异构图谱 *G*。
- 每个提取的关系都带有**临时时间戳与语境元数据**（时间边、上下文记忆），使图谱具备时间感知能力，支持时间约束检索与因果推理。

### 2.2 高层语义提取：证据驱动抽象（Evidence-Driven Abstraction）

CAM 与固定时间间隔式摘要的关键不同：把抽象视为**依赖子图成熟度触发的异步操作**，避免因时间界预设而导致的过早或延迟总结。

- 为每个字符实体 *v* 维护其累积的关联边集合（自身为源/目标指向它的全部入边出边）。
- 只有当从上次摘要后累积的**新边达到阈值 τ_char** 时，才触发角色级抽象（LLM 将局部行为历史合成角色属性节点，如性格、角色定位等）。
- 为每一对人物 *(u, v)* 维护显式交互 + 隐式共现集合，达到阈值 τ_rel 后产生持久关系边。
- 抽象后直接写回图谱，同时**保留所有原始低层事件证据**，便于后续证据修正/复核。
- 据敏感性实验（附表 4），默认阈值设为 τ_char=50、τ_rel=30。

### 2.3 自适应推理（Adaptive Reasoning）

将推理形式化为"**状态机 + 迭代工具调用**"流水线（LangGraph 实现）。代理状态表示为：

```
S_t = (Q, C_meta, M_t, H_t)
```

其中 Q 为用户问题，C_meta 为全局元数据（视频时间跨度、主要角色、抽取三元组总量、对话列表等），M_t 为随轮次更新的中间记忆（整合已发现证据），H_t 为搜集到的原始证据历史。

核心流程为「**规划器（Planner）→ 执行器（Executor）→ 验证器（Verifier）**」：

- **Planner（LLM）**：分析当前状态，选择要用哪个搜索工具及其参数。
- **Executor**：调用工具访问图谱/原始视频，获得证据返回。
- **Verifier**：判断累积上下文是否足以回答问题（Complete），还是不足（Incomplete）或者陷入循环（Stuck）；若 Stuck 则注入系统提示引导新搜索方向。
- 若超过最大轮次或判定 Complete，最后进入 **Final Answer Node** 输出简明答案。

### 2.4 搜索工具箱（Toolbox）

七个专用工具，核心是一套多通道检索的 **general_search（通用搜索）**：三步走：

1. 查询解析：将问题转为语义三元组 <s, r, t>，分配权重与各检索通道预算；
2. 结构化相似度匹配：同时考虑语义的正反方向（防主语/宾语互换），公式如下：

```
S_struct = max( w_s·sim(s_q,s_c) + w_t·sim(t_q,t_c),
                w_s·sim(s_q,t_c) + w_t·sim(t_q,s_c) )
           + w_r·sim(r_q,r_c)
```

3. 多通道检索：高阶层经结构化相似度，低层事件边加注语境相似度评分，对话按语义直查并扩展前后邻句。

配套工具包括：
- **Temporal Search**：时间窗约束的搜索。

- **Graph Traversal**：锚点实体在语义过滤后邻域内的显式图拓扑跨越，支持多跳演绎路径推理。
- **Search Object**：基于嵌入的实体对齐缓解词汇不匹配（如将"marker"与"pen"对齐）。
- **Frequency Count**：统计事件/对象在时间轴上出现频次。
- **Video Rewatch**：视频重看，是最关键的多模态兜底——当文字记忆不足以回答细微空间/动作问题时，直接回溯原图帧；对保留视觉连续性和解决文本压缩导致的信息丢失至关重要（实验表明：*watch_video_clip* 是最常用的第二工具）。
- **Audio Listening**：音频监听——处理背景声等非语音线索。

## 6. 主要结论

- CAM 通过时间锚定异构知识图谱，加上"证据驱动-自主异步"的高层语义抽象，有效解决了长视频中的"低层事件-高层语义"鸿沟；相比固定间隔/fixed-round 方法在 PU 和 MH（人物理解、多跳关系）类问题中提升最明显。
- 自适应多工具推理（图谱遍历、时间窗查询、对象检索、视频重看、频次统计）显著强于只做相似度匹配的检索——后者是当前证据下系统失败的最主要原因。
- CAM 在图噪声下有一定抗性（0%→10% 噪声时准确率仅小幅下降）；以更小的 Qwen 骨干也能超过最强的基于 GPT 基线之前的最好水平，展现灵活的成本-准确率配置空间。
- 在不同基准上均优于各领域最强模型 11~23 个百分点，而且 token / 推理轮次成本控制在中低档，无需针对数据集格式裁剪。

## 7. 方法优点

1. **时间锚定、持续演进的图记忆设计**：将实体连续与跨片段时间位置关系置于图结构中，天然支持时间搜索、因果推理与关系链的传递性演绎，超越基于独立段落的扁平记忆。
2. **证据驱动的自发抽象设计富有启发性**：不预设时间间隔，而是根据局部图密度/结构成熟度决定何时总结，客观符合"证据稀疏不均分布"的真实视频特征；摘要形成后原始细节仍保留——可供问题驱动时反向定位。
3. **工具箱的"多模态兜底机制"设计**：除非文本图谱明确足以回答，否则允许 Agent 直接重新观看看视频段或收听音频来验证答案——直接缓解压缩丢损的问题，实用价值显著。
4. **Planner-Executor-Verifier 闭环自校正工作流**：Verifier判别 Stuck 并注入系统提示引导，避免循环搜索，也减少盲目反复尝试，兼顾准确率与收敛时代价。
5. **评价严谨**：对 LLM 评判器做了跨模型一致性-人工一致性

- **评价严谨**：对 LLM 评判器做了跨模型一致性-人工一致性验证（GPT-5.2 与 GPT-4o 一致性达 96.7%、与人类 97.7%），并辅以实体关联人工标注对照和误差类型分析，使主观评估环节也具备量化可信度。

6. **支持流式与可扩展部署**：记忆构建以 30 秒为处理单元且每单元平均处理时延低于视频时长，可边摄入边建图，满足在线/流式场景；不同骨干模型（GPT、Qwen）均可驱动，能够在准确率与推理成本之间灵活取舍。

## 8. 方法局限与潜在风险

尽管 CAM 在多个基准上表现突出，但仍存在以下几点局限：

- **记忆压缩仍是不可逆的信息瓶颈**：外观、动作、对话被压缩为文本/图结构后，细节必然受损。CAM 虽以“视频重看”兜底，但该工具依赖规划器主动发现“何时需要回看”，若问题线索不足以触发重看，仍可能遗漏关键证据。
- **提取与抽象依赖闭源大模型 API**：记忆构建、关系抽取、高层抽象、推理规划均调用 GPT/Qwen 等商业模型，成本、时延和输出稳定性受外部 API 影响；论文未披露最终端到端成本，实用部署时需额外评估费用与隐私限制。
- **高层抽象仍由 LLM 完成，缺乏严格可证明性**：角色属性、关系边等高层结论由 LLM 生成，本质是“证据到解释”的归纳，可能出现幻觉；尽管原始事件被保留用于复核，但验证环节并没有显式的“证据链校验”，一旦抽象错误且被后续推理采纳，错误会沿图传播。
- **图谱结构与查询工具偏向实体中心问题**：对于非实体中心（如氛围、叙事节奏、抽象解说）或高度依赖全局蒙太奇的问题，图谱与拓扑搜索的优势不明显；论文也承认该类视频收益有限。
- **可扩展性有待大规模验证**：当前测试视频时长集中在 27–34 分钟，图规模中等。若延伸到数小时乃至更长视频，记忆图的边数与抽象触发频次会迅速膨胀，阈值 τ 是否需要随视频长度自适应、检索延迟与 token 成本如何增长，目前缺乏系统实验。
- **基准域偏向单镜头无剪辑视频**：三个基准多为机器人 / 人格化 Vlog 风格，长镜头或单一叙事流居多；真实电影 / 新闻等快切、多机位长视频的适用性还未充分验证。

## 9. 总结

CAM 是围绕“长视频问答 = 记忆构建 + 动态查询”设计的一套完整系统。其核心创新在于：将视频记忆组织为“时间锚定、持续演化”的异构知识图谱，并以证据密度而非固定时间间隔驱动高层语义的异步抽象；推理侧则以 Planner–Executor–Verifier 状态机统筹多通道图检索与多模态回看，形成一套能够自适应收敛的自校正问答流程。实验表明，CAM 在没有针对基准定制的前提下，以明显优势超越现有流式理解与视频记忆基线；消融也清晰验证了图结构、高层语义模块与工具多样性的各自贡献。不过，其性能仍受限于 LLM 抽取质量、闭源 API 成本以及实体中心基准的代表性，未来可在开放式视频域、更长时序以及抽取可靠性保障上继续扩展。
