## 摘要
对话中的多模态情感分析和情绪识别需要对文本、声学和视觉模态之间的异构交互进行有效建模。尽管大语言模型（LLM）提供了强大的语言理解能力，但将其适应于多模态情感计算仍然具有挑战性：全模型微调在计算上难以承受，而许多现有的轻量级适配器在跨模态融合过程中未能保留丰富的文本线索。为了解决这些局限性，我们提出了多视图文本引导的多模态融合适配器（MVFA），这是一种参数高效的框架，能够为冻结的LLM增强强大的多模态推理能力。MVFA首先通过最大池化、均值池化和注意力池化构建互补的文本视图；然后这些视图引导与音频和视觉特征的跨模态交互。随后，通过增强型Q-Former融合模块将融合后的多模态表示压缩为一组紧凑的可学习伪标记。以ChatGLM3-6B-base作为主要骨干网络，我们进一步在LLaMA2-7B和Qwen3-8B上验证MVFA，以检验其在多个冻结LLM骨干网络上的可移植性。MVFA在三个具有挑战性的数据集上进行了评估：CH-SIMS V2.0、MELD和CHERMA。实验结果表明，MVFA在仅更新一小部分参数的情况下，在关键指标上达到了最先进的性能。具体而言，它在CH-SIMS V2.0上达到了84.62%的Acc2和84.59%的F1，在MELD上达到了67.36%的Acc和66.03%的WF1，在CHERMA上达到了74.66%的Acc。这些发现确立了多视图文本引导融合作为一种在情感计算中参数高效的多模态LLM适应的有效且可扩展的范式。代码可在https://github.com/Overwhelm1208/MVFA公开获取。

## Abstract
Multimodal sentiment analysis and emotion recognition in conversations demand effective modeling of heterogeneous interactions across textual, acoustic, and visual modalities. Although large language models (LLMs) offer powerful language understanding, adapting them to multimodal affective computing remains challenging: full-model fine-tuning is computationally prohibitive, while many existing lightweight adapters fail to preserve rich textual cues during cross-modal fusion. To address these limitations, we propose the multi-view text-guided multimodal fusion adapter (MVFA), a parameter-efficient framework that augments frozen LLMs with strong multimodal reasoning capability. MVFA first constructs complementary text views via max pooling, mean pooling, and attention pooling; these views then guide cross-modal interactions with audio and visual features. The fused multimodal representations are subsequently compressed into a compact set of learnable pseudo-tokens through an Enhanced Q-Former Fusion Module. Using ChatGLM3-6B-base as the primary backbone, we further validate MVFA on LLaMA2-7B and Qwen3-8B to examine its portability across multiple frozen LLM backbones. MVFA is evaluated on three challenging datasets: CH-SIMS V2.0, MELD, and CHERMA. Experimental results demonstrate that MVFA achieves state-of-the-art performance on key metrics while updating only a small fraction of parameters. Specifically, it attains 84.62\% Acc2 and 84.59\% F1 on CH-SIMS V2.0, 67.36\% Acc and 66.03\% WF1 on MELD, and 74.66\% Acc on CHERMA. These findings establish multi-view text-guided fusion as an effective and scalable paradigm for parameter-efficient multimodal LLM adaptation in affective computing. The code is publicly available at https://github.com/Overwhelm1208/MVFA.

- **核心目标**：提出一种**参数高效（Parameter-Efficient）** 适配方法，使冻结的 LLM 具备多模态情感识别能力，同时不丢失文本中的重要语义线索。

## 2. 论文提出的方法论

### 2.1 整体框架思想
MVFA（Multi-View Text-Guided Multimodal Fusion Adapter）是一个轻量级适配模块，采用 **「多视图文本 → 引导跨模态融合 → 压缩为伪标记 → 注入冻结LLM」** 的流水线。

### 2.2 多视图文本建模与融合（MTF模块）

论文针对单一压缩文本视图的缺陷，构造**三种互补文本视图**（对应图中三个分支，融合后引导跨模态对齐）：

- **Max-Pooling文本视图**（捕捉显著局部词汇线索）：
  ```
  Fmax = max(MLP_max(T))
  ```
- **Mean-Pooling文本视图**（概括整体语义倾向）：
  ```
  Fmean = AvgPool(MLP_mean(T))
  ```
- **Attention-Pooling文本视图**（自适应加权各token的贡献，由无参数注意力打分得到）：
  ```
  S = MLP_attn(T)；a = softmax(mean(S)); Fattn = a^T S
  ```
- **渐进融合**：三种视图依次拼接、经 MLP 投影并配合残差连接融合得到 **Ftext**，作为文本全局表征。每路 MLP 使用独立参数。

### 2.3 文本引导的跨模态注意力

音频和视频特征分别经**单向 LSTM** + 线性投影压缩为固定维度全局向量：

```
Audio: Ā = Linear_a(LSTM_a(A)_final)
Visual: V̄ = Linear_v(LSTM_v(V)_final)
```

随后执行两侧独立的跨模态注意力（文本特征作为 Query，音频/视觉作为 Key 和 Value）：
- **文本-音频交叉注意力**：Q为Ftext，K/V为音频全局向量
- **文本-视觉交叉注意力**：Q为Ftext，K/V为视觉全局向量
各自配合残差+LayerNorm；两者输出拼接后经两层 MLP+ReLU 投影回原维度，得到**Fcross**。

### 2.4 增强型Q-Former融合模块（ENQF）

- 将 Fcross 经过**LayerNorm+GELU 线性投影**规范化到潜在空间，得到 Fproj；
- 引入**通道门控增强子网络**（两层FC+GELU+Sigmoid）生成门控向量 g，得到增强特征 Fenh；最终组合 Fcombined = Fproj + α·Fenh（默认 α = 0.3）；
- 一组可学习查询向量 Q（默认 n = 4 个伪标记）经**线性变换后与Fcombined做交叉注意力（MHA）**，最后经残差+投影头输出紧凑伪标记 **P**。
- 用该模块替代传统 Q-Former 中的复杂自注意力堆叠（避免密集参数与计算开销），同时通过门控增强提升关键语义捕捉能力。

### 2.5 LLM推理与损失

- 最终输入序列为：
  ```
  X_input = [P; T; Tp]
  ```
  其中 **P** 为伪标记；**T** 为原始文本嵌入；**Tp** 为加了任务提示（Prompt）的文本嵌入。
- 冻结的 LLM 自回归生成情感/情绪标签序列 Y，损失采用**负对数似然（NLL）**；梯度仅回传到 MVFA 模块，LLM 参数保持不变。

## 6. 论文的主要结论与发现

1. **主结果领先**：MVFA-ChatGLM3-6B 在三个数据集上均达到最佳整体性能——
   - CH-SIMS V2.0：**84.62% Acc2 / 84.59% F1 / 77.27% Acc2-Weak / 0.736 Corr / 0.284 MAE**；
   - MELD：**67.36% Acc / 66.03% WF1**；
   - CHERMA：**74.66% Acc**，7类情绪中6类取得最佳F1。
2. **对照MSE-Adapter的增益**（同以ChatGLM3-6B-base为骨干时）：
   - CH-SIMS V2.0：Acc2 +1.76、F1 +1.87、Acc2-Weak +2.58、Corr 0.728→0.736、MAE 0.291→0.284；
   - MELD：Acc +1.48、WF1 +1.36；
   - CHERMA：Acc +1.25。
3. **参数效率高**：仅更新约 **0.1%** 的模型参数即可超越众多全量/传统方法。
4. **不同骨干上可移植**：MVFA 可有效适配 LLaMA2-7B 与 Qwen3-8B，但最终性能高度依赖骨干自身的语言理解能力，ChatGLM3-6B-base 效果最佳。
5. **消融结论**：多视图文本设计不冗余——移除任意单一池化分支均造成性能下降；MTF 与 ENQF 各自都有贡献且互补；文本模态主导ERC任务（去除文本后性能大幅滑坡），但音/视频仍提供有效互补信息。
6. **超参数趋势**：伪标记数量 n=4 最优（太少限制容量，太多引入冗余）；特征增强系数 α=0.3 最优（太小增强不足，太大破坏主融合表征）。
7. **细粒度分类改善**：混淆矩阵显示 MVFA 对易混淆的困难情绪类别（尤其 Disgust/ Fear/ Surprise）识别有明显改善。

## 7. 优点与亮点

- **多视图文本引导设计的创新性与直观性**：通过三种池化策略分别捕获词汇显著性、整体语义倾向和自适应关键token等互补文本信息，超越了以往方法的单一压缩文本视图，理论上更契合情感表达的多面性。
- **文本引导（不对称）融合范式**：以文本作为 Query 引导视觉/音频侧信息，而非对称拼接或密集注意力堆叠，更符合情感理解中文本语义主导的认知直觉。
- **轻量且高效**：用改进的跨模态交叉注意力取代稠密自注意力堆叠、用门控增强的 ENQF 压缩多模态信号，可训练参数控制在全局模型的 0.1% 以内，工程实用性较强。
- **泛化验证较充分**：在中文/英文、MSA/ERC、分类/回归多个维度上验证；并对三种常见 LLM 骨干做了可移植性检验。
- **实验严谨性佳**：统一5个随机种子取均值、复现最强基线比较、同时报告分类与回归两类指标、并做了模块/分支/模态/超参数的阶梯式消融分析。
- **可视化辅助分析**：混淆矩阵和定性案例辅助支撑了定量结论。

## 8. 不足与局限

- **与MSE-Adapter相关的预提取特征流程**：MVFA 同样建立在预提取的标准化特征之上，其具体效果受上游特征提取质量制约，面对低资源场景或特征缺失时的鲁棒性有待验证。
- **骨干差异未被充分挖掘**：LLaMA2/Qwen3上的MVFA性能落后于ChatGLM3变体，表明方法仍部分依赖骨干模型的语言/指令理解能力；论文并未分析MVFA自身在不同骨干上性能差异的根源（如tokenizer、预训练数据、指令对齐的影响）。
- **消融与调参的骨干覆盖面窄**：消融实验和超参数敏感性只在 ChatGLM3-6B-base 上完成，未检验在LLaMA2或Qwen3骨干上是否仍得出相同结论。
