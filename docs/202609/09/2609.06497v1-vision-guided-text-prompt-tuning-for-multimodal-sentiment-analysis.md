## 摘要
多模态情感分析需要对言语语义和非言语情感线索进行有效建模。一个核心挑战是如何以受控、自适应且参数高效的方式，将以文本为中心的情感理解与视觉面部证据进行校准。文本通常作为语义锚点，而视觉线索为模糊或隐含的表达提供补充证据；然而，不加区分的融合可能引入视觉噪声并扭曲文本语义。此外，完全微调大型视觉和文本编码器成本高昂，且容易在有限且依赖场景的多模态情感分析基准上过拟合。为解决这些问题，我们提出了视觉引导的文本提示调优（VG-TPT），将视觉-文本情感建模形式化为对冻结文本表示的可控视觉校准。VG-TPT通过逐层自适应提示将视觉情感线索注入冻结的BERT编码器，而非依赖后期特征融合或全骨干微调。一个协同引导路由器根据演化的文本状态和视觉引导特征，从可训练的提示库中组合提示，实现样本特定和层特定的调制。在CMU-MOSEI和CMU-MOSI上的实验表明，VG-TPT持续优于纯文本基线，并在仅更新240万可训练参数的情况下，达到与几种全模态方法相当或更优的性能。代码可在 https://github.com/ma-tubu/VG-TPT 获取。

## Abstract
Multimodal sentiment analysis requires effective modeling of both verbal semantics and non-verbal affective cues. A central challenge is to calibrate text-centered sentiment understanding with visual facial evidence in a controlled, adaptive, and parameter-efficient manner. Text usually serves as the semantic anchor, whereas visual cues provide complementary evidence for ambiguous or implicit expressions; however, indiscriminate fusion may introduce visual noise and distort textual semantics. Moreover, fully fine-tuning large visual and textual encoders is costly and prone to overfitting on limited and scenario-dependent MSA benchmarks. To address these issues, we propose Vision-Guided Text Prompt Tuning (VG-TPT), which formulates visual-text sentiment modeling as controllable visual calibration of frozen text representations. VG-TPT injects visual affective cues into a frozen BERT encoder through layer-wise adaptive prompts, rather than relying on late-stage feature fusion or full backbone tuning. A co-guided router composes prompts from a trainable prompt bank according to both the evolving text state and the visual guidance feature, enabling sample-specific and layer-specific modulation. Experiments on CMU-MOSEI and CMU-MOSI show that VG-TPT consistently improves over text-only baselines and achieves competitive or superior performance compared with several full-modality methods, while updating only 2.4M trainable parameters. The code is available at https://github.com/ma-tubu/VG-TPT.

### 1. 核心问题与整体含义（研究动机与背景）

- 多模态情感分析（Multimodal Sentiment Analysis, MSA）需要同时利用语言文本和视觉面部表情等信息推断情感状态。
- 文本通常被视为语义锚点，能够提供密集而可控的语义信息；而视觉面部线索能为模糊或隐含的表达提供补充证据，甚至能扭转纯文本判断错误的情感（例如“有趣经历”配合厌恶表情实际表达负面情绪）。
- 然而，已有方法存在三个关键问题：
  - **融合方式粗放**：早期或后期简单拼接、交叉注意力等融合方法把视觉当作并行辅助流，无法有效参与文本语义的逐步形成过程；
  - **视觉噪声干扰**：不加选择地将视觉信息与文本融合可能引入噪声、扭曲文本语义；
  - **训练成本高**：全量微调大型视觉和文本编码器参数量巨大，且在样本有限、场景依赖强的 MSA 基准上易过拟合。
- 论文因此提出“如何在不全量微调的前提下，以可控、自适应、参数高效的方式，用视觉面部证据校准以文本为中心的情感理解”这一核心研究问题。

### 2. 方法论（VG-TPT 的核心思想、技术细节与关键公式）

- **总体框架**：
  - 文本作为语义锚点，视觉信息作为引导条件；
  - 利用**冻结**的视觉编码器提取紧凑的视觉引导特征；
  - 利用**冻结**的 BERT 文本编码器，逐层注入视觉信息，最后接轻量预测头完成情感强度回归或分类。
- **视觉引导特征提取**：
  - $g_V = E_V(X_V)$，其中 $E_V$ 为冻结视觉编码器。
- **逐层视觉引导文本编码**：
  - 在特定层 $l\in S$ 生成自适应提示 $P_l$；
  - 将其插入到序列的 `[CLS]` 之后，形成增强序列；
  - 经过 Transformer 层后移除提示 token，保持原文本序列结构、使提示只参与临时交互。
- **协同引导的路由机制（Co-guided Prompt Routing）**：
  - 同时考虑当前文本状态 $h_{cls}^l$ 与视觉引导特征 $g_V$；
  - 路由向量：$z_l = [W_T h_{cls}^l; \, W_V g_V]$；
  - 与一组可学习/冻结的路由锚点（anchors）比较，生成软路由分布：$\alpha_l = \text{Softmax}(z_l A / \tau)$；
  - 该机制允许提示的选择是**样本特定**且**逐层特定**的，从而更好适应不同文本-视觉配对的情感关系。
- **自适应提示组合**：
  - 每个受提示层维护一个可学习的提示基底库 $B_l = \{B_{l,k}\}_{k=1}^K$；
  - 通过路由权重加权组合基底，得到自适应提示部分 $P_{ada}^l = \sum_k \alpha_{l,k} B_{l,k}$；
  - 此外加入视觉指令 token $p_V = W_I g_V$，显式携带视觉证据；
  - 最终提示为 $P_l = [P_{ada}^l; \, p_V]$。
- **训练目标**：
  - 回归任务：$L_{task} = |\hat{y} - y|$；
  - 为防止路由退化到少量基底，引入激活平衡损失：$L_{bal} = \frac{1}{|S|}\sum_{l\in S} (\sum_{k} m_{l,k}^2 - 1)$，其中 $m_{l,k}$ 是 mini-batch 内各基底的平均激活；
  - 总损失：$L = L_{task} + \lambda_{bal} L_{bal}$。
- **参数高效策略**：
  - 视觉编码器与 BERT 主干全部冻结；
  - 仅训练提示基底库、路由投影、视觉指令投影和预测头；
  - 可训练参数仅为 2.4M，约占模型总参数的 1.2%。

### 3. 实验设计：数据集、基准与对比方法

- **数据集**：
  - CMU-MOSEI：训练 17,016 条，验证 1,813 条，测试 4,098 条；
  - CMU-MOSI：训练 1,283 条，验证 214 条，测试 686 条；
  - 两个数据集均采用从 -3 到 +3 的情感强度标注，并采用回归任务设定。
- **视觉输入处理**：从原始视频中采样每个语段的中帧，送入视觉编码器提取引导表示；这与很多做法直接用预对齐特征不同。
- **评估指标**：MAE（平均绝对误差）、Acc-7（七分类准确率）、Acc-2（二分类极性准确率）、F1 分数。
- **对比方法**：
  - 文本基线：BERT、XLNet；
  - 视觉基线：V-Transformer；
  - 全模态基线（Audio+Vision+Text）：EF-LSTM、MulT、MMIM。
- 作者明确指出了对比的不完全对应：全模态方法额外使用声学模态，因此并非严格同类可比。

### 6. 论文的主要结论与发现

- VG-TPT 在纯文本基线基础上带来稳定增益，说明视觉面部信息能够有效补充和纠正文本情感判断；
- 仅使用视觉引导的 V+T 设置即可与使用音频、视觉、文本的全模态基线相当甚至更优：
  - CMU-MOSEI 上 Acc-2 和 F1 超过所有对比方法，Acc-7 接近 MMIM但取得最佳 Acc-2/F1；
  - CMU-MOSI 上 Acc-7 最高，且 MAE 优于 BERT/XLNet；
- 逐层自适应提示、协同引导路由和软组合均是必要部件；
- 以 2.4M 可训练参数达到优于全量 BERT 微调的结果，说明冻结主干加提示调优可作为多模态情感分析中兼具性能和效率的有效选择。

### 7. 优点（方法与实验设计的亮点）

- **思想新颖**：摒弃传统“后期融合”范式，把视觉证据作为“逐层提示”动态介入文本编码过程，从而更深刻地校正文本语义，而不仅是输出层面的调整；
- **自适应性强**：路由机制同时感知文本当前状态和视觉线索，支持样本级与层级的非固定提示组合，避免了全局共享提示表达能力不足的问题；
- **参数高效**：大部分预训练主干冻结，仅训练 2.4M 参数，大幅降低训练和部署成本；
- **逻辑清晰、消融完备**：为了验证结构设计，设计了四组有方向性的消融实验，结果都显示组件必要性，证据链条完整；
- **实验设置坦诚**：指出音频基线不可严格直接对比，避免了不必要的误导；
- **开放代码**：提供 GitHub 链接，便于复现和后续研究。

### 8. 不足与局限（实验覆盖、偏差风险与应用限制）

- **实验范围有限**：仅使用视觉+文本设定，没有与同设置下已有专门方法对比；也没有在声学+视觉+文本的三模态设定下扩展验证；
- **对比公平性受限**：全模态方法包含音频输入，其性能受模态信息量影响，无法完全体现 VG-TPT 优于“其他融合范式”的普遍性；
- **视觉信息简化**：作者仅采样单个视频中间帧作为视觉引导，丢掉了面部表情随时间变化的动态信息，可能限制视觉表达的上限；
- **训练细节缺失**：缺少优化器、学习率、批大小、视觉编码器具体选取、提示长度 M、基数 K、层集合 S 的选择等超参数说明，复现难度增加；
- **潜在平衡损失风险**：虽然使用平衡损失约束提示基底的利用，但 λ_bal 的敏感性与最优取值未做超参数分析；
- **应用场景限制**：论文动机中提及机器人和辅助驾驶等应用，但实验中未涉及实际场景数据，对域迁移和噪声鲁棒性的验证不足；
- **未来工作空缺明显**：作者自己指出音频-视觉-文本链式引导、更细粒度的时序视觉推理还有待完成。
