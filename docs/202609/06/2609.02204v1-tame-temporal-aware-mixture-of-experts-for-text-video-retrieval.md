## 摘要
文本-视频检索（TVR）旨在检索与自然语言查询匹配的视频，但将CLIP等图像-文本模型扩展到视频时，由于缺乏时间建模而受到根本限制。视频在视觉内容和运动方面表现出逐帧的异质性，而将所有帧压缩为单一表示通常会掩盖时间结构和语义转换。为了解决这个问题，我们提出了用于文本-视频检索的时间感知专家混合模型（TAME），这是一个基于CLIP的框架，可联合建模帧级结构和时间关系。首先，我们将稀疏专家混合（MoE）层集成到两个CLIP编码器中，并在视觉分支上应用帧一致路由，使专家根据帧级视觉模式进行专门化，同时保留原始的视觉-语言对齐。其次，我们引入了帧时间（FT）标记，用于聚合全局跨帧信息并将其反馈到每个帧，使视觉编码器能够捕获长时间范围的时间依赖性，而不会损害局部细节。第三，我们设计了一个跨时间交互与聚合（CTIA）模块，通过分阶段的时间过滤和融合来细化逐帧的句子-视频相似度。在标准TVR基准上的实验表明，TAME始终优于基于CLIP的基线。在MSR-VTT上，它相对于CLIP4Clip将R@1提高了4.0，并在DiDeMo、MSVD、LSMDC和ActivityNet上也取得了持续提升。代码可在此处获取：https://github.com/sejong-rcv/TAME。

## Abstract
Text-Video Retrieval (TVR) retrieves videos that match a natural-language query, but extending image-text models such as CLIP to videos is fundamentally limited by the lack of temporal modeling. Videos exhibit frame-wise heterogeneity in appearance and motion, and compressing all frames into a single representation often obscures temporal structure and semantic transitions. To address this, we propose Temporal-Aware Mixture-of-Experts for Text-Video Retrieval (TAME), a CLIP-based framework that jointly models frame-level structure and temporal relations. First, we integrate sparse Mixture-of-Experts (MoE) layers into both CLIP encoders and apply frame-consistent routing on the vision branch so that experts specialize according to frame-level visual patterns while preserving the original vision-language alignment. Second, we introduce Frame-Temporal (FT) tokens that aggregate global cross-frame information and feed it back to each frame, enabling the visual encoder to capture long-range temporal dependencies without harming local details. Third, we design a Cross-Temporal Interaction and Aggregation (CTIA) module that refines frame-wise sentence-video similarities through staged temporal filtering and fusion. Experiments on standard TVR benchmarks show that TAME consistently improves over CLIP-based baselines. On MSR-VTT, it improves R@1 by 4.0 over CLIP4Clip, and also achieves consistent gains on DiDeMo, MSVD, LSMDC, and ActivityNet. The code is available at https://github.com/sejong-rcv/TAME.

## 2. 方法论

### 2.1 总体框架
TAME 建立在 CLIP 双编码器（ViT-B/32）基础之上，引入以下三个协同设计的核心模块：

| 模块 | 作用 |
|---|---|
| **MoE-Enhanced CLIP** | 扩展编码器容量，利用稀疏专家使模型适应异质帧模式 |
| **Frame–Temporal (FT) tokens** | 注入跨帧上下文，在保留 patch 空间结构的前提下实现轻量时序传播 |
| **Cross-Temporal Interaction & Aggregation (CTIA)** | 将逐帧证据细化为连贯的视频级检索决策 |

### 2.2 MoE-Enhanced CLIP：稀疏专家混合编码器

**基本思路**：将双编码器中的若干 FFN 层替换为稀疏 MoE 层，每个 MoE 层包含 N_E 个并行 MLP 专家，路由器只选择其中 Top-K 个专家激活，从而在保持激活计算量基本不变的条件下扩大参数量。

**关键设计——文本分支（token 级路由）**：
- 每个文本 token 独立路由，计算公式为：
  ```
  θ_j = softmax(TopK(G_t(h_j)))
  y_j = Σ_{i=1}^{N_E} θ_j,i · E_i(h_j)
  ```

**关键设计——视觉分支（帧一致路由）**：
- 与常规的 patch 级路由（同一帧内各 patch 可能被分配到不同专家）不同，TAME 以帧为单位进行统一路由：以帧级 [CLS] token 作为路由信号，将该帧所有 patch 统一分配给同一组专家：
  ```
  θ_n = softmax(TopK(G_v(f_n)))
  y_n = Σ θ_n,i · E_i(X_n)
  ```
- 这种**帧一致路由**保证了帧内语义的连贯性，降低 patch 级路由噪声，使各专家能够按帧级视觉模式实现特化。

**专家初始化与负载均衡**：
- 每个专家由预训练 CLIP 的 FFN 权重复制初始化，路由器则随机初始化（sparse upcycling 策略）。
- 引入 Switch Transformer 风格负载均衡损失（LBL）防止路由坍缩：
  ```
  L_aux = α · N_E · Σ ρ_i · π_i
  ```
- 对文本（L^T_aux）和视频（L^V_aux）编码器分别计算该损失。

### 2.3 Frame–Temporal (FT) Tokens：帧间时态传播

**动机**：CLIP 视觉编码器逐帧独立处理，无法捕获跨帧的动作连续性和长程依赖。

**结构设计**：
- 在每帧的输入序列中，于 [CLS] token 和 patch tokens 之间插入 H 个可学习的 FT tokens：
  ```
  T_n^(0) = concat(f_n, t_n, P_n)
  ```
- 局部阶段：MoE 层内先对帧内序列做 MultiHead Self-Attention，得到更新后的 [CLS]、FT tokens 与 patch tokens。

**全局混合（global attention over FT tokens）**：
- 将各帧的 FT tokens 与 patch tokens 拼接为全局序列 U，执行全局多头自注意力：
  ```
  U = concat([t'_n; P'_n]_{n=1}^F)
  U_hat = softmax(QK^T/√d) · V
  ```
- **关键设计**：全局注意力输出中只更新 FT tokens（残差连接），保持 patch tokens 不变、[CLS] token 不被全局混合改变，从而最大限度地保护 CLIP 预训练中 patch 级和帧级的原始语义，也限制了全局信息进入帧表示的通道。
- 全局注意力只在视觉编码器中少量 MoE 层（如最上层 L_v^G=2）上运行，文本分支不运行（L_t^G=0），以控制计算开销。

**复杂度分析**：全局注意力额外成本为 O(B·L_v^G·F²(H+M)²·C)，相比每层都做跨帧注意力的方案显著降低。

### 2.4 CTIA：跨时间交互与聚合模块

**动机**：需要将逐帧的句子-视频相似度转化为统一、鲁棒的视频级决策，显式解决帧间时间一致性与证据整合问题。

**四个阶段**：

1. **锐化（Sharpening）**：在帧轴上对逐帧余弦相似度 s 做 softmax 归一化：
   ```
   r = softmax(s / τ_s)
   ```

2. **局部高斯平滑（Local Gaussian smoothing）**：用一维高斯核 k 对 r 做卷积：
   ```
   r_conv = r * k
   ```
   强制相邻帧的短期时间连贯性，抑制帧级噪声的孤立波动。

3. **非局部帧图传播（Non-local frame-graph propagation）**：构建帧间内容感知相似度图 A（基于帧特征 F 的 softmax 归一化内积），添加自环系数 γ 防止过平滑，再在图上传播相关信号：
   ```
   A ← γI + (1-γ)A
   r_graph = A · r
   ```
   该步能连接语义相似但时间距离较远的帧（如同类场景反复出现的情况）。

4. **可学习融合与权重生成**：
   - 使用可学习参数 β = ReLU([β_r, β_c, β_g]) 线性融合三个信号：
     ```
     u = β_r·r + β_c·r_conv + β_g·λ_g·r_graph
     ```
   - 通过带温度的 softmax 得到最终帧权重 w，CTIA 分数为加权和：
     ```
     S_CTIA = w^T s
     ```

**最终检索分数**：
```
S_final = ½(S_base + S_CTIA)
```
其中 S_base 是 CLIP4Clip 式时序编码器聚合视频特征后与文本的余弦相似度；S_CTIA 是帧级证据的加权聚合分数。

### 2.5 训练目标

总损失 = 双向 InfoNCE 损失（文本→视频、视频→文本）+ 负载均衡正则（λ(L^T_aux + L^V_aux)）+ 困难负样本边界损失（batch-hard margin loss）：
```
L_total = L_vq + λ(L^T_aux + L^V_aux) + L_hard
```
L_hard 惩罚"最难负样本比正样本更接近"的情况，要求二者间隔至少为 margin m。

## 6. 主要结论与发现（续）

4. **时间建模模块是性能提升的直接原因**：在加入稳定的 MoE 之后，逐步加入 FT tokens、CFA 和 CTIA，每一步都在 MSR-VTT 上带来稳步的 R@1 提升。其中 FT tokens 提供了帧间信息流动的通道，CFA 进一步精炼跨帧注意力，CTIA 则将多帧证据转化为可学习的、时间感知的聚合权重。三者在表征扩展基础上形成了完整的“编码—传播—聚合”闭环，缺一不可。

5. **帧置换与掩码实验验证了时间敏感性**：倒序和随机置换帧序会显著降低 TAME 的性能，说明模型并非单纯地在帧袋（bag-of-frames）上工作，而是真正利用了时序结构。掩码实验显示，即使遮挡 60% 的帧，TAME 仍然能保持相对稳定的检索性能，表明 FT tokens 与 CTIA 具备较强的信息冗余利用和缺失帧鲁棒性。

6. **路由诊断证实负载均衡损失的必要性**：在没有 LBL 时，文本编码器顶层路由的 top-1 共享度从随机初始的约 0.35 快速上升到 0.75–0.80，归一化熵仅约 0.5–0.6，意味着几乎所有 token 都被路由到同一个专家。加入 LBL 后，路由分布趋近均匀（熵 ≈ 1.0），变异系数明显下降，专家真正实现了多样化分工。视觉分支同样受益，同时帧一致路由有效避免了帧内 patch 分裂与语义碎片化问题。

7. **计算效率与性能的平衡可行**：TAME 的总参数量为 205.40M，较 CLIP4Clip 增加了约 25%，但 GFLOPs/sample 仅从 54.12 增至 77.59（增幅约 43%），远低于参数增幅。在 4×A6000 上，MSR-VTT 仅需约 4 小时完成训练，推理时每 query 约 20.8 ms，证明稀疏 MoE + 轻量时态模块的设计在可控成本下能同时带来显著的精度收益与可接受的效率开销。

## 7. 论文局限与潜在问题

尽管 TAME 在多个标准基准上取得了可观提升，论文本身以及本次分析中也暴露出一些值得注意的局限：

- **比较基准的公平性问题**：与 InternVideo2（6B）等大规模统一预训练模型直接对比时，TAME 的参数量、预训练数据规模均不在同一量级。虽然论文在表格中标注了来源与缺失指标，但并未使用相同的训练样本或预训练阶段进行等成本比较，因此表中所呈现的优势更多体现为“CLIP 骨干 + 轻量改造”路线的高性价比，而非全面超越。
- **推理与训练效率的透明度不足**：论文只报告了推理相似度矩阵的总时间和单 query 延迟，并未分析峰值显存、端到端吞吐、FT tokens 所带来的序列长度增长对注意力的二次复杂度影响，以及对长视频（如 ActivityNet 的较长片段）的扩展成本。
- **时间建模深度的上限未知**：FT tokens 与全局注意力仅在最后两层 MoE 中运行。对于更长、更复杂的视频叙事结构，两层跨帧交互是否足够语义细化仍缺乏系统性实验。帧置换和掩码实验虽验证了时间敏感性，但均基于出现频次固定的短片段（约 12 帧），与真实长视频的上下文相比仍有差距。
- **仅依赖零样本/线性探测式 CLIP 初始化**：TAME 没有在更大规模的视频-文本语料上进行端到端预训练，而是直接从 CLIP 图像模型出发。因此，其上限高度受限于 CLIP 的图像-文本对齐质量。对领域迁移剧烈的视频（如医学、体育动作细节）可能不够鲁棒。

## 8. 总结与评述

**TAME 的核心贡献**可归纳为三点：一是将 MoE 结构以“帧一致路由”方式适配到 CLIP 视觉编码器，在稀疏激活的前提下扩大了模型容量；二是设计 FT tokens 与全局注意力机制的轻量组合，将时间信息以可控的方式注入视频帧表示，而不破坏预训练特征的空间语义；三是提出 CTIA 模块，通过锐化、局部高斯平滑、非局部图传播和可学习融合四个步骤，显式地以帧级证据的时间一致性来形成最终的视频级决策。

**从方法论角度**，TAME 巧妙地将自然语言处理中流行的稀疏 MoE 扩展到视频-文本任务，并针对视频帧的时间属性和 CLIP 预训练结构进行了定制化设计（如帧级一致路由、FT tokens 的残差保护机制）。这种“稀疏特化 + 轻量时间传播”的思路，较单纯增加帧间 Transformer 层或堆叠外部时序网络更具参数效率。

**从实验角度看**，论文的消融体系完整、诊断工具丰富（路由均衡度量、置换/掩码鲁棒测试），有力支撑了每个模块的存在价值。但公正地说，TAME 所获得的绝对性能仍未达到 2024–2025 年产学界一流大规模预训练模型的水平，其更强的意义在于证明了“无需大规模视频预训练，仅在图像-文本预训练骨架之上做架构级改造，也能逼近甚至超过部分专门的视频-语言模型”。

**总体而言**，TAME 是一项在 CLIP 双编码器范式内推动视频时间理解的重要尝试。它把“模型容量扩展”和“时间结构建模”置于统一的视角下加以解决，为后续在视觉-语言模型中引入稀疏专家机制与跨帧动态路由提供了有参考价值的范式，也为低成本、高可控的视频检索系统提供了切实可行的技术路线。
