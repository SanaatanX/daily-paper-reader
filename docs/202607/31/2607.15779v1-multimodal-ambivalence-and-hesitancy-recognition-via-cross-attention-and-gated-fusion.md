## 摘要
我们提出了一种用于视频中矛盾/犹豫（A/H）识别的多模态框架，该框架为ECCV 2026的ABAW11挑战赛而开发。所提出的方法融合了从BAH数据集中提取的文本、声学和视觉模态，使用了三个预训练编码器：用于转录文本的F2LLM-v2-0.6B（1024维）、用于音频的WavLM-Large（1024维）以及用于面部视频的VideoMAE V2（768维）。我们首先使用经典分类器（MLP、随机森林、GBDT）建立了全面的单模态基线，每个分类器均通过Optuna进行了优化，并仅使用文本特征在测试集上获得了最佳单模态宏F1分数\textbf{0.6659}——显著优于零样本Video-LLaVA基线（宏F1：0.2827）。在这些基线的基础上，我们提出了一种多模态融合架构，该架构将三种模态间的双向交叉注意力与门控多模态单元（GMU）相结合，并通过50次Optuna搜索选择了架构和优化超参数。该模型在验证集上取得了\textbf{0.7394}的宏F1分数，相较于最佳单模态基线相对提升了11.0%，证实了显式的跨模态交互能够捕获任何单一模态单独无法提供的互补线索。最终预测使用该模型在官方未标注的私有测试集上生成，并按照挑战赛协议提交。代码公开于https://github.com/yassineouzar/IUSD_AH/

## Abstract
We present a multimodal framework for Ambivalence/Hesitancy (A/H) recognition in video, developed for the ABAW11 challenge at ECCV 2026. The proposed approach fuses textual, acoustic, and visual modalities extracted from the BAH dataset using three pretrained encoders: F2LLM-v2-0.6B for transcripts (1024-d), WavLM-Large for audio (1024-d), and VideoMAE V2 for facial video (768-d). We first establish comprehensive unimodal baselines using classical classifiers (MLP, Random Forest, GBDT), each optimized via Optuna, and obtain a best unimodal Macro F1 of \textbf{0.6659} on the test set using text features alone -- substantially outperforming the zero-shot Video-LLaVA baseline (Macro F1: 0.2827). Building on these baselines, we propose a multimodal fusion architecture that combines bidirectional cross-attention across all three modalities with a Gated Multimodal Unit (GMU), with both architectural and optimization hyperparameters selected through a 50-trial Optuna search. This model achieves a Macro F1 of \textbf{0.7394} on the validation set, a relative improvement of 11.0\% over the best unimodal baseline, confirming that explicit cross-modal interaction captures complementary cues that no single modality provides in isolation. Final predictions on the official, unlabeled private test set are generated using this model and submitted according to the challenge protocol. Code is publicly available at https://github.com/yassineouzar/IUSD_AH/

- **核心问题**：单一模态信息不足以准确捕捉 A/H 的微妙信号，因此需要一个**原则性的多模态融合方法**，同时建模模态内与跨模态的交互。
- **竞赛背景**：该工作针对 ECCV 2026 的 **ABAW11 挑战赛** A/H 识别赛道，基于主办方提供的 **BAH 数据集**开展研究。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 总体框架概述

论文采用“**单模态基线 → 多模态融合**”的两阶段策略：先逐一评估各模态的独立预测能力，再设计融合架构利用跨模态互补信息。

### 2.2 特征提取（三类预训练编码器）

论文的核心思想之一是**保留全序列 token 表示而非池化**，以保留细粒度的时序与语义动态：

| 模态 | 预训练编码器 | 输出维度 | 提取策略 |
|------|-------------|---------|---------|
| 文本 | F2LLM-v2-0.6B（基于 Qwen3-0.6B 微调） | Nₜ × 1024 | 保留完整 last_hidden_state 序列，不等长，不池化 |
| 音频 | WavLM-Large（316M 参数） | Nₐ × 1024 | 提取完整 last_hidden_state 序列，保留韵律细节 |
| 视觉 | VideoMAE V2（Base） | Nᵥ × 768 | 切成 16 帧块（不足则重复最后帧补齐），逐块过骨干后拼接所有 patch 级 token |

### 2.3 单模态分类基线

- 对每个模态分别训练三种经典分类器：**MLP、随机森林（RF）、梯度提升决策树（GBDT）**。
- 特征经 StandardScaler 标准化（在训练+验证的 902 个视频上拟合，防泄漏）。
- 使用 **Optuna + TPE 采样器**，每个分类器 100 次搜索，以验证集 Macro F1 为目标优化。

### 2.4 多模态融合架构（核心贡献）

融合架构包含四个关键组件：

1. **模态投影与位置编码**：各模态变长 token 序列线性投影至共享维度 d_model，后接 LayerNorm 与 Dropout，并加正弦位置编码注入时序信息。
2. **双向交叉注意力（Cross-Modal Attention）**：实现**六个方向的交叉注意力堆栈**（text←video、text←audio、video←text、video←audio、audio←text、audio←video）。每个方向含一个或多个前归一化交叉注意力块（含残差连接与前馈网络），并对 padding 位置施加掩码。
3. **池化**：交叉注意力后的上下文 token 序列经可配置的池化策略（均值/最大/学习注意力池化，由 Optuna 选择）压缩为单向量。
4. **门控多模态融合（GMU）**：三个池化向量拼接后送入 GatedFusion 单元——由拼接表示计算上下文向量，再为每个模态生成独立的 sigmoid 门控，动态**抑制噪声/无信息模态**（如面部遮挡、音频质量差），加权求和得到最终融合表示。
5. **分类头**：融合表示经可配置 MLP 输出单个 logit，以二分类交叉熵损失训练。

### 2.5 超参数优化

- 多模态架构与优化超参数（d_model、注意力头数、前馈维度、交叉注意力层数、dropout、池化策略、GMU 门控维度、分类器结构、学习率、权重衰减、梯度裁剪范数、优化器等）通过 **50 次 Optuna 搜索**确定。
- 最优配置（trial 17）：d_model=256、1 个注意力头、前馈维度 256、每模态对 2 层交叉注意力、dropout=0.278、均值池化、GMU 门控维度 64、单层分类头（宽 128、tanh）、RAdam 优化器、学习率 5.19e-4、梯度裁剪范数 2.31。

## 6. 论文的主要结论与发现

1. **预训练特征 + 有监督训练远超零样本**：训练后的单模态分类器（最优 0.6659）显著优于 Video-LLaVA 零样本基线（0.2827），论证了领域内训练的必要性。
2. **文本模态最为判别性强**：文本（F2LLM）单模态 Macro F1 达 0.6659，高于音频（0.6275）和视觉（0.5727），与词汇性犹豫信号（如限定语、间接表达）更直接可解读的直觉一致。
3. **多模态融合带来显著增益**：交叉注意力 + GMU 融合模型在验证集上达 **0.7394**，较最佳单模态相对提升 **11.0%**，证明显式跨模态交互能捕捉单模态无法提供的互补线索。
4. **各模态错误模式具有正交性**：音频与视觉的错误模式不同于文本，说明它们捕捉了部分正交的犹豫线索——这是融合有效的经验证据。
5. 训练/验证性能差距（0.9498 vs. 0.7394）提示存在过拟合，未来可通过正则化或数据增强进一步改善。

## 7. 优点（方法或实验设计的亮点）

- **全序列 token 保留策略**：在所有阶段保留变长 token 序列（不早期池化），配合掩码注意力，为跨模态交互保留了细粒度时序信息，且对未来的跨模态或多模态 LLM 扩展友好。
- **六方向双向交叉注意力设计**：每个模态同时作为 query 查询另外两个模态，充分建模模态间的双向依赖，而非简单的单向信息流或拼接。
- **GMU 门控机制设计合理**：针对野外录音可能存在的模态质量参差（面部遮挡、音频噪声），动态加权是一种针对性强的设计。
- **模块化、可复现的工程实现**：特征提取、预处理、训练、预测均为独立 CLI 可配置模块，代码公开，随机种子固定——对社区复现与后续研究有实际价值。
- **系统化的超参数搜索**：综合考虑架构与优化超参数（50-trial Optuna + TPE），非人工拍脑袋调参。
- **错误分析驱动设计决策**：通过分析单模态混淆矩阵发现模态间的互补性，为融合架构提供了基于证据的动机。

## 8. 不足与局限

- **缺乏多模态消融研究**：没有分解验证交叉注意力、GMU 各自贡献，也没有测试不同的融合组合（如两两模态融合 vs. 三模态），导致架构选择的理据不够充分。
- **跨集评估口径不一致**：单模态基线在测试集评估、多模态在验证集评估，两种评估集大小和类别分布不同，对比的有效性存疑；且未报告融合模型在标注测试集上的结果，泛化能力证据不完整。
- **零样本基线过弱**：0.2827 的基线过于基础，削弱了“大幅超越”的有说服力程度。
- **使用测试集进行训练**：多模态模型在训练+标注测试（1,303）上训练——这虽是为私有测试集服务的合理策略，但也意味着标注测试集的表现只能依赖验证集（124 样本）推断，统计可靠性有限。
- **未对预训练编码器进行微调**：特征提取器为冻结状态，限制了模态内部表征与目标任务的对齐；若微调或参数高效微调，性能可能有进一步空间。
- **序列长度处理不对称**：音频和视频被重采样到固定长度（500/128），文本保留变长——这种不对称处理对不同模态信息的保真度可能有潜在影响。
- **训练与验证差距偏大**：训练 Macro F1 0.9498 vs. 验证 0.7394，过拟合风险显著，但论文未尝试更强正则化或数据增强措施。
- **与 SOTA 的比较局限**：与 BROTHER 的对比仅为间接参照，无法在同口径下判定是否达到或超过当前最优水平。
