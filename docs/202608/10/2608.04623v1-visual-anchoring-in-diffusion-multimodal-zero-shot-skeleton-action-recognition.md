## 摘要
零样本骨架动作识别（ZSAR）在未见过动作具有相似的骨架关节动态但物体或场景上下文不同时仍然存在歧义。RGB提供了这些缺失的线索，然而现有的多模态方法通常维护独立的骨架和RGB评分分支并融合其输出。在不使用未标注测试数据进行自适应或融合校准的情况下，固定的融合权重无法捕捉依赖于类别对的模态可靠性，而自适应规则缺乏目标侧反馈来决定哪个分支应占主导地位。我们通过按生成分类（classify-by-generation）范式绕过了这一权重选择问题，其中每个类别的得分由文本条件下的去噪器对添加到骨架特征上的噪声的预测准确度来评定。这种表述将逐渐损坏的骨架与固定条件分离，使得RGB和文本能够共同条件作用于一个单一的类别评分函数，而不是产生独立的分数。我们将这一思想实例化为用于骨架-文本匹配的多模态三元组扩散（TDSM-MM），在文本条件下的去噪Transformer中增加了一个非扩散的RGB条件令牌，作为骨架数据重构期间的稳定视觉锚点。我们提出的TDSM-MM通过大量实验进行了消融，在NTU-60/120的四个划分中的三个上取得了最佳归纳准确率，并在NTU-120 96/24上超越了直推式最先进方法（即71.3%对69.1%），且无需测试时自适应，这表明基于扩散的方法可能是零样本学习的一个有前景的方向。

## Abstract
Zero-shot Skeleton Action Recognition (ZSAR) remains ambiguous when unseen actions share similar skeleton joint dynamics but differ in objects or scene context. RGB provides these missing cues, yet existing multimodal methods typically maintain independent skeleton and RGB scoring branches and fuse their outputs. Without using unlabeled test data for adaptation or fusion calibration, a fixed fusion weight cannot capture class-pair-dependent modality reliability, while an adaptive rule lacks target-side feedback for deciding which branch should dominate. We bypass this weight-selection problem via the classify-by-generation paradigm, where each class is scored by how accurately a text-conditioned denoiser predicts the noise added to the skeleton feature. This formulation separates the progressively corrupted skeleton from fixed conditioning, allowing RGB and text to jointly condition a single class-scoring function rather than produce independent scores. We instantiate this idea as Multimodal Triplet Diffusion for Skeleton-Text Matching (TDSM-MM), augmenting a text-conditioned denoising Transformer with a non-diffused RGB condition token that serves as a stable visual anchor during skeleton data reconstruction. Our proposed TDSM-MM has been ablated via extensive experiments and achieved the best inductive accuracy on three of four NTU-60/120 splits and surpasses the transductive state-of-the-art on NTU-120 96/24 (i.e., 71.3% vs. 69.1%), without test-time adaptation, suggesting that diffusion-based methods can be a promising direction for zero-shot learning.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题背景**：零样本骨架动作识别（ZSAR）需要在没有标注样本的情况下识别未见过的动作类别。纯骨架特征只编码身体动态，当不同动作具有相似的关节运动但区别在于物体或场景上下文时（例如“拿刀”和“头痛/敬礼”），骨架表示会产生歧义。
- **RGB的互补价值**：RGB 提供了目标、外观、场景等骨架缺失的线索，且 RGB 与文本已通过大规模视觉-语言预训练较好对齐，可作为连接骨架与文本的中间模态。
- **现有方法的不足**：已有的多模态 ZSAR 方法（如 BSZSL）通常为骨架和 RGB 各设独立评分分支，再对分数进行后置融合。但融合权重的选择存在根本困难：
  - 固定权重无法捕捉“类别对”之间变化的模态可靠性；
  - 自适应规则在归纳设置下缺乏未见类标签反馈来校准；
  - 已有证据表明，加入 RGB 并不总能超越强骨架方法（如 BSZSL 在部分 NTU 划分上不如纯骨架 TDSM）。
- **本文核心主张**：将多模态 ZSAR 重新表述为“扩散中的按类生成”问题——候选类别由去噪器对骨架噪声的预测误差来评分，RGB 作为非扩散的稳定视觉条件令牌直接参与这一联合评分函数，从而避免后置融合的权重选择难题。

## 2. 论文提出的方法论
### 2.1 核心思想：classify-by-generation
- 保持同一个逐渐加噪的骨架特征不变，交替替换每个候选类别的文本条件，由文本条件去噪器预测被添加的噪声。
- 候选类的能量定义为噪声预测均方误差，能量越低表示该类与观测（骨架+RGB）越匹配。
- RGB 不再产生独立分数，而是作为“非扩散条件令牌”与文本令牌一同构成条件流，参与去噪器的联合注意力计算。

### 2.2 关键技术细节
- **冻结表示**：
  - 骨架：冻结 Shift-GCN 提取 256 维特征 `x_{i,0}`。
  - 文本：OpenCLIP ViT-H（SD 2.1 所用）编码动作名称与 TDSM 描述，得到 35×2048 的局部令牌矩阵和 2048 维全局向量。
  - RGB：OpenCLIP ViT-H/14 对 8 帧均匀采样并平均，得到 1024 维样本级外观特征 `v_i`。
- **扩散损坏**：仅对骨架特征执行 DDPM 前向过程：`x_{i,t} = sqrt(ᾱ_t) x_{i,0} + sqrt(1-ᾱ_t) ε`。
- **RGB 条件令牌**：通过可学习线性映射 `E_v` 将 `v_i` 映射到 768 维，加一个可学习位置/槽嵌入 `p_v`，得到非扩散令牌 `z_i^v`。
- **CrossDiT 处理**：采用 12 块 DiT 风格 Transformer，每个块同时处理 37 个令牌（1 个骨架令牌 + 35 个文本令牌 + 1 个 RGB 令牌）；骨架流与条件流分离计算 QKV 后做联合注意力；全局文本向量与时间步嵌入通过 AdaLN 调制两个流。RGB 不生成 AdaLN 参数，但隐藏状态随每个块更新。
- **训练目标**：对每个样本采样一个噪声、一个时间步和一个错误类别文本，计算正确类能量 `E(y_i)` 与错误类能量 `E(y^-)`，训练目标为：
  - 扩散损失：正确类噪声预测 MSE（L_diff = mean E(y_i)）；
  - 三元组损失：`max(0, E(y_i) - E(y^-) + γ)`，促使正确类能量低于错误类；
  - 总损失为两者之和，γ=1。
- **推理**：固定时间步 t*=25，使用 N=10 个共享高斯噪声；对每个测试样本和每个噪声，构造同一个带噪骨架，然后用同一 RGB 评估全部未见候选类，取平均能量最小的类别作为预测。整个过程不更新任何参数、提示、原型或缓存。

### 2.3 与后置融合的对比
- 后置融合需要选择骨架权重 α，当模态间分数排序不一致时，α 的合适范围依赖类别对和分数尺度，而未见类对的差异无法从已见类校准得到。
- TDSM-MM 将融合吸收进联合注意力，由去噪器在候选文本、骨架、RGB 交互后直接输出统一能量，不需要独立 RGB 排序或显式融合权重。

## 6. 论文的主要结论与发现
- **RGB 作为条件而非独立分支更有效**：在归纳 ZSAR 中，将 RGB 信息作为单一去噪目标的组成部分，优于组合独立模态分数；后置融合的权重校准问题被联合注意力吸收。
- **非扩散 RGB 令牌具有“视觉锚”作用**：随着骨架损坏加剧，RGB 条件对候选排序的影响增大；语义不兼容的 RGB 在高损坏时间步会造成更大伤害，而兼容 RGB 保持稳定。
- **RGB 改变的是候选相对能量而非简单偏移**：不同动作的 RGB 会促使真类与供体类之间的能量差向供体方向移动，使 7.8% 的样本预测转向供体标签，证明 RGB 参与了候选区分。
- **改进主要来自对象/姿态依赖的未见类**：如 headache、juggling table tennis balls、cross arms 等骨架模式不够具体的动作；部分动作（如 salute）会出现倒退，说明效果是类依赖的。
- **无需测试时适应即可超越直推方法**：在 NTU-120 96/24 上 71.3% vs 69.1%，表明扩散方法在零样本学习中具有潜力。

## 7. 优点
- **范式创新**：首次将多模态骨架 ZSAR 形式化为扩散驱动的“按类生成”问题，使辅助模态直接参与候选评分，避开了融合权重选择的根本性困难。
- **设计简洁且可解释**：仅增加一个非扩散 RGB 条件令牌，结构改动小；通过多个反事实实验清晰展示了 RGB 在扩散过程中的“锚定”机制。
- **受控比较公平**：与纯骨架 TDSM 保持相同骨干、相同范式，仅变化 RGB 条件，能清楚归因性能变化。
- **统计验证扎实**：大量使用 bootstrap 置信区间、配对 McNemar 检验、类分层和主题聚类检验，增强了结论可信度。
- **代码公开**：提供项目页面和 GitHub 链接，利于复现。

## 8. 不足与局限
- **依赖 RGB 质量**：RGB 必须与当前样本的视觉语义正确对齐。替换为标签不匹配的真实 RGB 时，NTU-120 110/10 准确率从 86.6% 骤降至 35.5%，说明在 RGB 缺失、不可靠或误导时的鲁棒性不足。
- **类级回归现象**：对部分视觉混淆类（如 salute），RGB 条件可能重新分配决策并造成退化；条件机制只能缓解而不能完全消除。
- **推理成本较高**：每个样本需要约 `K×N` 次去噪器前向（K 为未见类数量，N=10），虽缓存 RGB 特征后开销增加不大，但在线部署还需额外视觉编码成本。
- **数据集覆盖有限**：仅在 NTU-60/120 两个数据集上验证，缺少其他动作识别基准（如 Kinetics-Skeleton、UCF101 等）或更广泛的多模态零样本测试。
- **不确定性报告不完整**：主要结果为五次噪声评估均值，但未跨训练种子报告标准差/置信区间；部分因果分析基于固定 checkpoint，不能完全反映训练随机性。
- **协议边界较窄**：专注于纯归纳设置，未与更广泛的转导方法系统比较，也未探索测试时适应或缓存机制下的性能上限。
