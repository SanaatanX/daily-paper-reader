## 摘要
视觉-语言模型通常将预训练视觉编码器产生的所有标记投影到大型语言模型中。然而，最终层的特征可能会丢弃文本、局部属性和空间关系，而高分辨率输入会显著增加上下文长度和推理延迟。我们引入了\method，一种多尺度自适应视觉编码器。\method使用位置相关的门控机制融合来自视觉Transformer的浅层、中间层和深层特征，在保留全局语义的同时增强边缘、文本和局部结构。随后，它根据问题相关性、局部信息内容、全局语义和空间覆盖进行基于问题的标记路由，并采用适应图像复杂度的标记预算。为了减轻压缩损失，我们进一步引入了全量到压缩的表示蒸馏和空间多样性正则化器。在统一7B语言模型框架下的示例性模拟中，\method将SigLIP-SO400M视觉标记的平均数量从729减少到146（约80.0\%），并将VQAv2、GQA、TextVQA、ScienceQA-IMG和MMBench的平均得分提高了2.2个百分点，同时将单图像首令牌时间从228\,ms降低到129\,ms。我们提供了完整的模型设计和评估协议。所有报告的数字目前仅作为论文组织和实验设计的占位符；正式声明需要实际训练运行、独立复现和官方基准评估。

## Abstract
Vision-language models commonly project all tokens produced by a pretrained vision encoder into a large language model. However, final-layer features can discard text, local attributes, and spatial relationships, while high-resolution inputs substantially increase context length and inference latency. We introduce \method, a Multi-scale Adaptive Vision Encoder. \method uses position-dependent gates to fuse shallow, intermediate, and deep features from a vision Transformer, preserving global semantics while enhancing edges, text, and local structure. It then performs question-conditioned token routing according to question relevance, local information content, global semantics, and spatial coverage, with a token budget that adapts to image complexity. To mitigate compression loss, we further introduce full-to-compressed representation distillation and a spatial diversity regularizer. In an illustrative simulation under a unified 7B language-model framework, \method reduces the average number of SigLIP-SO400M visual tokens from 729 to 146 (approximately 80.0\%) and improves the mean score on VQAv2, GQA, TextVQA, ScienceQA-IMG, and MMBench by 2.2 percentage points, while reducing single-image time to first token from 228\,ms to 129\,ms. We provide the full model design and evaluation protocol. All reported numbers currently serve only as placeholders for paper organization and experimental design; formal claims require real training runs, independent replications, and official benchmark evaluation.

# MAViE 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **核心矛盾**：现代视觉-语言模型（VLM）通常将预训练视觉编码器（如 CLIP、SigLIP、DINOv2）的**所有**视觉 token 直接注入大语言模型，且只使用编码器**最后一层**的特征。这种做法存在两个关键问题：
  1. **细粒度信息丢失**：ViT 的浅层特征包含边缘、纹理、字符笔画等细节，中间层包含部件与区域结构，而深层偏向全局语义。只用末层特征会削弱 OCR、计数、局部属性识别等能力。
  2. **推理开销过大**：提高输入分辨率虽然能改善细粒度感知，但视觉 token 数量随分辨率近似平方增长（如 224²→448²，token 数量约为原来的 4 倍），显著增加上下文长度、显存占用和首 token 延迟（TTFT）。
- **研究意义**：作者旨在同时解决"表示不够精细"与"视觉 token 冗余"两大问题，提出一种既能保留多尺度细粒度信息、又能根据问题和图像复杂度自适应压缩视觉 token 的编码器，实现感知质量与推理效率的平衡。

## 2. 方法论

### 2.1 总体框架
- 图像统一缩放至 384×384，使用 SigLIP-SO400M/14 编码（patch 14×14），得到 N = 27×27 = 729 个视觉 token。
- 提取第 8、16、24 层特征（分别对应浅层细节、中间层结构、深层语义），经两个核心模块处理后送入 7B LLM。

### 2.2 HMF（Hierarchical Multi-level Fusion，层次化多级融合模块）
- **统一投影**：将三层特征映射到公共维度，对浅层和中间层使用 3×3 深度可分离卷积增强局部归纳偏置。
- **位置相关门控**：每个空间位置独立预测三层特征的混合权重：
  \[
  g_i = \text{softmax}(W_g[f_{s,i}; f_{m,i}; f_{d,i}]), \quad \tilde{f}_i = g_{s,i}f_{s,i} + g_{m,i}f_{m,i} + g_{d,i}f_{d,i}
  \]
  \[
  f_i = f_{d,i} + \gamma \tilde{f}_i
  \]
  采用残差设计（γ 初始化为 0.1），避免浅层噪声在训练初期干扰深层语义。
- **高频区域增强**：计算每个 token 的局部变化幅度 \(u_i\)（与邻域 token 的 L2 距离均值），对文本、边界、复杂纹理等高频区域施加窗口化注意力，增强局部结构。

### 2.3 QATR（Question-conditioned Adaptive Token Routing，问题条件自适应 Token 路由模块）
- **问题表示**：对 LLM 的 token 嵌入做注意力池化得到问题向量 q。
- **四种评分信号**（加权求和）：
  - 问题相关性（question relevance）：视觉 token 与问题向量的余弦相似度；
  - 局部信息量（local information）：基于局部变化幅度 \(u_i\)；
  - 全局语义（global semantics）：与全局特征均值的余弦相似度；
  - 空间覆盖（spatial coverage）：与已选 token 的最小距离（顺序选择时动态更新），避免 token 全部集中到单一显著区域。
- **动态 token 预算**：复杂度估计器输入局部变化统计量、注意力熵和问题范数，经 sigmoid 映射到 [72, 288] 区间的 token 数 K（取 8 的倍数）。训练时用 Gumbel-Top-K 松弛，推理时用硬 Top-K。
- **被剪 token 的回收**：未选中的 token 通过可学习 context query 聚合成 M=8 个上下文 token，保留背景与整体布局信息。

### 2.4 训练目标
整体损失 = 语言建模交叉熵 + 对齐损失（sigmoid 图像-文本对齐）+ 蒸馏损失（全量特征与压缩特征之间的余弦 + L2 距离）+ 空间多样性正则化，权重为 (0.10, 0.50, 0.05)。

## 7. 优点

- **问题定位精准**：同时针对"末层特征丢失局部细节"和"高分辨率 token 爆炸"两个 VLM 实际痛点，切中要害。

## 8. 不足与局限

- **无真实实验结果**：全文核心表格均为占位符，无法验证方法真实有效性；这使所有性能结论目前只能视为"研究设想"。
- **固定输入分辨率限制**：384×384 对于极小或严重模糊的文字仍然不够，浅层特征无法恢复输入中已丢失的信息。
- **路由可能遗漏关键区域**：当问题需要比较多个相距较远的小目标时，路由器可能漏掉低显著性对象；模糊指代（ambiguous pronouns）可能使相关性信号过早聚焦错误区域。
- **动态机制的工程复杂度**：可变序列长度给大规模分布式训练带来 padding 和负载均衡方面的额外工程负担。
- **公平性风险**：选择性路由可能系统性忽略小目标、低对比度区域或分布外的文字，在文档理解、无障碍辅助等高危场景中放大模型错误；token 选择热力图不应被视为充分证据。
- **统计严谨性不足**：缺乏多次运行、误差棒、显著性检验、端到端能耗测量及跨硬件复现；评估结果对问题条件的敏感性分析虽然方向合理，但同样是模拟值。
- **后续工作待完成**：真实训练与官方基准评估、动态高分辨率裁剪、视频与多图扩展、"观察-推理-再观察"的迭代路由、硬件感知的预算优化等均未实现。
