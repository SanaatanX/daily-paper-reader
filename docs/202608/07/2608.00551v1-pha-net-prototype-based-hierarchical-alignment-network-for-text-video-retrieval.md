## 摘要
随着大规模图像-文本预训练模型（如CLIP）的出现，文本-视频检索近年来取得了显著进展。现有的最佳性能方法涉及在个体、局部和全局层面同时对齐跨模态语义，这引起了人们对简洁文本与丰富视频之间内在语义不匹配的担忧。一种典型的方法是将多个语言-视频注意力模块集成到分层框架中，然而这种范式仅以高昂的计算成本优化视觉表示。在本文中，我们提出了一种新的基于原型的分层对齐网络（PHA-Net），用于跨模态对齐个体/局部/全局级别的表示。具体来说，我们引入了多个模态共享原型作为桥梁，以高效优化文本和视频表示，用于跨模态对齐。然后，我们认为聚类标记中不平衡的语义分布可能会损害检索性能，因为语义较弱的标记不太受关注。为了减少这些标记的影响，所提出的原型支持的标记合并模块负责通过原型语义引导增强具有强语义的标记，并抑制其他具有弱语义的标记。此外，我们设计了一种原型对比损失，以鼓励文本和视觉原型关注不同的语义信息。该辅助损失的思想是确保来自同一原型的文本和视觉原型之间的相似度高于来自不同原型的相似度。在四个基准上的大量实验证实了我们PHA-Net的有效性，在MSR-VTT（8.8%）、ActivityNet（19.2%）、VATEX（0.7%）和Charades（4.9%）上的所有召回率总和方面取得了显著改进。代码可在https://github.com/JingXiaolun/PHA-Net获取。

## Abstract
With the emergence of large-scale image-text pre-training models, e.g., CLIP, text-video retrieval has experienced substantial advances in recent years. Existing best-performing methods involve aligning cross-modal semantics at individual, local, and global levels simultaneously, raising concerns about the intrinsic semantic mismatch between concise texts and rich videos. A canonical approach is to integrate multiple language-video attention modules into the hierarchical framework while this paradigm only optimizes visual representations with prohibitive computational costs. In this paper, we propose a new prototype-based hierarchical alignment network (PHA-Net) to align individual/local/global level representations across modalities. Concretely, we introduce multiple modality-shared prototypes as the bridge to efficiently optimize text and video representations for cross-modal alignment. Then, we argue that the imbalanced semantic distribution in clustered tokens may undermine retrieval performance, as tokens with weak semantics are of little interest. To reduce the impact of these tokens, a proposed prototype-supported token merge module is responsible for enhancing tokens with strong semantics and suppressing others with weak semantics via prototype semantics guidance. Moreover, we devise a prototype contrastive loss to encourage textual and visual prototypes to focus on different semantic information. The idea of this auxiliary loss is to ensure higher similarity between textual and visual prototypes from the same prototype than those from different prototypes. Extensive experiments on four benchmarks confirm the effectiveness of our PHA-Net, which achieves significant improvements in the sum of all recalls on MSR-VTT (8.8%), ActivityNet (19.2%), VATEX (0.7%), and Charades (4.9%). Code is available at https://github.com/JingXiaolun/PHA-Net.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：文本-视频检索（Text-Video Retrieval, TVR）旨在根据文本查询找到相关视频，或反之。近年来，大规模图像-文本预训练模型（如 CLIP）显著推动了该领域的发展。现有最佳方法往往需要在**个体级（单词/帧）**、**局部级（短语/片段）**和**全局级（句子/视频）**三个层面同时进行跨模态语义对齐。
- **核心问题**：简洁文本与丰富视频之间存在**内在语义不匹配**；传统分层对齐方法主要存在两大缺陷：
  1. **仅优化视觉表示**：典型做法是使用基于文本引导的交叉注意力模块，只生成语义相关的视频特征，却未能同步优化文本表示，导致对多义词或复杂语义匹配能力不足。
  2. **计算开销高昂**：每个层级至少需要一个交叉注意力模块，推理速度大幅下降。
- **本文目标**：提出一种**基于原型的分层对齐网络（PHA-Net）**，通过模态共享原型作为“桥梁”，以相对高效的方式联合优化文本和视频表示，并在个体、局部、全局三个层级完成跨模态对齐。

## 2. 方法论

### 2.1 总体框架
- 以 CLIP 为骨干（文本编码器 + 视频编码器），提取词 token 和帧 token。
- 在个体级和局部级引入**可学习的模态共享原型**（modality-shared prototypes），通过轻量级 Transformer 块建模原型与 token 的关系。
- 采用**原型支持的 token 合并模块**（prototype-supported token merge module）完成从词/帧到短语/片段、再到句子/视频的层级聚合。
- 设计**原型对比损失**（Prototype Contrastive Loss, PCL）保证不同原型关注不同语义区域。

### 2.2 关键技术细节
- **个体级对齐（Individual Alignment）**
  - 随机初始化一组个体级原型 \(P^I\)，与词/帧 token 拼接后送入轻量级 Transformer 块，得到语义对齐后的词/帧 token。
  - 使用加权 token 级交互机制（weighted token-wise interaction）计算个体级相似度，并计算对比损失。

- **局部级对齐（Local Alignment）**
  - 对个体级输出 token 使用一维卷积建模时间关系，然后采用 **DPC-KNN 密度峰值聚类**将词/帧聚成短语/片段。
  - 由于聚类后 token 的语义分布不平衡，提出**原型支持的 token 合并模块**：
    - 将原型平均并重复到与聚类 token 相同数量，作为查询 \(Q\)；
    - 将聚类后的加权平均 token 作为键 \(K\) 和值 \(V\)；
    - 通过交叉注意力输出“原型支持的短语/片段 token”，从而增强强语义 token、抑制弱语义 token。
  - 同样在短语/片段后面追加局部级原型，再经 Transformer 块对齐后计算局部级对比损失。

- **全局级对齐（Global Alignment）**
  - 将局部级 token 再次通过原型支持的 token 合并模块，聚合成句子 token 和视频 token，计算全局对比损失。

- **原型对比损失（PCL）**
  - 对文本原型和视觉原型计算跨样本相似度矩阵，使用 InfoNCE 约束：同一原型对应的文本原型与视觉原型应当相似，不同原型之间应当不相似，从而保证原型语义多样性。

- **训练损失**
  - 总体损失为：分层对比损失（个体+局部+全局） + 权重参数化的自蒸馏损失（个体→局部、局部→全局、个体→全局的 KL 散度）+ 原型对比损失。
  - 推理时直接对三个层级的相似度加权求和作为最终相似度。

## 3. 实验设计

### 3.1 数据集与基准
- **MSR-VTT**：10,000 个视频，每个视频 20 条描述；使用 9K 训练/1K 测试划分（JSFusion 协议）。
- **ActivityNet**：20,000 个 YouTube 视频，拼接多条描述形成视频-段落检索；使用 val1 划分。
- **VATEX**：34,991 个视频，采用 HGR 划分（25,991 训练 / 1,500 验证 / 1,500 测试）。
- **Charades**：9,848 个视频片段，采用与 [51] 相同的协议。

### 3.2 评价指标
- R@1、R@5、R@10（越高越好）
- MdR（中位数排名，越低越好）
- MnR（平均排名，越低越好）
- RSum（文本到视频和视频到文本的 R@K 之和）与 SumR（两个方向 RSum 之和）

### 3.3 对比方法
- 非 CLIP 方法：CE、MMT、HiT、ClipBERT、Frozen、MCQ 等。
- CLIP 微调方法：CLIP4Clip、X-Pool、CenterCLIP、X-CLIP、EMCL-Net、TS2-Net、DRL、DiffusionRet、UCoFiA、ProST、EERCF、TeachCLIP、TC-MGC、S2CA、HBI（基线）等。

### 3.4 实现细节
- 骨干：CLIP-ViT-B/32（默认）和 ViT-B/16（额外实验）。
- 轻量级 Transformer 块层数为 4，特征维度 512。
- 优化器 Adam，学习率：CLIP 编码器 1e-7，其他模块 1e-4。

## 6. 主要结论与发现
- PHA-Net 在四个数据集上均取得显著性能提升：

  - ActivityNet：SumR 提升 **19.2%**
  - VATEX：SumR 提升 **0.7%**

## 7. 优点
- **方法创新性强**：将“模态共享原型”引入分层 TVR，同时解决了仅优化视觉表示和计算开销过大的问题。
- **层次设计完整**：个体、局部、全局三级对齐互补，且原型数量采用“金字塔式”分配（底层多、上层少），符合语义复杂度和计算效率的权衡。
- **辅助损失合理**：原型对比损失和自蒸馏损失分别从原型多样性和跨层级一致性两个角度提升模型泛化能力。
- **实验全面且可信**：覆盖多数据集、多骨干、多维度消融，并公开代码，可复现性强。
- **效率优势明显**：训练时间比基线短约 35%，推理时间也比部分交叉注意力方法快。

## 8. 不足与局限
- **静态原型数量**：原型数量固定（\(N_p^I=3, N_p^L=1\)），不同视频内容复杂度差异大时，静态配置可能限制跨场景泛化能力，论文也承认这一点。
- **聚类算法可微性问题**：DPC-KNN 本身不可微，论文仅简略提及采用“前向结构掩码 + 后向注意力特征传播”机制，未充分展开其训练稳定性或收敛性分析。
- **实验提升不均**：在 VATEX 上提升很小（SumR 仅 +0.7%），作者解释为视频描述多样性高，但未给出针对性解决方案。
- **骨干依赖较强**：所有实验基于 CLIP 预训练模型，未验证在非 CLIP 骨干上的效果，可能受预训练分布影响。
- **应用范围有限**：仅验证了文本-视频检索任务，未扩展到其他跨模态任务（如图像-文本、医学影像分析等）；论文提到这些作为未来工作。
- **失败案例分析**：模型对场景突变、数量属性等细粒度语义仍易出错，说明原型表达能力存在上限。
