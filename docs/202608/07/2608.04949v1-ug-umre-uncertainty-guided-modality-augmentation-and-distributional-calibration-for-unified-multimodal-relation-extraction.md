## 摘要
统一多模态关系抽取（UMRE）旨在识别文本实体与视觉对象之间的模态内和跨模态关系。然而，现有的UMRE研究仍面临两个关键问题：忽略固有的偶然不确定性会导致噪声传播，以及不同模态分布之间深层的异质性阻碍对齐。为解决这些问题，我们提出了不确定性引导的UMRE网络（UG-UMRE）。具体而言，我们设计了一个不确定性驱动的单模态增强（UDUA）模块，该模块基于变分信息瓶颈将特征建模为高斯分布。通过引入不确定性感知的自监督对比学习机制，UDUA在保持语义一致性的同时有效过滤噪声。此外，我们引入了联合偶然不确定性对齐（JAUA）模块作为全局语义预校准机制。JAUA利用概率分布一致性构建共享潜在空间，通过同步跨模态统计属性消除分布差距，从而为细粒度交互奠定坚实基础。在三个基准数据集（UMRE、MORE和MNRE）上的实验表明，UG-UMRE达到了最先进的性能。进一步分析验证了所提出的UDUA和JAUA模块的可插拔性和有效性。

## Abstract
Unified Multimodal Relation Extraction (UMRE) aims to identify intra-modal and cross-modal relations between textual entities and visual objects. However, existing UMRE studies still encounter two critical issues: ignoring inherent aleatoric uncertainty causes noise propagation, and deep-seated heterogeneity between distinct modal distributions hinders alignment. To address these issues, we propose the Uncertainty-Guided UMRE Network (UG-UMRE). Specifically, we design an Uncertainty-Driven Unimodal Augmentation (UDUA) module, which models features as Gaussian distributions based on the Variational Information Bottleneck. By incorporating an uncertainty-aware self-supervised contrastive learning mechanism, UDUA effectively filters out noise while maintaining semantic consistency. Furthermore, we introduce the Joint Aleatoric Uncertainty Alignment (JAUA) module as a global semantic pre-calibration mechanism. JAUA leverages probabilistic distribution consistency to construct a shared latent space, eliminating the distributional gap by synchronizing cross-modal statistical properties, thereby laying a robust foundation for fine-grained interaction. Experiments on three benchmark datasets (UMRE, MORE, and MNRE) demonstrate that UG-UMRE achieves state-of-the-art performance. Further analysis validates the pluggable and effective performance of the proposed UDUA and JAUA modules.

## 1. 核心问题与整体含义

- **研究背景**：统一多模态关系抽取（UMRE）旨在同时提取文本实体之间、视觉对象之间以及文本实体与视觉对象之间的模态内和跨模态关系，是更贴近真实场景的多模态关系建模范式。相比早期的 MNRE 和 MORE 子任务，UMRE 的“统一”性质显著增加了跨模态表示学习和语义推理的复杂度。
- **核心问题**：现有 UMRE 方法存在两个关键挑战：
  - **模态噪声**：输入数据在各自模态空间内存在固有的偶然不确定性（aleatoric uncertainty），例如社交图像中的无关背景、文本中的模糊俚语或缩写。若忽略这种内在随机性，噪声会被错误传播，导致模型过拟合虚假关联。
  - **模态间隙**：文本和视觉特征来自异构编码器（如 BERT 和 ViT），分布在不同的特征空间中，直接进行跨模态融合会造成语义错位和后端融合失败。
- **整体含义**：论文提出“先降噪、再校准、最后融合”的新范式，通过不确定性建模和分布级对齐来同时缓解上述两大瓶颈，而不是像传统方法那样直接在未过滤、未校准的特征上进行跨模态交互。

## 2. 方法论

### 2.1 核心思想

- 将每个样本的单模态特征建模为多元高斯分布：均值表示稳定的核心语义，方差显式量化该样本的偶然不确定性。
- 采用“先降噪（UDUA）、后校准（JAUA）、再融合（MMoE）”的三阶段流程。

### 2.2 特征获取阶段

- 文本特征：使用 Qwen2.5-VL-7B 生成图像描述并与原文本拼接，输入 BERT 获得文本特征 \(F_T\)。
- 视觉特征：使用 ViT 和 Depth-Anything 分别提取 RGB 和深度特征，拼接位置编码后得到视觉特征 \(F_V\)。
- 多级最优传输（MOT）：利用最优传输理论和 Sinkhorn 优化聚合分层表示，得到增强特征 \(F'_T\) 和 \(F'_V\)。

### 2.3 UDUA 模块（不确定性驱动的单模态增强）

- **VIB 不确定性量化**：将 MOT 增强特征经过全局平均池化和全连接层投影，参数化后验高斯分布 \(p(Z|T) \sim \mathcal{N}(\mu_T, \sigma_T^2 I)\) 和 \(p(Z|I) \sim \mathcal{N}(\mu_I, \sigma_I^2 I)\)；通过变分信息瓶颈（VIB）目标函数在保留目标任务相关信息的同时压缩冗余噪声。
- **自监督对比学习（SCL）**：利用重参数化采样，以均值 \(\mu_i\) 为锚点，从其分布中采样正样本 \(z_i^+ = \mu_i + \sigma_i \odot \epsilon\)，采用 InfoNCE 风格损失将不确定性扰动下的语义变体拉向稳定中心，同时推远其他样本，实现分布感知的去噪和特征增强。

### 2.4 JAUA 模块（联合偶然不确定性对齐）

- 针对 UDUA 产生的跨模态高斯分布，计算双向 KL 散度作为对齐损失，同时惩罚语义中心（均值）的不一致和不确定性尺度（方差）的不一致。
- 该模块在分布层面进行全局预校准，构建共享潜在空间，消除模态间隙；保留多层级序列特征供后续交互使用，避免覆盖模态特有细节。

### 2.5 多模态融合与关系分类

- 使用层级跨模态交互（HCMI），以高层源模态特征作为 Query 注意力到互补模态的各层级特征，生成文本引导的视觉特征和视觉引导的文本特征。
- 通过多模态混合专家（MMoE）动态融合文本/视觉最优表示和跨模态交互特征得到最终表示。
- 根据关系三元组类型选择头/尾实体表示（文本实体用 \(\langle s\rangle\) 特征，视觉对象用 \(\langle o_i\rangle\) 特征拼合视觉特征），经过 MLP 分类器输出关系预测。

### 2.6 联合训练

- 总损失为 \(L = L_{umre} + \lambda_1 L_{IB} + \lambda_2 L_{SCL} + \lambda_3 L_{JAUA}\)，通过平衡系数联合优化主任务和各项辅助损失。

## 3. 实验设计

## 6. 主要结论与发现

- **性能提升**：UG-UMRE 在三个数据集上均达到新 SOTA，相比 REMOTE 分别提升 F1 2.34%（UMRE 69.98%）、3.95%（MORE 66.76%）、2.25%（MNRE 89.59%）。
- **模块有效性**：单独加入 UDUA 或 JAUA 均能提升性能；同时加入效果最佳，且 UDUA 收益略高于 JAUA，说明高质量去噪后的单模态特征是有效跨模态对齐的前提。
- **可插拔性**：UG-UMRE 能无缝集成到不同骨干（FocalMRE、REMOTE）中，在不改变原模型输入输出接口和核心参数的情况下带来一致性提升。
- **鲁棒性**：在 100% 噪声比例下，REMOTE+UDUA 相比 REMOTE 提升 17.32% F1，显示 UDUA 能有效阻断噪声传播。
- **模态间隙消除**：JAUA 使文本和视觉特征在潜在空间中紧密交织，证明分布级预校准优于仅依赖交互模块的隐式对齐。

## 7. 优点

- **问题切入精准**：明确区分“模态噪声”和“模态间隙”，并以统一不确定性和分布视角处理，而非简单增加融合模块。
- **方法论具有新意**：将变分信息瓶颈与偶然不确定性建模结合，并通过自监督对比学习利用不确定性进行有效的“语义增强”而非盲目添加噪声。
- **模块可插拔、轻量**：UDUA 和 JAUA 作为独立模块可迁移到其他 MRE 模型，参数和计算开销较小（REMOTE+UG-UMRE 仅增加 2.36M 参数、3.7G FLOPs）。
- **实验体系完善**：涵盖主实验、消融、可视化、鲁棒性、超参数、关系类型分析、效率和案例研究，验证充分且有说服力。
- **公平性意识强**：对对比模型采用相同输入、对生成式增强方法排除理由充分（避免破坏空间语义）。

  - 只使用单 GPU（RTX 4090），未报告多次运行平均值和方差，缺乏统计显著性验证。

  - JAUA 仅作用于整体潜在变量，未对序列级分布进行校准，可能不足以处理细粒度局部模态错位。
