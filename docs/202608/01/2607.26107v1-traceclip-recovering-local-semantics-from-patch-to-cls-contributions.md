## 摘要
密集视觉-语言理解，包括目标定位、区域识别和开放词汇语义分割，需要将语言概念与空间定位的视觉区域相关联。CLIP通过学习大规模对比预训练中的共享图像-文本嵌入空间，为这些任务提供了强大的基础。然而，其图像级目标将文本与CLS派生的全局表示对齐，使得局部视觉-语言对应仅被间接约束。现有方法要么引入额外的监督、外部模型或任务特定的适应，而无训练方法主要从现有补丁特征中恢复密集响应，而不检查局部语义在CLIP内部何处最易访问。我们引入了TraceCLIP，一种无训练框架，通过隔离写入CLS注意力输出中的补丁特定项来恢复潜在的补丁级语义证据。TraceCLIP进一步将贡献派生的语义响应转换为语义测地拓扑门，该门校准最终层补丁亲和力以进行密集特征重建。诊断实验表明，这些贡献特征表现出强烈的局部语义判别性和文本条件下的空间对齐。在八个零样本语义分割基准上，TraceCLIP在两个主干和背景设置中，相较于先前最强的无训练方法，平均mIoU提高了1.3至4.5个百分点，且无需额外训练、外部视觉基础模型或区域级监督。更广泛地说，这些发现表明，空间定位的语义可能在全局对齐表示的内部构造中仍然可访问。

## Abstract
Dense vision-language understanding, including object localization, region recognition, and open-vocabulary semantic segmentation, requires associating language concepts with spatially grounded visual regions. CLIP provides a strong foundation for these tasks by learning a shared image-text embedding space from large-scale contrastive pre-training. However, its image-level objective aligns text with a CLS-derived global representation, leaving local vision-language correspondence only indirectly constrained. Existing methods either introduce additional supervision, external models, or task-specific adaptation, while training-free approaches mainly recover dense responses from existing patch features without examining where local semantics become most accessible within CLIP. We introduce TraceCLIP, a training-free framework that recovers latent patch-level semantic evidence by isolating the patch-specific terms written into the CLS attention output. TraceCLIP further converts contribution-derived semantic responses into a semantic-geodesic topology gate that calibrates final-layer patch affinity for dense feature reconstruction. Diagnostic experiments show that these contribution features exhibit strong local semantic discrimination and text-conditioned spatial alignment. On eight zero-shot semantic segmentation benchmarks, TraceCLIP achieves gains of 1.3 to 4.5 points in average mIoU over the strongest prior training-free methods across both backbones and background settings, without additional training, external vision foundation models, or region-level supervision. More broadly, these findings suggest that spatially localized semantics may remain accessible within the internal construction of globally aligned representations.

## 1. 核心问题与整体含义

- **背景**：CLIP 通过大规模对比预训练建立了共享的图像-文本嵌入空间，但其图像级对比学习目标使用 CLS 令牌的全局表示与文本对齐，导致局部（patch 级）视觉-语言对应关系只被间接约束。
- **问题**：现有训练-free 的密集预测方法主要关注如何从已有 patch 特征中恢复更好的稠密响应，但没有仔细探究一个更根本的问题——**CLIP 内部计算中，局部语义证据在何处最直接可访问？**
- **含义**：作者认为，用于局部预测的信息可能参与了全局表示（CLS token）的构造，因此可以从内部计算路径中恢复这些局部语义，而不需要额外训练或外部模型。这一视角补充了“训练更多、适应更强”的传统思路。

## 2. 方法论

### 核心思想
- 在 ViT 自注意力中，CLS 的注意力更新可分解为多个 token 位置的加权 value 项之和。将这些 **patch-to-CLS 贡献项** 隔离，并投影到 CLIP 联合嵌入空间，即可获得可直接与文本比较的 patch 级视觉语言特征。
- 论文先用诊断实验证明贡献特征比最终 patch 状态有更强的局部语义判别性和空间对齐性；然后提出 TraceCLIP，将这些贡献响应转化为一种“语义-测地拓扑门”，用于校准最终层 patch 亲和度，实现无需训练的密集特征重建。

### 关键技术细节
1. **Patch-to-CLS 贡献分解**
   - 第 \(l\) 层、head \(h\) 中，CLS 到 patch \(i\) 的注意力系数为 \(A^{l,h}_{0i}\)，value 投影矩阵为 \(W^{l,h}_{OV}\)。
   - 读出特征：
     \[
     C^{l,h}_i = W_{\text{proj}}\big(A^{l,h}_{0i}\, W^{l,h}_{OV}\, \mathrm{LN}(x^l_i)\big)
     \]
     其中 \(W_{\text{proj}}\) 是 CLIP 视觉投影。
   - 对 head 求和得到 patch 级贡献特征 \(C^l_i = \sum_{h=1}^H C^{l,h}_i\)。

2. **贡献驱动的语义先验**
   - 将贡献特征矩阵 \(C\) 与文本嵌入矩阵 \(T\) 做点积：\(S_{\text{con}} = C^\top T\)。
   - 取每个 patch 的 argmax 得到初步语义标签 \(L_i\)，并用 softmax 概率作为置信度 \(P_i\)。

3. **语义-测地拓扑门（Semantic-Geodesic Topology Gate）**
   - 在 patch 网格上构建四邻接图，对相邻对 \((i,j)\) 定义边界指示 \(m_{ij}=1\)（若标签不同），边界置信度 \(c_{ij}=\min(P_i,P_j)\)。
   - 边代价 \(w_{ij} = 1 + \beta m_{ij}c_{ij}\)，即跨语义边界时增加代价。
   - 计算所有 patch 对的最短路径距离 \(D_{ij}\)，再转换为门：
     \[
     G_{ij} = \frac{\exp(-D_{ij}^2/2\sigma^2)}{\sum_r \exp(-D_{ir}^2/2\sigma^2)}
     \]
     该门保留了测地距离近的 patch 间强连接，同时抑制跨边界的传播。

4. **亲和度校准与密集重建**
   - 沿用 ClearCLIP 的 query-query 亲和度：\(A^h = \mathrm{softmax}_{\text{row}}\big(Q^h(Q^h)^\top/\sqrt{d_h}\big)\)。
   - 用拓扑门校准：
     \[
     \tilde{A}^h_{ij} = \frac{(A^h_{ij}+\varepsilon)(G_{ij}+\varepsilon)^\lambda}{\sum_r (A^h_{ir}+\varepsilon)(G_{ir}+\varepsilon)^\lambda}
     \]
     其中 \(\lambda\) 控制校准强度，\(\varepsilon\) 为数值稳定项。
   - 用校准后的亲和度聚合最终层 value 特征，经输出投影、后归一化和视觉投影，得到重建的 patch 级特征，再与文本嵌入计算相似度，上采样得到分割结果。

## 6. 主要结论与发现

- **贡献特征暴露了更强的局部语义**：在 COCO 上，ViT-B/16 的 \(C^{(-1)}\) 将区域分类准确率从最终 patch 的 11.3% 提升到 43.1%，定位点准确率从 19.9% 提升到 65.7%；ViT-L/14 上类似，且越靠近最终层效果越好。
- **局部证据在注意力贡献路径中被清晰地保留**，但在残差相加和 MLP 混合后变得难以直接访问。这说明冻结 CLIP 内部已经具备空间定位的语义信息，只是不在最终 patch token 接口中显式暴露。
- **TraceCLIP 无需训练即可提升密集预测**：在八个零样本分割基准上，ViT-B/16 平均 mIoU 比最强训练-free 方法提升 1.3–1.6 点，ViT-L/14 提升 2.9–4.5 点。
- **更广泛的启示**：全局对齐表示的内部构造中也编码了可恢复的局部语义，这为理解大型视觉语言模型的表示形成提供了新视角。
