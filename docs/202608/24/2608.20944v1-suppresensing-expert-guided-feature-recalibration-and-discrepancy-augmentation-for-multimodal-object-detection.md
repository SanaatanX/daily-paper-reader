## 摘要
遥感中的多模态目标检测面临语义异质性和模态特定噪声干扰的挑战。为此，我们提出了SuppreSensing，将多模态融合重新表述为一个选择性协作过程，联合建模共享信息和模态特定线索。SuppreSensing首先设计了一个专家驱动的多模态特征重校准（EMFR）模块，将共享共识提取重新表述为输入自适应的多专家选择过程，以缓解多模态融合中的对称性陷阱。作为补充，采用模态特定属性增强策略，通过建模双向差异模式来增强特定模态特征，减轻跨模态异质性。此外，我们提出了一个基于“专业检查-综合分析-诊断更新”体检范式的专家驱动定制特征净化（ECFP）模块，以迭代过滤冗余并强化任务相关语义。在DroneVehicle和VEDAI数据集上的大量实验表明，SuppreSensing实现了最先进的检测性能。在自然场景数据集（FLIR和LLVIP）上的跨域评估进一步验证了其在多种环境条件下的优越鲁棒性和泛化能力。

## Abstract
Multimodal object detection in remote sensing faces challenges due to semantic heterogeneity and modality-specific noise interference. To this end, we propose SuppreSensing, which reformulates multimodal fusion as a selective collaboration process that jointly models shared information and modality-specific cues. SuppreSensing first designs an Expert-driven Multimodal Feature Recalibration (EMFR) module, which reformulates shared-consensus extraction as an input-adaptive multi-expert selection process to alleviate the symmetry trap in multimodal fusion. Complementing this, a modality-specific attribute augmentation strategy is employed to enhance specific modality features by modeling bidirectional discrepancy patterns, mitigating cross-modal heterogeneity. Furthermore, we propose an Expert-driven Customized Feature Purification (ECFP) module based on a "specialized inspection-comprehensive analysis-diagnostic update" physical examination paradigm to iteratively filter redundancies and reinforce task-relevant semantics. Extensive experiments on the DroneVehicle and VEDAI datasets demonstrate that SuppreSensing achieves state-of-the-art detection performance. Cross-domain evaluations on natural scene datasets (FLIR and LLVIP) further validate its superior robustness and generalization capability across diverse environmental conditions.

- **核心问题一：对称性陷阱（Symmetry Trap）**。现有主流特征级融合方法大多基于"一致性对齐假设"，通过投影共享空间或注意力交互来强制不同模态在语义上对齐。这种强对齐范式存在一个关键弊端：过度的语义同质化会抑制模态特有的判别性线索——例如红外图像中微弱的热特征、可见光图像中的细粒度纹理细节——将这些有价值的模态特有信息当作不可靠干扰加以弱化甚至消除。
- **核心问题二：多模态MoE的对称路由缺陷**。尽管混合专家（Mixture of Experts, MoE）为动态选择提供了有前景的框架，但现有方法大多继承了自然语言处理领域的均衡路由策略，未考虑多模态图像在模态退化下的不对称性——质量较差的模态可能会通过路由传播噪声。
- **核心问题三：模态异质性与噪声干扰**。不同模态在成像机理、信噪比、空间分辨率、环境敏感度等方面存在显著差异，任务对每个模态的依赖程度也随场景动态变化，导致融合后的表示鲁棒性和判别力不足。
- **论文的整体定位**：将多模态融合重新定义为**选择性协作过程**，同时建模模态间共享信息和各模态特有线索，打破强对齐范式对模态特有信息的抑制，兼顾共享共识提取与模态差异保留，从而提升遥感多模态目标检测在多样化环境下的性能与泛化能力。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体架构

SuppreSensing 包含两大核心模块：
- **EMFR**（Expert-Driven Multimodal Feature Recalibration，专家驱动的多模态特征重校准）：用于多模态特征的重校准。
- **ECFP**（Expert-Driven Customized Feature Purification，专家驱动的定制特征净化）：用于特征的迭代净化与精炼。

整体流程为：可见光特征 F_Vis 和红外特征 F_Inf 输入 EMFR 进行重校准，得到校准后的融合特征，再送入 ECFP 进行迭代净化，最终输入检测头进行目标分类与定位。

### 2.2 EMFR 模块：专家驱动的多模态特征重校准

EMFR 将输入特征分解为两条互补路径：一条通过动态专家路由提取模态共享共识，另一条建模双向差异特征以增强模态特有属性，然后对两条路径的结果进行聚合重校准。包含两个子组件：

**（1）跨模态特征重校准（Cross-modal Feature Recalibration, CFR）**

- 核心思想：将共享共识提取从固定映射转化为**输入自适应的专家选择过程**。
- 技术流程：
  1. 先将双模态特征相加得到综合表示 **F = F_Vis + F_Inf**。
  2. 轻量路由网络 R 预测专家权重：**α = Softmax(R(F))**。
  3. 使用 K 个同构专家对综合特征进行加权处理得到共享共识：**F_c = Σ α_k · E_k(F)**。
  4. 通过通道注意力算子 φ(·) 将共识注入各分支，生成门控权重 **G_i = φ(F_i)**，i ∈ {c, Vis, Inf}。
  5. 跨模态门控重校准公式为：
     - F⁺_Inf = G_c × G_Vis ⊙ F_Inf
     - F⁺_Vis = G_c × G_Inf ⊙ F_Vis
- 场景自适应特性：在强日光下，模型可更多地依赖红外线索补偿可见光过曝；在弱光下，可更多地强调红外图像的热显著性。

**（2）模态特定属性增强（Modality-specific Attribute Augmentation, MAA）**

- 核心思想：显式建模双向差异模式，增强模态特有判别性线索，缓解跨模态异质性。
- 技术流程：
  1. 计算双向差异特征：**D_Vis = F_Vis − F_Inf**，**D_Inf = F_Inf − F_Vis**。
  2. 通过非线性变换和通道注意力细化差异特征：**F⁻_s = φ(D_s) ⊙ F_s**。
  3. 最终的重校准特征为：**F′_s = F_s + λ⁺F⁺_s + λ⁻F⁻_s**，其中 λ⁺ 和 λ⁻ 为可学习参数。

### 2.3 ECFP 模块：专家驱动的定制特征净化

ECFP 以"专业检查—综合分析—诊断更新"（specialized inspection-comprehensive analysis-diagnostic update）的体检范式为设计灵感，将多模态特征转化为五条定制化路径，作为每个空间位置的诊断指标，通过迭代更新逐步净化特征。具体五条路径为：

1. **空间位置定制处方（Spatial Location Customized Prescription, SLCP）**
   - 针对遥感图像复杂背景和空间位置特征差异，引入 MoE 机制实现"联合会诊、定制处方"。
   - 阶段一（症状诊断）：路由网络联合投影主、辅模态特征，生成逐像素的"症状"表示 **G_route = Concat(W_x(F_pri), W_y(F_sec))**；再通过冻结的正交专家矩阵 E 与症状表示的内积计算匹配权重：**M = Softmax((G_route · E) / τ + ε)**，实现专家"联合会诊"。
   - 阶段二（定制处方）：基于可学习的专家知识库 P ∈ R^(K×K)，沿空间维度扩展为候选空间 P̂，由匹配权重 M 加权聚合，形成定制化特征处方：**F_{B,S,K} = Σ_K M_{B,S,K} · P̂_{K,S,K}**。

2. **辅助模态映射（Auxiliary Modal Mapping, AMM）**
   - 将辅助模态特征通过线性/非线性变换投影到潜在空间：**F̂_aux = σ(W_p F_aux + b_p)**，校准主辅模态间的表征偏差。

3. **阶段特定主模态投影（Stage-specific Primary Modality Projection, SPMP）**
   - 针对网络加深导致的主模态特征语义层级变化，使用非线性投影层提取各阶段深度特定特征，校准跨层语义一致性。根据层 l 的阶段使用不同的投影函数 Φ₀ 或 Φ₁。

4. **全局静态先验（Global Static Prior, GSP）**
   - 为每一层提供与输入内容无关的固有统计特征，帮助校准跨层模态分布偏移。

5. **进化主模态（Evolved Primary Modality, EPM）**
   - 保留上一层诊断更新后的主模态特征作为进化基线，提供跨迭代的连续性参考，更新公式为：**F^(l)_pri = F^(l−1)_pri + F_fus(Concat(F^(l−1)_EPM, F^(l−1)_GSP, F^(l−1)_{B,S,K}, F̂^(l−1)_aux, P^(l−1)_proj))**。

最终，五条解耦特征流沿通道维度拼接聚合，形成综合报告；通过循环迭代净化策略，逐步抑制任务无关噪声、强化判别性语义。

- **方法有效性的根源**：不依赖数据集特定的空间对齐先验，而是从全局和局部两个视角建模模态互补性，自适应调整模态贡献，因而具备跨域泛化能力。

## 7. 方法亮点

1. **问题建模新颖**：将多模态融合明确重构为"共享信息 + 模态特有信息"的选择性协作问题，直接指向强对齐范式的根本缺陷（对称性陷阱），问题意识清晰。
2. **MoE 机制的创新性应用**：不同于 NLP 中继承的对称均衡路由，EMFR 将共识提取设计为输入自适应的多专家选择过程，使路由策略能感知场景环境和模态质量，缓解噪声传播。
3. **双向差异建模**：MAA 通过显式建模 F_Vis − F_Inf 和 F_Inf − F_Vis 的差异模式来增强模态特有线索，思路简洁而有效。
4. **"体检"隐喻与工程化设计结合**：ECFP 将特征净化类比为"专项检查—综合分析—诊断更新"的体检流程，设计上采用五路并行特征流（SLCP/AMM/SPMP/GSP/EPM），概念新颖且模块功能边界清晰。
5. **跨模态门控注入**：在 CFR 中，共享共识通过通道注意力生成门控权重，以交叉门控（cross-gating）方式注入对方模态分支，实现了"共识指导下的模态互相增强"。
6. **系统性的消融设计**：不仅做了模块级消融，还深入 ECFP 内部逐路径消融，证据链完整。
7. **广泛的验证场景**：从遥感小目标到自然场景行人、从白天到暗夜，多维度验证泛化能力。

## 8. 不足与局限

1. **效率与实用性评估不足**：未与对比方法在参数量、计算量上进行公平对比，未报告推理速度，无法判断该方法是否适合实时或资源受限的无人机平台部署。
2. **mAP@0.5:0.95 指标报告不完整**：对比表中多数方法仅报告 mAP@0.5，缺少更严格的 mAP@0.5:0.95 的横向对比。
3. **实验环境细节缺失**：未提供训练总时长、单卡/双卡的具体耗时、内存占用等，限制了可复现性的完整评估。
4. **消融基线定义模糊**：基线模型的组成（如是否含任何融合机制、主干选择等）未明确说明，影响消融增益解读。
5. **超参数敏感性分析缺失**：专家数量 K、温度参数 τ、噪声项 ε、可学习权重 λ 的初值等都未讨论，读者难以判断方法对超参数的敏感程度。
6. **跨域泛化验证仍有局限**：虽然 FLIR 和 LLVIP 验证了方法从遥感迁移到自然场景的能力，但缺少对更多退化条件（如雨雾、极端天气）和更多模态组合的验证；LLVIP 仅含 1 个类别，验证充分性有限。
7. **理论分析不足**：论文主要是经验性验证，未对"为什么输入自适应专家选择能缓解对称性陷阱"给出理论层面的分析或证明。
8. **潜在偏差风险**：DroneVehicle 的标注格式为 OBB，而部分对比方法可能基于 HBB 设计，存在指标比较的细微不对齐风险（论文未讨论这一影响）。
