## 摘要
多模态目标重识别（ReID）旨在通过利用模态间的互补信息来检索目标实例。然而，现有方法面临两个挑战。首先，它们往往无法利用良好对齐且可靠的语义先验，使其易受背景杂乱和跨模态错位的影响。另一方面，它们通常依赖于整体特征建模，忽略了全局与局部表示之间的协同作用。为克服这些局限，我们提出了一种具有双语义引导与全局-局部相互调制的鲁棒多模态ReID框架，主要由三个关键组件组成，即文本语义注入器（TSI）、掩蔽全局-局部调制器（MGLM）和层次化专家混合融合（HMF）。TSI通过将干净且连贯的文本特征集成到视觉令牌中来增强语义感知。MGLM通过软掩码和全局上下文的联合引导实现部件感知的跨模态交互，从而改善细粒度特征对齐。最后，HMF在局部语义监督下自适应地聚合多光谱特征，产生具有判别性和鲁棒性的表示。在三个多模态ReID基准上的大量实验表明了所提方法的有效性。代码将在论文被接收后于 https://github.com/zw-absin/DSGM 公开提供。

## Abstract
Multi-modal object Re-Identification (ReID) aims to retrieve target instances by leveraging complementary information across modalities. However, existing methods suffer from two challenges. First, they often fail to exploit well-aligned and reliable semantic priors, making them vulnerable to background clutter and cross-modal misalignment. On the other hand, they typically rely on holistic feature modeling, overlooking the synergy between global and local representations. To overcome these limitations, we propose a robust multi-modal ReID framework with dual semantic guidance and global-local mutual modulation, which mainly consists of three key components, namely the Text-Semantic Injector (TSI), the Masked Global-Local Modulator (MGLM), and the Hierarchical MoE Fusion (HMF). The TSI enhances semantic awareness by integrating clean and coherent textual features into visual tokens. The MGLM enables part-aware cross-modal interaction through joint guidance from soft masks and global context, improving fine-grained feature alignment. Finally, the HMF adaptively aggregates multi-spectral features under local semantic supervision, yielding discriminative and robust representations. Extensive experiments on three multi-modal ReID benchmarks demonstrate the effectiveness of the proposed method. The code will be made publicly available at https://github.com/zw-absin/DSGM upon acceptance.

## 1. 论文的核心问题与整体含义（研究动机和背景）

多模态目标重识别（Multi-modal Object Re-Identification, ReID）旨在利用可见光（RGB）、近红外（NIR）和热红外（TIR）等异构模态之间的互补信息，在跨摄像头、跨光谱的条件下鲁棒地检索目标实例。尽管单模态ReID已在RGB域取得显著进展，但面对极端光照、恶劣天气、严重遮挡和剧烈视角变化等真实部署条件时，基于外观的特征可靠性仍受到严重制约。

论文指出现有方法存在两大核心问题：

- **语义先验利用不充分**：大多数方法未能利用良好对齐且可靠的语义先验（如文本描述、分割掩码），导致模型易受背景杂乱干扰，并在跨模态间出现特征错位。早期尝试借助CLIP注入语义先验，但过于泛化；近期虽引入多模态大语言模型（MLLM）生成文本描述，但模态间往往采用不一致的提示词，导致描述语义漂移（如TIR图像被错误描述为具有颜色属性），造成误导性引导。
- **全局与局部特征协同缺失**：现有方法多依赖整体（全局）特征建模，缺乏对局部部件级对应关系的显式建模，难以在模态间实现细粒度的局部对齐，限制了复杂场景下的判别力。

针对上述局限，论文提出**DSGM（Dual Semantic Guidance and Global-Local Mutual Modulation）** 框架，以双语义引导（统一文本描述 + 软语义掩码）为核心，结合全局-局部相互调制机制，系统性地增强跨模态对齐鲁棒性和特征判别力。

## 2. 论文提出的方法论

**核心思想**：构建两类统一的语义信号——任务特定的文本描述和软语义掩码——为多光谱特征学习提供结构化引导，并通过全局上下文与局部部件之间的动态交互实现跨模态对齐。

框架由三个关键组件构成：

**（1）文本语义注入器（Text-Semantic Injector, TSI）**
- 采用统一提示策略，通过MLLM（GPT-4o）生成跨模态共享的单一文本描述，消除模态特定的提示偏差。
- 在冻结的CLIP文本编码器中注入**padding mask**，抑制PAD令牌在自注意力中的传播，避免填充噪声干扰文本语义。
- 使用多个Generalized Mean（GeM）池化实例获取多粒度全局文本特征。
- 通过**超图特征精炼模块（HFR）** 将图像令牌与文本令牌置于共享超图空间中进行高维多模态交互，超越传统的两两注意力机制。

**（2）掩蔽全局-局部调制器（Masked Global-Local Modulator, MGLM）**
- 利用SAM2从结构增强的融合图像（YCbCr空间中融合三模态亮度通道）生成软语义掩码，作为前景定位先验。
- 将图像和掩码划分为k个水平条带，每个局部块拼接三模态特征与全局上下文令牌，形成部件级跨模态特征。
- 在掩码引导下通过掩码感知编码器进行局部跨模态建模，抑制背景噪声，促进细粒度部件对齐。

**（3）层次化专家混合融合（Hierarchical MoE Fusion, HMF）**
- 包含部件感知MoE与全局上下文MoE两级路由机制。
- 第一级根据局部语义线索选择专家，生成局部融合特征和上下文向量；第二级以该上下文向量调制全局特征路由，实现局部到全局的自适应特征聚合。
- 采用噪声门控与辅助负载均衡损失，防止路由崩溃并鼓励专家多样性。

**优化目标**：采用标签平滑交叉熵损失与三元组损失的组合，分别作用于视觉编码器输出和HMF融合特征，并叠加MoE辅助损失。

## 3. 实验设计

**数据集与基准**：
- **RGBNT201**：大规模多模态行人ReID数据集，201个身份，RGB/NIR/TIR三模态同步采集，包含夜间、强光、雾霾等退化场景。
- **RGBNT100**：车辆ReID数据集，100辆车，8,675个训练三元组与8,575个测试三元组。
- **MSVR310**：更具挑战性的车辆ReID数据集，2,087个图像三元组，含重度遮挡、低照度和多样天气条件。

**评估指标**：mAP与CMC Rank-1/Rank-5/Rank-10。

**对比方法**：覆盖三大类——CNN基础方法（OSNet、PCB、HANNet、PFNet等）、ViT基础方法（TOP-ReID、EDITOR、DESANet等）、CLIP/MLLM基础方法（MambaPro、DeMo、IDEA、NEXT、Signal等）。

**实验结果**：
- RGBNT201上，取得82.6% mAP与87.0% Rank-1，超越所有对比方法，比IDEA提升2.4% mAP与4.9% Rank-1。
- RGBNT100上，89.4% mAP / 98.2% Rank-1，比TOP-ReID提升8.2% mAP。
- MSVR310上，64.6% mAP / 76.0% Rank-1，比IDEA提升17.6% mAP与13.6% Rank-1。

## 6. 论文的主要结论与发现

- 双语义引导（统一文本描述 + 软掩码）能有效缓解跨模态语义漂移，为多光谱特征学习提供一致性锚点。
- 全局-局部相互调制机制显著增强了对背景杂波和遮挡的鲁棒性，使模型聚焦于关键前景区域。
- HMF的两阶段局部→全局MoE路由优于静态融合或单层MoE，实现了上下文自适应的模态权重分配。
- 在三个多模态ReID基准上，DSGM在mAP和Rank-1上均超越现有最先进方法，尤其在极端退化场景（MSVR310）下提升幅度显著。
- 框架对弱文本生成器（Qwen-VL）表现出良好的鲁棒性，且跨数据集泛化能力优于对比方法。
