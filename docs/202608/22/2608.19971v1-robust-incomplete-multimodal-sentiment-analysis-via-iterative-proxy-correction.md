## 摘要
多模态情感分析旨在通过整合语言、视觉和听觉线索来推断情感状态。然而，现实世界的多模态输入往往不完整或受到损坏，这可能削弱跨模态互补性，并将误导性信息引入下游融合。现有的用于不完整MSA的基于代理的方法通常依赖一次性代理构建来补偿退化的语言信息，但生成的代理在初始化时可能粗糙或不可靠。过早地将这样的代理注入多模态推理会传播初始错误并损害情感预测。为了解决这一局限性，我们提出了一种用于鲁棒不完整MSA的迭代代理修正框架。我们的方法从非语言模态构建面向语言的代理，并通过门控残差修正，在多模态语境下逐步细化该代理。然后，根据估计的语言可靠性得分，将修正后的代理与观察到的语言表征自适应融合，使模型能够平衡基于代理的补偿和可信的语言证据。此外，我们引入了一个阶段性的潜在修正目标，使用完整的语言表征作为训练时的语义锚点，以稳定代理细化的轨迹。在MOSI、MOSEI和SIMS上在不同缺失模态设置下的大量实验表明，所提出的框架始终优于竞争性基线，并在不完整输入下实现鲁棒的情感预测。

## Abstract
Multimodal sentiment analysis aims to infer affective states by integrating language, visual, and acoustic cues. However, real-world multimodal inputs are often incomplete or corrupted, which can weaken cross-modal complementarity and introduce misleading information into downstream fusion. Existing proxy-based methods for incomplete MSA commonly rely on one-shot proxy construction to compensate for degraded language information, but the generated proxy may be coarse or unreliable at initialization. Prematurely injecting such a proxy into multimodal reasoning can propagate initial errors and compromise sentiment prediction. To address this limitation, we propose an iterative proxy correction framework for robust incomplete MSA. Our method constructs a language-oriented proxy from non-language modalities and progressively refines it under multimodal context through gated residual correction. The corrected proxy is then adaptively fused with the observed language representation according to an estimated language reliability score, allowing the model to balance proxy-based compensation and trustworthy linguistic evidence. In addition, we introduce a stage-wise latent correction objective that uses the complete language representation as a training-time semantic anchor to stabilize the proxy refinement trajectory. Extensive experiments on MOSI, MOSEI, and SIMS under diverse missing-modality settings demonstrate that the proposed framework consistently outperforms competitive baselines and achieves robust sentiment prediction under incomplete inputs.

## 一、核心问题与整体含义（研究动机与背景）

- **研究问题**：多模态情感分析（MSA）通常假设语言、视觉、听觉三种模态在训练和推理时都是完整可靠的。然而真实场景中，模态数据常因传感器故障、背景噪声、传输不稳定或隐私限制等原因出现缺失或损坏。这种不完整性不仅造成信息损失，退化的模态还可能继续参与跨模态交互，注入误导性信息，扭曲最终的情感预测。
- **现有方法的不足**：现有的不完整多模态情感分析方法主要分为**重构式**（显式恢复缺失信号）和**表征式**（直接学习面向决策的潜在表征）两大类。其中，以语言为中心的方法被广泛采用，因为它们假设文本蕴含了最直接的任务相关语义。然而当文本本身缺失、嘈杂或语义不足时，该假设不成立。由此衍生的**语言导向代理方法**（如 LNLN）从非语言模态构造辅助潜在表征来补偿退化的语言信息，但普遍采用**一次性代理构建**的范式——代理一旦生成就直接注入下游融合。
- **核心挑战**：一次性代理在不完整输入下往往粗糙、嘈杂、仅在部分信息上有用，过早参与跨模态融合会**传播并放大初始误差**，最终损害预测性能。论文的核心洞察是：代理不应被视为一个固定替代品，而应在决策前被逐步精炼为更可靠的语言导向表征。

## 二、方法论：核心思想、关键技术细节与公式流程

### 2.1 总体框架

整体流程：多模态输入 → 模态编码 → 迭代代理修正 → 语言-代理融合 → 下游多模态推理 → 情感预测。在训练阶段，完整样本仅用于辅助监督。

### 2.2 多模态输入编码

三种模态分别通过各自的编码器映射到共享潜空间：

- 公式：H_m_l = E_l(X_m_l)，H_m_v = E_v(X_m_v)，H_m_a = E_a(X_m_a)
- 编码后经 token 压缩，得到 H_m_l, H_m_v, H_m_a ∈ R^(N×d)，其中 N 为 token 数量，d 为隐藏维度。

### 2.3 迭代代理修正（核心创新）

- **代理初始化**：为避免对观测语言流的平凡重参数化，代理仅从非语言模态初始化，捕捉语言输入中缺失的互补线索：
  - S^(0) = G([Q; H_m_a; H_m_v])，其中 G 为 Transformer 代理生成器，Q 为可学习的查询 token。
- **迭代细化**：在第 t 步，拼接当前代理与三种模态表示形成上下文 C^(t) = [S^(t); H_m_l; H_m_a; H_m_v]，然后计算：
  - 残差修正项：∆^(t) = ϕ_t(C^(t))
  - 更新门：M^(t) = σ(ψ_t(C^(t)))
  - 代理更新：S^(t+1) = LN(S^(t) + M^(t) ⊙ ∆^(t))
  - 经过 T 步修正后得到最终代理 S^* = S^(T)
- **设计要点**：门控机制控制修正强度，层归一化稳定更新轨迹，迭代过程使代理在多模态语境下逐步趋于可靠。

### 2.4 语言-代理自适应融合

- 估计观测语言表征的可靠性得分：r = σ(f(Pool(H_m_l)))，r ∈ [0,1]
- 融合公式：H_d = (1 − r)S^* + r·H_m_l
- 当语言可靠时模型更多信任 H_m_l；语言不可靠时更多依赖修正后的代理，实现两种证据来源的自适应平衡。

### 2.5 情感预测

融合后的语言表征与视觉、听觉特征一起送入下游融合网络 F，最终预测 ŷ = W_o·Pool(F) + b_o。

### 2.6 训练目标

- 情感预测损失：L_sp = ‖ŷ − y‖²₂（回归损失）
- 阶段式修正损失：L_corr = Σλ_t‖S^(t) − H_c_l‖²₂，以完整语言表征 H_c_l 作为训练时语义锚点，且后阶段权重更大（Σλ_t = 1）
- 总损失：L = L_sp + θ·L_corr + L_aux（L_aux 沿用基座框架 LNLN 的辅助目标）

## 六、主要结论与发现

1. 迭代代理修正框架在 MOSI、MOSEI、SIMS 三个数据集上一致优于现有基线，在多数指标上取得最佳或次佳成绩。
2. **关键亮点**：在 MOSEI 上 Corr 从基线 LNLN 的 0.530 大幅提升至 0.595，MAE 从 0.692 降至 0.664，展示了更强的细粒度情感强度建模能力。
3. 模态消融显示：语言是最具信息量的模态，文本参与的设置显著优于纯 A/V/A+V；听觉和视觉主要起补充作用，单独使用时不足以支撑可靠预测。
4. 组件消融证明三个组件均有效：**w/o Proxy 降幅最大**（证实代理补偿的重要性），w/o Iterative 和 w/o Lcorr 也均有所下降（证实迭代精炼和阶段监督均有益）。
5. 案例研究表明：迭代代理修正能从缺失输入中更好地恢复情感相关语义；但高度模糊或跨模态证据冲突的样本仍具有挑战性。

## 七、优点

- **问题洞察深刻**：准确识别了现有代理方法“一次性构建、过早注入”导致的误差传播问题，切入点新颖且具有实际意义。
