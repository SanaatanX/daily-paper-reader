## 摘要
动态场景图（DSGs）以⟨主体，谓词，对象⟩三元组的形式捕获视频中的时空交互，并为视频字幕生成、视频问答和动作分析等下游任务提供支撑。然而，端到端的动态场景图生成（DSGG）方法是封闭集的：它们只能识别固定训练词汇中的对象和谓词，并且难以应对稀有概念的长尾分布，严重限制了其实际应用。现有的开放词汇模型通常继承预训练的大语言模型，导致多阶段训练和推理成本高昂。我们引入了OvDSGG，这是首个用于开放词汇DSGG的端到端框架。OvDSGG构建于开放词汇的空间骨干和时间骨干之上；我们进一步提出了一种连接两者的三元组特征提取模块，以及一种视觉-语言对齐模块，通过在联合视觉-语言特征空间中学习自适应决策边界来保持开放词汇识别能力，无需现有方法中昂贵的知识蒸馏。我们还引入了一个基于Action Genome改编的严格开放词汇DSGG基准，对对象和谓词均进行了不相交的基础/新类划分。OvDSGG在所有指标上显著优于开放词汇基线，零样本Recall@$K$分数比次优基线高出10.0–20.4个百分点，同时在封闭集DSGG上保持与最先进模型的竞争力。代码和基准公开于https://github.com/jhelsby/OvDSGG/。

## Abstract
Dynamic scene graphs (DSGs) capture spatio-temporal interactions across videos as $\langle$subject, predicate, object$\rangle$ triplets, and underpin downstream tasks such as video captioning, video question answering, and action analysis. However, end-to-end dynamic scene graph generation (DSGG) methods are closed-set: they recognize only objects and predicates from a fixed training vocabulary and struggle with the long-tailed distribution of rare concepts, severely limiting their real-world applicability. Existing open-vocabulary models typically inherit pretrained large language models, resulting in multi-stage training and inference with substantial cost. We introduce OvDSGG, the first end-to-end framework for open-vocabulary DSGG. OvDSGG builds on top of an open-vocabulary Spatial Backbone and a Temporal Backbone; we further propose a Triplet Feature Extraction Module that bridges them, and a Visual-Language Alignment Module that preserves open-vocabulary recognition by learning an adaptive decision boundary in the joint visual-language feature space, without expensive knowledge distillation in existing methods. We further introduce a rigorous open-vocabulary DSGG benchmark adapted from Action Genome, with disjoint Base/Novel splits for both objects and predicates. OvDSGG significantly outperforms open-vocabulary baselines across all metrics, with zero-shot Recall@$K$ scores 10.0--20.4 percentage point higher than the next-best baseline, while on closed-set DSGG remaining competitive with state-of-the-art models. Code and benchmark are publicly available at https://github.com/jhelsby/OvDSGG/.

## 2. 方法论

### 2.1 总体架构

OvDSGG 包含四大组件，依次串联，形成端到端可训练的视频场景图生成流水线：

1. **空间骨干（Spatial Backbone）**：基于 Grounding DINO 的开放词汇视觉-语言检测器。
2. **三元组特征提取模块（Triplet Feature Extraction Module）**：将实体查询提升为三元组级表示。
3. **时间骨干（Temporal Backbone）**：基于 OED 的渐进式精炼模块，聚合跨帧时间上下文。
4. **视觉-语言对齐模块（Visual-Language Alignment Module）**：用 BERT 文本嵌入初始化分类头，实现开放词汇分类。

### 2.2 核心思想

**将开放词汇的图像 SGG 框架 OvSGTR 与单阶段 DSGG 模型 OED 进行有机集成**，通过两个新模块解决两大适配难题：

- **难题一**：时间模块需要紧凑的逐查询三元组表示，但 Grounding DINO 只输出逐对象查询 → 通过**三元组特征提取模块**将实例特征和谓词特征拼接成三元组表示。
- **难题二**：开放词汇能力必须在时间训练中得以保持，但 OvSGTR 的知识蒸馏保留损失在视频上每帧都需要教师前向传播，成本过高 → 通过**视觉-语言对齐模块**将文本嵌入作为可学习分类头的初始化，从结构上保留新类原型，完全去掉蒸馏损失。

### 2.3 关键技术细节

**（1）空间骨干（Grounding DINO）**

- 对象类名拼接为统一提示（如 "person. bag. bed..."），由 BERT 编码得到对象嵌入 `e_obj_c`。
- 谓词类名由同一 BERT 编码得到谓词嵌入 `e_rel_p`，用于下游分类头初始化。
- 每帧输出 `Nq` 个实体查询 `h_obj`、锚框 `b_anc`、密集记忆特征图 `M`。

**（2）三元组特征提取模块**

- **实例特征**：`h_ins = W_ins · h_obj`（线性投影）。
- **谓词特征**：`h_rel = InteractionDecoder(h_ins; M)`（3 层 Transformer 解码器，含自注意力、交叉注意力、FFN）。
- **三元组表示**：`h_trp = [h_ins; h_rel] ∈ R^(Nq×2d)`（通道维拼接）。

**（3）时间骨干（OED 渐进式精炼模块）**

- 按查询置信度 `p = p_obj · p_attn · p_spat · p_cont` 对参考帧查询进行排序。
- 级联 `m` 层，逐层保留 top-`k_i` 个高置信度参考查询，交叉注意力逐步精炼目标帧表示（阈值递减，如 80n → 50n → 30n）。
- 精炼后特征沿通道拆分，得到时间增强的实例特征 `h'_ins` 和关系特征 `h'_rel`。

**（4）视觉-语言对齐模块**

- **对象分类**：`p_obj = σ(W_obj · h_ins)`，权重矩阵 `W_obj` 行由对象文本嵌入初始化：`W_obj[c,:] = e_obj_c / ||e_obj_c||_2`。
- **边界框回归**：两个 3 层 MLP 分别预测主体/客体坐标偏置，在 inverse-sigmoid 空间加入锚框。
- **谓词分类**：按 Action Genome 的谓词结构，分 attention、spatial、contacting 三组独立线性头，权重由预测文本嵌入初始化。
- **与 OvSGTR 的关键区别**：OvSGTR 用冻结 BERT 嵌入与输出特征计算余弦相似度损失（知识蒸馏）；OvDSGG **仅用文本嵌入初始化权重，权重可学习**，实现语义先验与决策边界的解耦。

**（5）训练与推理要点**

- **匹配**：匈牙利匹配 + 多标签 sigmoid Focal Loss + L1/GIoU 边界框损失。
- **开放词汇掩码策略**：对象损失仅计算 Base 类（Novel 类不进入训练提示）；谓词损失用二进制掩码 `m_gp` 限制在 Base 谓词上。Novel 类行在整个训练过程中不接收梯度，保持文本嵌入初始值。
- **部分冻结策略**：视觉骨干和 BERT 完全冻结，Grounding DINO 倒数六层跨模态编码器和解码器可微调；开放词汇时间训练时冻结整个空间组件以减轻灾难性遗忘。
- **推理**：滑动时间窗口，全局置信度阈值剪枝 + 批量 NMS 去重。

### 2.4 任务定义

- **封闭集 DSGG（CS-DSGG）**：训练与评估词汇相同。
- **开放词汇 DSGG（OV-DSGG）**：词汇划分为不相交的 Base/Novel 子集，训练仅用 Base 标注，评估用完整词汇。

## 6. 主要结论与发现

- **核心结论**：OvDSGG 是首个端到端开放词汇 DSGG 框架，在开放词汇设置下显著优于所有构造基线。

## 7. 优点

1. **首个端到端开放词汇 DSGG 框架**：填补了动态场景图生成在开放词汇方向的研究空白。
2. **去除知识蒸馏依赖**：通过结构化的文本嵌入初始化分类头，在视频场景下大幅降低训练成本，且不牺牲开放词汇性能。
3. **巧妙的模块桥接设计**：三元组特征提取模块将 Grounding DINO 的对象级查询转化为时间模块所需的三元组表示，形成有效的时空衔接。
4. **语义先验与决策边界解耦**：分类头初始化保留 BERT 语义先验，可学习权重适应目标域，是本文方法论的亮点。

6. **全面的评估体系**：同时报告 R@K、mR@K、zR@K 三种指标，区分 With/No Constraint 设置，结果客观充分。
7. **部分冻结策略**：有效缓解了开放词汇训练中的灾难性遗忘问题，为后续研究提供了经验。

1. **开放词汇时间模块仍存在退化**：No-Constr. mR@50 和多数 zR@K 指标上，时间模块相比空间模块略有回退（如 zR@10 With-Constr. 从 15.5 降至 13.6），说明时间增强对稀有和新类别的排序重校准有限。
2. **冻结限制**：为避免灾难性遗忘而冻结空间组件，限制了模型用时间信息重校准稀有类别的能力，需更精细的适配策略（如参数高效的时间适配器）。
3. **封闭集性能差距**：与 OED 相比在多数封闭集指标上仍略逊色（尽管排名第二），Grounding DINO 相对 DINO 的封闭集劣势是主要原因。
4. **长尾偏差未彻底解决**：开放词汇对齐缓解了 Novel 类偏差，但 R@K 与 mR@K 之间仍有明显差距，模型仍偏向高频 Base 类。
5. **算力信息不透明**：未披露训练所用 GPU 型号、数量及耗时，难以评估方法的实际资源门槛。
6. **基准单一性**：仅在 Action Genome 上验证，Novel 划分也是自行构建，缺少跨数据集和第三方验证。
7. **框架复杂度较高**：依赖 Grounding DINO + BERT + OED + 多个新模块，工程实现和调参成本较高，可能限制其在资源受限场景下的应用。
