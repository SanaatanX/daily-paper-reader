## 摘要
多模态情感分析(MSA)旨在从文本、音频和视觉等异构输入中预测情感极性和强度。虽然大型语言模型(LLM)为MSA提供了强大的语义先验，但有效融入音频和视觉信号仍然具有挑战性。一个关键挑战在于，音频和视觉情感线索在不同时间尺度上演化，然而许多基于LLM的方法在将这些信号与文本融合之前，通过浅层投影或粗粒度池化对其进行压缩，这可能削弱跨模态对齐并丢失细粒度情感信息。我们提出了MGSI，一种用于基于LLM的MSA的多粒度情感集成框架。MGSI首先在短、中、长三个时间尺度上对音频和视觉流进行编码，同时保留局部变化和全局情感趋势。然后，通过文本引导对齐来细化非文本特征，并应用极性和强度感知增强，以更好地处理模糊和接近中性的样本。最终得到的多模态表示被压缩为一小组伪标记，用于高效地条件化冻结的LLM。在四个公开基准上的实验表明，MGSI显著优于冻结LLM基线，并与强大的多模态方法保持竞争力。进一步的消融和敏感性分析支持了多粒度时间建模、文本引导细化和自适应情感校准的有效性。

## Abstract
Multimodal sentiment analysis (MSA) aims to predict sentiment polarity and intensity from heterogeneous inputs such as text, audio, and vision. While large language models (LLMs) offer strong semantic priors for MSA, effectively incorporating audio and visual signals effectively remains challenging. A key challenge is that audio and visual sentiment cues evolve over different temporal scales, yet many LLM-based methods compress these signals through shallow projection or coarse pooling before fusing them with text, which can weaken cross-modal alignment and erase fine-grained affective information. We propose MGSI, a multi-granularity sentiment integration framework for LLM-based MSA. MGSI first encodes audio and visual streams at short-, medium-, and long-range temporal scales, preserving both local variations and global affective trends. It then refines non-text features through text-guided alignment, and applies polarity- and intensity-aware enhancement to better handle ambiguous and near-neutral samples. The resulting multimodal representation is finally compressed into a small set of pseudo-tokens for efficient conditioning of a frozen LLM. Experiments on four public benchmarks show that MGSI substantially outperforms frozen-LLM baselines and remains competitive with strong multimodal methods. Further ablation and sensitivity analyses support the effectiveness of multi-granularity temporal modeling, text-guided refinement, and adaptive sentiment calibration.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：多模态情感分析（MSA）旨在从文本、音频和视觉等异构输入中预测情感极性与强度。大型语言模型（LLM）具备强大的语义先验，被越来越多地用于 MSA 系统，但其原生处理的是文本 token，音频与视觉特征并非天然的语言符号，需要转换为与 LLM 输入空间兼容且语义对齐的表示。
- **核心问题**：现有 LLM 基方法在融合音视频信号时，常通过浅层投影或粗粒度池化将非文本序列压缩后注入 LLM。这种过早、粗糙的压缩会**破坏跨模态对齐**，并**丢失音频与视觉线索在不同时间尺度上演化的细粒度情感信息**（例如局部瞬时波动、中等长度模式、长程情感趋势）。
- **论文主张**：LLM 基 MSA 的核心瓶颈不仅在于“如何将音视频特征映射到 LLM 嵌入空间”，更在于“**哪些蕴含情感的时间结构应当在这一映射中保留下来**”。因此，作者提出将多模态适应视为一种**结构化的时间-语义压缩**，而非简单投影。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：在将非文本信号压缩为 LLM 可用的伪标记（pseudo-tokens）之前，先显式地对音频和视觉流进行**多粒度时间编码**，再通过**文本引导对齐**、**极性辅助监督**和**自适应情感校准**优化表示，最后以少量伪标记注入冻结 LLM。
- **总体框架（MGSI）**：包含三个阶段：
  1. 模态特定特征提取（多粒度时间编码器，MGT）；
  2. 跨模态情感集成（文本引导对齐、非中性分类器、自适应情感校准器、多尺度融合适配器）；
  3. 冻结 LLM 解码进行情感预测。

- **关键模块**：
  - **多粒度时间编码器（MGT）**：对每种非文本模态 `q ∈ {a, v}` 使用三个并行分支：
    - **短期分支**：一维卷积（`Conv1D`）+ 最大池化，捕获局部模式；
    - **中期分支**：膨胀卷积（`DConv1D`）+ 最大池化，扩大感受野；
    - **长期分支**：Transformer + 注意力池化，建模长程依赖与全局趋势；
    - 三个分支的摘要 token 经多头自注意力融合，再经 MeanPool 得到增强表示 `h(q)`。
  - **文本引导对齐（TGA）**：使用文本全局摘要生成门控信号，对音视频表示做残差调制 `ĥ(q) = h(q) ⊙ (1 + r(q))`，使非文本特征与文本语义对齐，随后线性融合音视频得到 `h(f)`。
  - **非中性分类器（NNC）**：对情感强度绝对值大于阈值 `τ` 的样本执行二分类（正/非正），通过辅助交叉熵损失 `L_nnc` 强化极性判别。
  - **自适应情感校准器（ASC）**：针对近中性或模糊样本，预测样本相关标量 `ρ`，对融合特征进行残差校正并做层归一化，缓解弱情感样本难建模问题。
  - **多尺度融合适配器**：将校准后特征经 K 个并行 MLP 分支、1D 卷积压缩为 M 个伪标记（默认 M=4），与文本嵌入按 `[E_pre; P; E_text; E_suf]` 形式拼接注入冻结 LLM。
- **训练目标**：主目标为 LLM 自回归生成目标 `L_gen`，加上权重 `λ_nnc` 的辅助非中性分类损失。

### 3. 实验设计：数据集、基准与对比方法

- **数据集**：四个公开基准
  - 英文：CMU-MOSI、CMU-MOSEI
  - 中文：CH-SIMS、CH-SIMS-V2
- **评价指标**：
  - MOSI/MOSEI：Acc-2、F1、Acc-7、MAE

- **对比方法**：

### 6. 论文的主要结论与发现

- MGSI 在四个公开基准上**一致且显著地优于冻结 LLM 直接提示式基线**，尤其对 ChatGLM3-6B 提升巨大（MOSI 上 Acc-2 提升 25.88，MOSEI 提升 27.46，SIMS 提升 6.74，SIMS-V2 提升 10.06；同时 MAE 显著下降）。
- 与 MSE-Adapter 相比，MGSI 在多数指标上取得更好或相当的成绩，表明性能增益不仅来自 adapter 机制，还来自**多粒度时间编码**和 **LLM 前精炼**。
- 消融实验表明：各核心模块（MGT、NNC、ASC）和三个时间分支均贡献互补效果，**没有任何单一模块是唯一决定性因素**。
- 不同时间分支在不同数据集上各有侧重（如 MOSI 上中期分支重要，SIMS 上长期分支对 F1/MAE 影响大），验证了多粒度设计的必要性。
- 敏感性分析显示，最佳局部感受野和融合策略存在**数据集依赖**，但注意力融合整体稳健；`λ_nnc` 需取适中值，否则过强会损害细粒度强度建模。

### 7. 优点

- **方法动机清晰**：精准指出 LLM 基 MSA 的关键问题——非文本信号的时间结构在压缩到 LLM 之前已被破坏，并据此设计解决方案。
- **轻量高效**：仅用 4 个伪标记替代长非文本序列，显著降低 LLM 注意力开销，保持效率的同时保留多尺度信息。
- **模块化设计**：MGT、TGA、NNC、ASC 等组件可独立替换或移除，便于分析和扩展。
- **多尺度信息保留**：结合卷积、膨胀卷积和 Transformer，覆盖短/中/长三种时间范围，消融证明每个尺度都有必要。
- **辅助监督与校准**：非中性分类器增强极性判别，自适应校准器处理近中性样本，提升了模糊样本的鲁棒性。
- **实验覆盖充分**：四个数据集（中英文），两个 LLM 骨干，多种主流基线，并做了消融和敏感性分析，结论可信度较高。

### 8. 不足与局限

- **依赖预提取特征**：框架使用预先提取的音频/视觉特征，而非端到端原始信号编码器，可能损失底层信息，且无法针对特定任务优化特征提取。
- **伪标记数量固定**：M 固定为 4，未实现自适应 token 分配；对于长序列或高表达性输入，效率-保真度权衡可能恶化。
- **标准差缺失**：报告了 3 个种子的均值，但未给出标准差，难以评估结果稳定性。
- **部分对比方法未复现**：DEVA、MFON 等仅做概念性比较，缺少在相同特征和分割下的严格对照。
