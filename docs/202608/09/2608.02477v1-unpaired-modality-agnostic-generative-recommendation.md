## 摘要
生成式推荐（GR）将推荐表述为对离散语义标识符（ID）的自回归生成。尽管最近的多模态GR方法利用视觉和文本信息改进了语义ID的构建，但它们通常需要条目级别的配对观察，将分词限制在模态可用性的交集上。此外，整合未配对的观察结果并非易事，因为微小的表示偏移可能会跨越量化边界，产生不兼容的标识符序列。为了解决这一挑战，我们提出了未配对模态无关生成式推荐（UnpairGR），它从配对、纯图像和纯文本观察中学习统一的语义ID空间。UnpairGR将特定于模态的处理限制在轻量级输入投影中，同时在所有观察条件下共享后续的Transformer和残差码本。配对观察建立可靠性引导的跨模态共识，而单模态观察直接优化相同的表示和编码。然后固定学习到的分词器，为单一自回归推荐器提供稳定的目标，无需特征插补、特定模态码本或回退映射。在三个基准数据集上的大量实验表明，UnpairGR在完全观察和不完整观察设置下均能持续提高推荐性能。

## Abstract
Generative Recommendation (GR) formulates recommendation as autoregressive generation over discrete semantic identifiers (IDs). Although recent multimodal GR methods improve semantic ID construction with visual and textual information, they typically require item-level paired observations, restricting tokenization to the intersection of modality availability. Moreover, incorporating unpaired observations is nontrivial because small representation shifts may cross quantization boundaries and produce incompatible identifier sequences. To address this challenge, we propose \textbf{Unpair}ed Modality-Agnostic \textbf{G}enerative \textbf{R}ecommendation (UnpairGR), which learns a unified semantic-ID space from paired, image-only, and text-only observations. UnpairGR confines modality-specific processing to lightweight input projections while sharing the subsequent Transformer and residual codebooks across all observation conditions. Paired observations establish a reliability-guided cross-modal consensus, whereas unimodal observations directly refine the same representations and codes. The learned tokenizer is then fixed to provide stationary targets for a single autoregressive recommender, without feature imputation, modality-specific codebooks, or fallback mappings. Extensive experiments on three benchmark datasets demonstrate that UnpairGR consistently improves recommendation performance under both fully observed and incomplete-observation settings.

## 1. 核心问题与整体含义

### 研究动机与背景

- **生成式推荐（Generative Recommendation, GR）** 将推荐任务转化为对离散语义标识符（Semantic IDs）的自回归生成：每个物品由一个语义ID序列表示，推荐器从用户历史交互中生成下一个物品的语义ID。
- **多模态信息的重要性**：图像提供外观级线索，文本提供描述性语义，二者互补，可构建更富有表达力的语义ID，提升推荐质量。
- **现有多模态GR方法的瓶颈**：主流方法（如 SynGR、MACRec 等）**强依赖物品级别的图文配对数据**，即同一物品必须同时具有可靠的图像和文本。然而在实际推荐系统中：
  - 图像和文本往往来自不同运营管线（如图像由卖家上传、文本由目录管理维护）；
  - 两条管线可独立更新，导致覆盖程度不均衡——部分物品有图无文、部分有文无图；
  - 目录演化还需要持续过滤与同步，维护干净的配对数据成本极高。
- **关键矛盾**：大量**有用但未配对**的图像和文本在现有框架下无法参与语义ID学习，造成信息浪费。
- **技术难点**：GR 的最终监督施加在**离散ID**上，而非连续嵌入。量化过程对表示扰动高度敏感——连续空间中微小的表示偏移可能跨越量化边界，导致语义ID序列不兼容。因此，未配对数据不能简单地通过独立对齐模块纳入，必须与配对数据**共享同一个离散词汇表**。

### 核心问题

> **能否让多模态 GR 直接从未配对的视觉和文本数据中学习富有表达力的语义ID？**

## 2. 论文提出的方法论

### 核心思想

UnpairGR 的核心原则是：**模态特定处理被限制在轻量输入投影中，而后续的 Transformer 转换和残差码本在所有观察条件（配对、纯图像、纯文本）之间完全共享**。这样，配对观察建立跨模态共识，单模态观察直接优化相同的表示和码本，最终所有观察类型都被映射到**同一个语义ID空间**中。

### 总体架构（两阶段）

- **第一阶段：模态无关物品量化（Tokenization）**——学习统一的语义ID空间；
- **第二阶段：自回归推荐器训练**——冻结tokenizer后，在固定语义ID上训练推荐器。

### 关键模块与技术细节

**（1）Modality-Agnostic Item Quantization（模态无关物品量化）**

- **轻量投影 + 共享 Transformer**：
  - 使用冻结的模态编码器（如 CLIP 等）提取视觉特征 \(h^v_i\) 和文本特征 \(h^t_i\)，保持模态分布稳定；
  - 每个模态经轻量投影 \(P_m\) 映射后，由**共享 Transformer** \(\Phi_\theta\) 处理：\( r^m_i = \Phi_\theta(P_m(h^m_i)) \)，\(m \in \{v, t\}\)；
  - 图像和文本的差异由投影层吸收，语义变换由共享Transformer完成——这使得单模态数据可直接更新同一组参数。

**（2）Cross-Modal Semantic Consensus（跨模态语义共识）**

- 配对物品的视觉和文本表示可能可靠性不同，直接平均易被模糊模态干扰；
- 提出**基于量化空间中分配不确定性的模态可靠性估计**：
  - 计算软分配 \(p^{(ℓ)}_{i,m}(k)\)（基于到码本向量的距离的 softmax，温度 τ）；  
  - 由平均归一化熵定义置信度 \(κ^m_i = 1 − \frac{1}{L} \sum_{\ell=1}^L \frac{H(p^{(ℓ)}_{i,m})}{\log K}\)（熵越低越可靠）；
  - 归一化得到权重 \(a^m_i = (κ^m_i + ε)/(κ^v_i + κ^t_i + 2ε)\)；
  - 融合表示为 \( r^p_i = a^v_i r^v_i + a^t_i r^t_i \)。
- 单模态物品直接使用可用表示，不进行融合。

**（3）Modality-Shared Residual Quantization（模态共享残差量化）**

- 所有观察类型共享同一组 L 级残差码本 \(\{C^{(ℓ)}\}_{\ell=1}^L\)，每级 K 个码；
- 残差量化过程：\( s^{(ℓ)}_{i,o} = \arg\min_k \| w^{(ℓ−1)}_{i,o} − e^{(ℓ)}_k \|_2^2\)，\( w^{(ℓ)}_{i,o} = w^{(ℓ−1)}_{i,o} − e^{(ℓ)}_{s^{(ℓ)}_{i,o}}\)；
- 每个物品的语义ID为 \( s_{i,o} = (s^1_{i,o}, \dots, s^L_{i,o}) \)，量化表示为各层码字之和；
- 共享码本使未配对数据精炼的正是配对数据使用的同一套码字，产生粗细粒度兼容的ID。

**（4）混合监督量化（Mixed-Supervision Quantization）**

- 配对物品重建两种模态，单模态物品只重建观察到的模态；
- 使用**直通估计器**（straight-through estimator）处理量化不可导问题；
- 总体损失：
  \[
  \mathcal{L}_{\text{mix}} = \sum_{o \in \{p,v,t\}} \mathbb{E}_{i \sim \mathcal{D}_o} [\ell_{\text{RQ}}(r^i_o) + R^i_o]
  \]
  其中 \(R^i_o\) 是模态重建损失；
- 从各数据子集均衡采样，防止某一观察类型主导码字分配。

**（5）跨观察语义正则化（Cross-Observation Semantic Regularization）**

- **量化前**：\( \mathcal{L}_{\text{align}} = \mathbb{E}_{i \sim \mathcal{D}_p} \lVert r^v_i − r^t_i \rVert_2^2 \)，拉近配对物品的视觉和文本表示；
- **量化后**：通过 Jensen–Shannon 散度约束配对共识分配与各模态分配的一致性：
  \[
  \mathcal{L}_{\text{cons}} = \mathbb{E}_{i \sim \mathcal{D}_p} \left[ \frac{1}{L} \sum_{\ell=1}^L \omega_\ell \Delta^{(\ell)}_i \right]
  \]
  其中 ωℓ 强调早期残差层的粗粒度语义在兼容性中的重要性。

**（6）均衡码分配（Balanced Code Allocation）**

- 防止码本崩溃：\( \mathcal{L}_{\text{use}} = \frac{1}{L} \sum_{\ell=1}^L \text{KL}(\bar{p}^{(\ell)} \| u_K) \)，鼓励码本广泛覆盖。

**（7）完整训练目标**

\[
\mathcal{L}_{\text{tok}} = \mathcal{L}_{\text{mix}} + \lambda \mathcal{L}_{\text{align}} + \eta \mathcal{L}_{\text{cons}} + \xi \mathcal{L}_{\text{use}}
\]

**（8）语义ID生成与推荐**

- Tokenizer 训练完后冻结，所有物品按观察条件（配对→共识表示，单模态→对应表示）取得语义ID；
- 对任意用户，历史交互序列由已交互物品的语义ID拼接而成，推荐器通过自回归最大化目标ID的似然进行训练：
  \[
  \mathcal{L}_{\text{rec}} = -\sum_{\ell=1}^L \log P_\psi(y_\ell | y_{<\ell}, x_u)
  \]
- 推理时，根据可用内容选择分词路线，所有路线共享同一 Transformer 和码本，**无需特征插补、模态特定码本或回退映射**；使用受限束搜索生成合法ID并检索物品。

## 6. 论文的主要结论与发现

1. **未配对数据可有效服务于多模态生成式推荐**：UnpairGR 从配对+纯图像+纯文本数据中统一学习语义ID，突破了配对瓶颈；
2. **完整输入下全面最优**：UnpairGR 在所有数据集和指标上超越最强基线 SynGR，HR@1 提升最高达 22.86%（Arts），NDCG@5 最高提升 16.17%（Instruments）；
3. **缺失模态下鲁棒性显著**：特别是在 100% 单模态缺失的极端条件下，UnpairGR 仍保持较高性能（如表 2 中 Games 的 Random 缺失 50% 条件下较 SynGR 提升 31.48%），说明纯图像或纯文本ID与共享tokenizer和推荐器保持兼容；
4. **跨观察ID高度一致**：文本-only 和图像-only ID 与配对参考ID的前缀匹配率（P1）分别高达约 0.875 和 0.867（All 数据集均值），归一化汉明距离显著低于随机置换，说明共享粗粒度语义、差异主要在细粒度尾部码；
5. **单模态冷启动可行**：确定性单模态掩蔽下的 Cold-R50 和 Cold-R90 路线均一致优于 Pure 路线，表明单模态语义ID无需特征插补即可直接支持推荐；
6. **共享 Transformer 是最关键的组件**：移除它导致 HR@10 从 0.1477 降至 0.1170，说明量化前的共享语义变换对兼容ID的产生至关重要；共享码本和未配对监督也各自贡献显著；
7. **效率优势明显**：共享架构在训练和推理上均优于现有方法，且收敛更快。

- **基线对比不完整**：缺失模态鲁棒性实验中仅与 3 种多模态生成式基线对比，未纳入其他处理模态缺失的代表性方法（如基于特征插补或辅助学习的模型），可能低估了竞争方法的优势。
- **模态缺失设置偏理想化**：训练与测试的缺失模式被设计为完全匹配，但现实中的缺失模式往往动态变化且存在分布漂移；文中未验证“训练无缺失、测试有缺失”或“训练有缺失、测试无缺失”等更常见的不匹配场景。
- **冷启动模拟过于简化**：Cold-R50/R90 采用确定性掩蔽目标物品的方式模拟单模态冷启动，与真实系统中“新物品在交互历史中从未出现”的冷启动机制存在差距，且未考虑时间动态和语义ID漂移问题。
- **语义ID的长期稳定性未被评估**：未讨论新物品加入、目录更新或模态内容变化时，已学习的语义ID码本是否需要重训、更新是否会破坏既有推荐器的兼容性。
- **可解释性与可控性不足**：语义ID的离散码字缺乏语义可解释性分析，未展示码字与用户偏好或物品属性之间的对应关系；也未探讨如何通过干预码字实现可控推荐。
- **对模态编码器的依赖较强**：使用冻结的 CLIP 等预训练编码器，其本身的偏差（如对文本拼写、图像风格敏感）会传入后续模块；文中未分析所选编码器对最终结果的影响，也未对比不同编码器下的稳定性。
- **关键超参数敏感度未充分报告**：可靠性融合的 ε、温度 τ、损失权重 λ/η/ξ 等仅给出最终取值，缺乏敏感性分析，使读者难以评估方法在不同设定下的稳健性。

## 9. 个人总体评价

UnpairGR 针对多模态生成式推荐中一个真实且棘手的问题——未配对模态数据的利用——提出了统一且优雅的解决方案。其核心贡献不在于引入复杂模块，而在于重新思考了模态信息在语义ID学习中的角色：将模态差异收敛到轻量投影，让共享 Transformer、共享残差码本承担跨模态语义泛化的重任。这一设计使配对数据与未配对数据自然同构，消除了对特征插补或回退映射的需求，具有较高的实用价值。

论文的实验设计较为周密，从推荐性能、鲁棒性、ID一致性、冷启动、消融到效率，形成多角度证据链，尤其对语义ID跨观察一致性的诊断直接揭示了方法有效的机理，体现了作者对问题本质的深刻理解。同时，共享架构带来的训练/推理加速也是一项额外亮点。

不过，该方法仍有明显的验证局限：数据集规模较小、领域单一，且实验设置过于理想化（训练–测试缺失模式完全匹配），距离真实推荐系统的严苛条件尚有距离。此外，对预训练编码器的强依赖和缺乏对编码器影响的敏感性分析，也使其在工业落地时面临不确定因素。总体而言，这是一篇思想清晰、方案务实、实验扎实的研究，对多模态生成式推荐的发展具有较好的启发意义，但其通用性和长期稳定性仍需在更广泛的场景中检验。

## 10. 一句话总结

UnpairGR 通过“模态差异留在投影、语义共识共享全局”的架构，让未配对的图像和文本也能生成统一、兼容的语义ID，在不牺牲完整输入性能的前提下显著提升了多模态生成式推荐对缺失模态数据的鲁棒性与效率。
