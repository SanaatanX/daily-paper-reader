## 摘要
视觉-语言模型（VLMs）在处理高分辨率图像时面临关键的计算瓶颈，原因在于Softmax多头注意力（MHA）的$O(N^2)$内存复杂度。虽然用独立的多层感知机（MLP）替代MHA可实现$O(N)$缩放，但这会剥离架构的空间序列路由能力，严重降低全局场景理解和对象持久性。在本文中，我们提出了线性多时间尺度保持（LIA-MTR）模块，一种内存高效的跨模态桥梁。通过将基于ELU的正特征映射与自适应写入门控和对数线性分布的循环衰减相结合，LIA-MTR在数学上将连续视觉序列压缩为有界记忆状态。理论分析证明该架构以严格的$O(N)$序列交互复杂度运行。实证方面，合成检索评估表明LIA-MTR能在16,000个token间无缝路由上下文，消除了朴素线性注意力典型的“中间丢失”退化。硬件基准测试揭示了无限上下文缩放能力，能在11.2 GB VRAM占用内原生处理262,144个视觉补丁，而标准MHA在16,384个补丁时即遭遇内存不足故障。此外，在665K个对话样本上进行指令微调后，LIA-MTR在MME基准上显著优于行业标准的MLP基线（71.00%对68.11%），这得益于对象持久性10%的绝对提升和更优的全局语义提取。这项工作为无限上下文的视觉-语言集成奠定了数学上严谨、计算上平坦的基础。

## Abstract
Vision-Language Models (VLMs) face a critical computational bottleneck when processing high-resolution imagery due to the $O(N^2)$ memory complexity of Softmax Multi-Head Attention (MHA). While substituting MHA with independent Multi-Layer Perceptrons (MLPs) achieves $O(N)$ scaling, it strips the architecture of spatial sequence routing, severely degrading global scene understanding and object permanence. In this paper, we propose the Linear Multi-Timescale Retention (LIA-MTR) module, a memory-efficient cross-modal bridge. By integrating an ELU-based positive feature mapping with adaptive write-gating and log-linearly distributed recurrent decays, LIA-MTR mathematically compresses continuous visual sequences into bounded memory states. Theoretical analysis proves the architecture operates with strict $O(N)$ sequence-interaction complexity. Empirically, synthetic retrieval evaluations demonstrate that LIA-MTR flawlessly routes context across 16,000 tokens, eliminating the "Lost in the Middle" degradation typical of naive linear attention. Hardware benchmarking reveals infinite-context scaling capabilities, natively processing 262,144 visual patches within an 11.2 GB VRAM footprint, whereas standard MHA suffers out-of-memory failure at 16,384 patches. Furthermore, following instruction tuning on 665K conversational samples, LIA-MTR significantly outperforms an industry-standard MLP baseline on the MME benchmark (71.00% vs. 68.11%), driven by a 10% absolute improvement in object permanence and superior global semantic extraction. This work establishes a mathematically rigorous, computationally flat foundation for infinite-context Vision-Language integration.

## 1. 核心问题与整体含义
- **研究背景**：视觉-语言模型（VLMs）依赖预训练视觉编码器（如 CLIP）与大型语言模型（如 Qwen）的跨模态对齐，跨模态桥接模块将视觉特征映射到文本空间。高分辨率图像、多图推理、连续视频等需求使视觉 token 序列长度 N 急剧增长。
- **核心矛盾**：
  - Softmax 多头注意力（MHA）具有全局语义路由能力，但计算密集的 N×N 矩阵导致 $O(N^2)$ 内存复杂度，在约 16K token 时即发生显存溢出（OOM）。
  - 简单的 MLP 桥接（如 LLaVA 所用）虽为 $O(N)$ 线性复杂度，但对每个视觉 patch 独立映射，没有序列/空间路由机制，导致全局场景理解下降和对象持久性（object permanence）减弱。
- **论文目标**：提出一种兼具线性内存复杂度和全局语义路由能力的跨模态桥接模块——Linear Multi-Timescale Retention（LIA-MTR），为无限上下文视觉-语言集成奠定基础。

## 2. 方法论
- **核心思想**：用“门控 + 固定大小循环记忆状态”替代二次复杂度的成对注意力，将连续视觉序列在数学上压缩为有界记忆表示，同时通过多个时间尺度保留局部细节与全局语义。
- **关键技术细节**：
  - 对每个视觉 token $x_t$ 计算查询、键、值投影：$q_t=W_q x_t$, $k_t=\varphi(W_k x_t)$, $v_t=W_v x_t$，其中 $\varphi(z)=ELU(z)+1$ 保证键的非负性，避免递归累加时分母坍塌。
  - 引入自适应写门 $g_t=\sigma(W_g x_{conv}^T)$ 和尺度混合器 $\alpha_t=softmax(W_{mix} x_{conv}^T)$，由 2D 空间卷积驱动，用于控制信息写入并动态平衡不同记忆尺度。
  - 维护 S 个并行记忆状态，每个状态有固定衰减常数 $\lambda_s \in (0,1)$，更新公式：$M_{t,s}=\lambda_s M_{t-1,s}+u_t$，其中 $u_t=g_t \odot (k_t \odot v_t)$。
  - $\lambda_s$ 按对数线性分布在 $[0.70, 0.995]$ 区间，对应记忆半衰期从 1.94 步到 138.28 步，可同时建模短期空间细节和长期全局语义。
  - 输出通过对所有尺度状态进行 $\alpha_t$ 加权求和，再经最终投影：$o_t = q_t \odot \sum_s \alpha_{t,s}\odot M_{t,s}$，$y_t=W_o o_t$。
- **理论保证**：
  - 定理 1：序列交互复杂度为严格 $O(N)$（固定维度 $d$ 和尺度数 $S$）。
  - 引理 1：记忆状态可展开为几何加权历史注入之和。
  - 定理 2：状态范数有界，随 $t\to\infty$ 几何收敛，数值稳定。
  - 引理 2：当 $S=1, \alpha=1, g=1$ 时退化为标准一阶线性注意力，说明 LIA-MTR 是广义线性注意力。

## 9. 总体评价

LIA-MTR 是一个理论动机清晰、实现相对轻量的跨模态桥接方案。它将线性注意力思想引入 VLM 的视觉-文本接口，在保持 $O(N)$ 内存复杂度的同时，通过多时间尺度递归记忆恢复了全局语义路由能力，解决了 MLP 桥接“无状态”与 Softmax 注意力“高开销”之间的两难问题。论文的核心贡献在于提出了一种可落地的替代桥接模块，并在显存扩展性和单 benchmark 上展示了明显优势。

然而，其论证强度受限于实验覆盖面和消融深度。目前证据链“理论可行 → 合成检索完美 → MME 提升”并不足以支撑其作为通用 VLM 桥接模块的广泛适用性。Spatial Positioning 的显著下降也提醒我们，压缩式记忆并非没有代价。整体而言，这是一篇**工程可借鉴、理论有依据、但验证仍偏初步**的工作，其最终价值取决于后续能否在多 benchmark、多模态任务及更复杂训练条件下保持优势。

## 10. 可复现性与实践建议

- 若需复现，应重点检查写门卷积核的设计、$\lambda_s$ 对数线性分布的区间选择，以及 Phase 2 中桥接模块与 LLM 联合训练时的学习率设置。

- 对实际应用而言，LIA-MTR 在显存受限、需要超长视觉上下文的场景（如高分辨率文档理解、长视频摘要）中尤其有吸引力，但若任务强依赖精确空间定位，需谨慎评估其压缩带来的精度损失。
