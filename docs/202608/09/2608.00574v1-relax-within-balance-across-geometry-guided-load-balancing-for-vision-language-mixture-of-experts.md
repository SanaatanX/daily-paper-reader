## 摘要
视觉-语言混合专家（MoE）批次包含不同数量的图像和文本令牌。图像分辨率、图像数量、分块和提示长度都会改变这种令牌混合。我们将标准令牌级Switch辅助损失称为Std-Aux。Std-Aux仅平衡混合负载，因此较大的图像和文本负载误差可能在某次混合中相互抵消。在我们主模型上，相同训练后的路由器在不同图像分辨率下的负载不平衡度变化超过五倍。我们固定图像和文本负载分布，并推导出负载随令牌混合变化的精确曲线。图像-文本负载差距控制了对令牌混合的敏感性。物理预处理也可能改变条件分布，而固定分布规律不包含此类变化。为设计解决方案，我们检查了路由器输入结构。图像和文本占据不同区域，而视觉令牌按源图像强分组。模态边界促使将图像和文本项分开，图像边界则促使每幅图像使用一个等权重路由实例。ReBA（Relax Within, Balance Across）实现了这两种选择。在四个拆分骨干网络上，ReBA降低了所有报告的基准输入的负载，同时保持平均任务准确率与Std-Aux相当。ReBA还降低了测试范围内的平均负载，以及在分辨率和分块变化下的最差物理负载。代码见https://github.com/ZiangWu-77/ReBA。

## Abstract
Vision-language MoE batches contain different numbers of image and text tokens. Image resolution, image count, tiling, and prompt length all change this token mix. We call the standard token-level Switch auxiliary loss Std-Aux. Std-Aux balances only the mixed load, so large image and text load errors can cancel at one mix. On our main model, the same trained router shows more than a fivefold change in load imbalance across image resolutions. We hold the image and text load profiles fixed and derive the exact load curve as the token mix varies. The image-text load gap controls sensitivity to the token mix. Physical preprocessing can also change the conditional profiles. The fixed-profile law excludes such changes. To design a remedy, we examine the router input structure. Image and text occupy distinct regions, while visual tokens group strongly by source image. The modality boundary motivates separate image and text terms. The image boundary motivates one equal-weight routing instance per image. ReBA, or Relax Within, Balance Across, implements both choices. Across four split backbones, ReBA lowers load on every reported benchmark input while keeping mean task accuracy comparable to Std-Aux. ReBA also lowers average load over the tested range and worst physical load under resolution and tiling shifts. Code is available at https://github.com/ZiangWu-77/ReBA.

## 1. 核心问题与整体含义（研究动机和背景）

视觉-语言混合专家（Vision-Language Mixture-of-Experts, MoE）模型在设计上面临一项特殊挑战：推理批次中图像与文本 token 的数量比例高度动态变化——图像分辨率、图像数量、分块（tiling）、以及提示词长度都会显著改变这一比例。然而，当前广泛采用的负载均衡方法，即标准 token 级 Switch 辅助损失（简称 **Std-Aux**），仅针对“混合负载”（即图像和文本 token 合在一起时的专家负载）进行约束。这带来一个隐蔽而严重的问题：

- **图像负载与文本负载各自的误差可以在混合负载中相互抵消**。即使整体混合负载看似接近均衡，图像和文本各自的专家负载可能高度不平衡，且误差方向相反。
- 当 token 混合比例（图像 token 占比 $a$）发生变化时，两者误差的相对权重也随之改变，原有的抵消关系被打破，导致负载不均衡度急剧上升。
- 实验显示，在同一个训练完成的路由器上，仅改变图像分辨率，负载不均衡度（RMS-CV）的变化可超过 **5倍**。

论文的核心论点是：**“在单一 token 比例下达到平衡，并不意味着在跨 token 比例下仍然平衡”**。这一发现揭示了一个更深层的问题——MoE 路由器学到的是一种“比例相关的平衡点”，而非真正稳健、跨构成一致的负载均衡。

为解决这一问题，论文通过分析路由器输入（router input）的空间几何结构，提出了一个全新的负载均衡方法 **ReBA（Relax Within, Balance Across，内部放松，跨域平衡）**，该方法将负载均衡目标从“混合负载”解耦为“分模态、分图像”的细粒度目标，从而实现对 token 比例变化的鲁棒性。

## 2. 论文提出的方法论

### 2.1 核心思想

ReBA 的设计基于对路由器输入几何结构的两个关键观察：

1. **模态边界清晰**：图像 token 与文本 token 在路由器输入空间中占据明显分离的区域，因此任何线性路由器都很容易学会将两类 token 送往不同专家，从而产生模态偏好。
2. **图像边界分明**：同一幅图像内的视觉 token 在路由器输入空间内聚成一个紧密的簇，而不同图像之间存在可测量的间距。因此，图像是比“单个 token”更合适的路由统计单元。

基于这两条边界，ReBA 采取两项设计决策：

- **按模态分离负载均衡目标**：分别计算图像负载项与文本负载项，各自独立约束，避免模态间误差相互隐藏。
- **图像级路由实例**：每张图像作为一个等权重的路由实例参与负载均衡统计，而不是将图像内所有 token 视为独立个体。这样可避免相关 patch 的重复影响，并更好地保留图像间差异。

### 2.2 关键技术细节

**问题形式化。** 对于每个 MoE 层，设 $\mathbf{q}_I$ 和 $\mathbf{q}_T$ 分别为图像和文本的归一化专家负载分布，$a$ 为图像 token 占比，则混合负载为：

$$
\mathbf{q}(a) = a\mathbf{q}_I + (1-a)\mathbf{q}_T
$$

若某一参考比例 $a_0$ 处混合负载恰为均匀分布 $\mathbf{u}$，则：

$$
\mathbf{q}(a) - \mathbf{u} = (a-a_0)(\mathbf{q}_I - \mathbf{q}_T)
$$

该公式揭示了一个关键结论：**负载随 token 占比偏离的程度，正比于图像-文本条件负载差向量 $\mathbf{q}_I - \mathbf{q}_T$ 的大小**。条件负载差越小，负载曲线越平坦；条件负载差越大，低负载区间越狭窄。

进一步的推导给出固定轮廓下负载曲线的解析形式：

$$
R(a) = R(a^\star) + \kappa (a - a^\star)^2, \quad \kappa = \frac{N}{L}\sum_l \|\mathbf{q}_{I,l} - \mathbf{q}_{T,l}\|_2^2
$$

其中 $\kappa$ 为曲率，由图像-文本负载差距直接控制。ReBA 的核心目标即是**降低 $\kappa$**。

**ReBA 目标函数。** 设某路由实例 $m$ 包含 $S_m$ 个 token，其软/硬路由轮廓为：

$$
P_{m,i} = \frac{1}{S_m}\sum_{t\in m} p_{t,i}, \quad F_{m,i} = \frac{1}{S_m}\sum_{t\in m} f_{t,i}
$$

则等实例平均为：

$$
\bar{P}_i = \frac{1}{|\mathcal{M}|}\sum_{m\in\mathcal{M}}P_{m,i}, \quad \bar{F}_i = \frac{1}{|\mathcal{M}|}\sum_{m\in\mathcal{M}}F_{m,i}
$$

实例级平衡损失为：

$$
\mathcal{L}_{\text{inst}}(\mathcal{M}) = N \sum_{i=1}^N \bar{F}_i \bar{P}_i
$$

完整目标为：

$$
\mathcal{L}_{\text{ReBA}} = \lambda_{\text{img}}\,\mathcal{L}_{\text{inst}}(\mathcal{M}_{\text{img}}) + \lambda_{\text{text}}\,\mathcal{L}_{\text{inst}}(\mathcal{M}_{\text{text}})
$$

其中 $\mathcal{M}_{\text{img}}$ 是每张图像一个实例的集合，$\mathcal{M}_{\text{text}}$ 是文本合并为一个池化实例，$\lambda_{\text{img}}$、$\lambda_{\text{text}}$ 取真实的图像/文本 token 比例作为权重。

### 2.3 算法流程概要

1. 对于每个模态 $r \in \{I, T\}$：
   - 在模态内每个路由实例中计算软/硬负载轮廓；
   - 对实例做等权平均；
   - 计算实例级平衡损失 $\mathcal{L}_r$；
2. 将图像与文本的实例级损失按 token 比例加权相加，得 $\mathcal{L}_{\text{ReBA}}$。

该方法不引入新的路由器或专家参数，仅改变统计分组方式，额外开销为 $O(|\mathcal{M}|N)$ 每层，远小于专家 FFN 的计算成本。

## 3. 实验设计

### 3.1 骨干模型与数据集

论文以四个拆分（split）MoE 骨干为核心实验平台：

- **Split-Qwen3VL-4B**（主模型）
- Split-Qwen2.5VL-3B
- Split-Qwen2VL-7B
- Split-InternVL3-8B

以上模型由对应的稠密视觉-语言模型通过不相交 FFN 参数切分转换而来，保持原有参数预算。训练数据使用 **Cambrian-737K** 微调一个 epoch。原生发布的 MoE（Qwen3-VL-MoE-30B、Qwen3.5-MoE-35B）仅用于路由诊断，不参与 ReBA 训练。

### 3.2 评测基准

任务精度与负载评测在7个标准多模态基准上进行：POPE、HallusionBench、MME、MMBench、MMStar、SEEDBench、ScienceQA。负载指标为主要指标，平均任务精度用于对照。

### 3.3 对比方法

- **No-Aux**：移除负载均衡损失，仅保留任务训练；
- **Std-Aux**：标准 token 级 Switch 辅助损失；
- **Coupled-ImgInst**：每图像一个轮廓，但仍为单一混合图像-文本损失；
- **Coupled-SymInst**：每图像一个轮廓 + 每文本行一个轮廓，仍用混合损失；
- **Decoupled-Matched**：分离图像/文本损失 + 每图像轮廓 + 池化文本，但权重与 Coupled-ImgInst 匹配；
- **ReBA-TextInst**：ReBA 但文本用每行一个实例；
- **ReBA（完整版）**：分离损失 + 每图像轮廓 + 池化文本 + token 比例权重。

### 3.4 实验场景

1. **固定加载探针**：500 个采样请求，固定像素预算，评估所有方法。
2. **分辨率扫描**：Split-Qwen3VL-4B 上 5 档像素预算。
3. **分块扫描**：Split-InternVL3-8B 上 1、3、6、12 块。
4. **原生 MoE 诊断**：Qwen3-VL-30B 和 Qwen3.5-35B 上低/源/高分辨率扫描。

### 3.5 负载指标

- 层 CV、平均层 CV、RMS-CV；
- 图像-文本条件负载差 $\mathcal{G}_1$；
- 图像内 CV、图像间轮廓占比 $\rho^2$；
- 曲率 $\kappa$、AUC、最差/范围等。

**局限性：**

- 训练仅在单一数据集（Cambrian-737K）上微调一个 epoch，缺少多种数据规模/多轮训练验证；
- 未在原生稀疏 MoE 上端到端训练 ReBA（仅以拆分模型训练、原生模型做诊断性验证）；
- 精度比较缺乏一致性增益，结果有增有减，仅声称“相当”；
- 实验时间范围为 2026 年，部分对比模型（如 ReaLB、MACS）较新，缺少更早版本的对比；
- 未报告 AUC 的置信区间。

## 6. 论文的主要结论与发现

1. **标准 Switch 辅助损失存在“模态互补抵消”陷阱**：Std-Aux 训练出的路由器可以形成方向相反、数值较大的图像和文本条件负载误差。在某个 token 占比下混合负载看似均衡，但实际条件负载高度失衡（图像-文本平均相关性为 -0.949，平均 L1 差距为 0.798）。
2. **负载失衡对 token 占比变化高度敏感**：在 Split-Qwen3VL-4B 上，固定轮廓预测曲线显示标准方法仅在极窄的 token 占比区间内保持低负载，占比偏离时 RMS-CV 迅速上升，幅度可超 5 倍。
3. **路由器输入几何边界可用于指导负载均衡设计**：模态边界驱动图像/文本分离项；图像边界驱动每图像等权重的路由实例。二者共同构成 ReBA。
4. **ReBA 显著降低条件负载差距**：平均图像-文本相关性从 -0.949 回升至 -0.166，L1 差距从 0.798 降至 0.137，曲率 $\kappa$ 下降 96.3%。
5. **ReBA 广泛降低负载且精度相当**：在 4 个骨干 × 7 个基准的全部组合上，平均层 CV 均低于 Std-Aux；平均任务精度差异在 -0.2 到 +0.6 之间，整体相当。
6. **ReBA 对物理预处理变化更为鲁棒**：在分辨率扫描和分块扫描下，平均负载和最差负载均低于 Std-Aux（在 Qwen 高分辨率档位，RMS-CV 从 0.351 降至 0.115）。
7. **原生 MoE 同样存在条件负载差距**：Qwen3-VL-30B 和 Qwen3.5-35B 的条件负载差距、模态偏好、固定轮廓曲线均验证了诊断的有效性，提示 ReBA 原则可扩展到更广泛的稀疏模型。

## 7. 优点

1. **问题诊断深入、视角独特**：论文不是简单提出一个新的负载均衡损失，而是深入揭示混合负载均衡的数学缺陷，并用精确的解析公式（公式 2、3）描述了 token 占比变化与负载变化的关系，具有很强的可解释性和可验证性。
2. **几何引导的设计思路**：基于路由器输入空间的实证几何测量来推导损失函数设计，而非凭经验调参。这种“先测量、后设计”的方法论值得借鉴。
3. **实验设计严谨**：区分了固定轮廓预测与物理运行、token 比例效应与条件轮廓变化效应、聚合负载与请求级尾部分布，并使用配对 bootstrap 置信区间。
4. **消融全面、回答明确**：逐步验证了图像实例、分离模态项、文本实例、权重设置等各项设计选择的必要性，结论清晰。
5. **系统/硬件视角的度量**：引入专家并行计算代理，将负载降低与潜在的端到端加速联系起来，尽管是理想化代理，但框架合理。
6. **开源与代码可复现**：提供 GitHub 代码仓库。
7. **跨模型验证**：4 个拆分骨干 + 2 个原生 MoE 的诊断，增强结论泛化性。

## 8. 不足与局限

1. **资源报告不完整**：未给出精确的 GPU 数量、总算力消耗和端到端

端到端训练时长，这对于评估方法的工程成本（特别是在 MoE 场景下）至关重要。

2. **训练数据单一**：所有 ReBA 训练均基于 Cambrian-737K 微调一个 epoch，未在更大规模、更多样化的数据混合上进行验证。负载均衡行为是否随数据规模扩大而保持优势仍未知。

3. **原生 MoE 上缺乏端到端训练验证**：论文仅在拆分（split）模型上训练 ReBA，原生稀疏 MoE（Qwen3-VL-30B、Qwen3.5-35B）仅用于诊断验证。由于原生素材模型通常在数十亿至数千亿 token 上训练，ReBA 在真实大规模稀疏训练中的表现仍缺少直接证据。

4. **任务精度收益不显著**：虽然 ReBA 在负载均衡上大幅优于 Std-Aux，但在任务精度上仅达到“相当”水平，甚至在某些基准上有小幅下降（-0.2 到 +0.6 之间）。论文未展示 ReBA 在精度上有系统性提升，这削弱了“负载均衡改进必然带来端到端收益”的叙事强度。

5. **未报告关键指标的置信区间**：虽然论文使用了配对 bootstrap，但主表格中未给所有 RMS-CV 和曲率的置信区间，部分结论的统计显著性不完全透明。

6. **计算代理模型过于理想化**：专家计算代理假设推测性执行完美、通信无成本，实际硬件上的加速比较可能与理论代理差距较大。

7. **文本实例采用简单池化**：文本所有 token 合并为一个实例，论文自述“文本方向采用池化是合理但粗略的”，未能体现文本内部（如不同提示词、不同搜索段落）的负载差异，跨文本的负载失衡可能仍然存在。

8. **对极端比例的处理讨论有限**：尽管分辨率扫描覆盖 5 档，但未覆盖极端低图像占比（如纯文本推理）或全图像推理的无图像设置，这些场景对路由器的鲁棒性要求更高。

9. **与最新方法的对比不完整**：对比基线和相关工作中提及了 ReaLB、MACS 等方法，但实验部分未与这些方法进行直接比较，缺少相对竞争力证据。

## 9. 与已有工作的关系

论文在视觉-语言 MoE 的负载均衡方法中，与以下工作形成关键对比，其定位清晰：

| 方法         | 核心思路                         | ReBA 的差异或优势                       |
|--------------|----------------------------------|------------------------------------------|
| **Switch/Std-Aux** | token 级、混合模态单损失        | ReBA 分离图像和文本项，避免模态误差抵消   |
| **Coupled-ImgInst** | 图像级实例但仍是混合损失       | ReBA 解耦两个模态，消除模态间互相干扰     |
| **Coupled-SymInst** | 图像级 + 文本行级实例，混合损失 | ReBA 强调池化文本而非行级实例，减少细粒度噪音 |
| **ReaLB、MACS 等负载均衡方案** | 多为单模态或通用正则化         | ReBA 直接面向多模态 token 比例动态变化     |

论文明确将自己的工作定位为**首个系统研究“视觉-语言 MoE 在跨 token 比例下负载失衡”问题，并提出跨模态解耦解决方案**。这一角度与已有方法（主要关注单模态或静态混合比例下的均衡）存在实质差异。

## 10. 深度讨论

### 10.1 总体评述与核心贡献

这是一篇极具启发性的论文。它在视觉-语言 MoE 领域提出了一个以往被忽略的、带有根本性质的问题——**标准负载均衡对 token 比例的敏感性**。论文的价值不仅在于提出 ReBA 这一具体方法，更在于提供了一个可供后续工作复用的数学分析框架（公式 2、3 中负载误差随 Token 占比的二次型变化关系），以及一套细致的实验设计范式（固定轮廓预测与物理运行的对照，条件负载差 $\mathcal{G}_1$ 的度量）。

从工程实用角度看，ReBA 是一个“收益明确且零部署成本”的技巧：它不改变模型结构和参数，只修改训练阶段的损失统计方式。因此，即使某些任务精度未明显提升，仅从推理服务稳定性角度也足以证明方法的实用性——负载分布越稳定，批处理调度和显存分配的尾部风险越低。

### 10.2 方法的局限与可能的改进方向

1. **自适应模态权重**：目前权重取图像/文本 token 比例，这种设置合理但不一定最优。可在训练时将 $\lambda_{\text{img}}$、$\lambda_{\text{text}}$ 设为可学习或动态调整，例如根据当前批次的条件负载差距动态强化较弱模态的约束。
2. **扩展到更多模态**：当前框架仅包含图像和文本。若模型扩展到视频、音频等模态，ReBA 的分离项应自然拓展为多模态独立实例，可行但需验证多模态间的相互作用。
3. **文本侧的细粒度路由**：当前文本池化为一个大实例，掩盖了不同提示词间的负载差异。未来可将文本提示词按语义或任务类型分组，在保持稳定性的同时兼顾文本内部均衡。
4. **与感知型负载均衡结合**：ReBA 是训练期的损失项，可与推理期的动态负载均衡策略（如在线专家迁移、请求路由调整）结合，形成训练-推理双阶段优化。

### 10.3 可复现性与工程建议

- 论文公开代码仓库，有助于复现；
- 但建议作者补充完整的资源报告（GPU 数量、训练时间）和标准化的负载评估套件，便于社区横向比较不同方法；
- 对实践者而言，ReBA 可视为对现有 MoE 视觉-语言模型微调时的一种“低成本即插即用”改进：在现有损失函数上增加一个约 10 行代码的辅助损失项，即可显著增强跨分辨率、跨 prompt 分布的负载鲁棒性。

## 11. 对领域的影响

这篇论文对视觉-语言 MoE 领域的影响主要体现在三点：

1. **为负载均衡研究设立了新评估标准**：传统研究仅报告固定负载下的 CV；本文揭示仅看混合 CV 可能被“模态互补”所误导。未来的研究工作如果要在多模态 MoE 上验证负载均衡，必须报告条件负载差（模态分解后的 CV），否则结论可能不具备跨 token 比例的可靠性。

2. **推动了“比例变体”问题的关注**：论文揭示路由器对 token 混合比例的动态响应特性。训练后的 MoE 在纯文本、纯图像等不同部署场景下的行为差异，可能成为后续研究的重点，潜在影响模型发布规范（例如在模型卡中提供 token 比例敏感性报告）。

3. **为其他模态组合提供了模板**：视频-文本、音频-文本等同样存在多模态 token 比例变化的问题，本文的“分解模态、实例等权重”思路可以被直接推广。
