## 摘要
指称表达理解（REC）通常在特定数据集微调下进行研究，导致模型成为专家模型，跨数据集泛化能力有限。在这项工作中，我们从统一开放词汇定位的角度重新审视REC，并确定表示退化是扩展单一通用模型的关键障碍。为了保持表示多样性，我们提出了一个整体的数据-模型协同设计框架。在架构上，我们引入了调制注意力-对比头（mACH）以实现高效的词元级视觉-语言对齐，以及一个文本条件的JEPA辅助流，提供互补的梯度支持以保留对齐活跃的表示，且不增加推理开销。在数据方面，我们引入了Objects365-Caption，通过上下文感知的指称表达丰富Objects365，用于大规模语言监督。我们进一步提供了理论分析，表明互补的梯度子空间保留对齐能力，从而扩展表示多样性。大量实验表明，我们的单检查点框架在标准REC基准上取得了极具竞争力的性能，同时在异构定位数据集上表现出强大的泛化能力，无需针对特定基准进行调整。

## Abstract
Referring Expression Comprehension (REC) is commonly studied under dataset-specific fine-tuning, resulting in specialist models with limited cross-dataset generalization. In this work, we revisit REC from the perspective of unified open-vocabulary grounding and identify representation degeneration as a key obstacle to scaling a single generalist model. To preserve representation diversity, we propose a holistic data-model co-design framework. Architecturally, we introduce the Modulated Attention-Contrastive Head (mACH) for efficient token-level vision-language alignment and a text-conditioned JEPA auxiliary stream that provides complementary gradient support to preserve alignment-active representations without inference overhead. On the data side, we introduce Objects365-Caption, enriching Objects365 with context-aware referring expressions for large-scale language supervision. We further provide a theoretical analysis showing that complementary gradient subspaces preserve alignment capacity and thereby scale representation diversity. Extensive experiments demonstrate that our single-checkpoint framework achieves highly competitive performance on standard REC benchmarks while exhibiting strong generalization across heterogeneous grounding datasets without benchmark-specific adaptation.

## 1. 核心问题与研究动机

**研究背景**：指称表达理解（Referring Expression Comprehension, REC）旨在根据自然语言查询在图像中定位目标物体。现有方法分为三大范式：
- 文本条件空间回归方法（在骨干网络内反复融合语言与视觉特征，计算开销大）
- 区域-词点积对齐方法（将视觉区域与文本嵌入投影到共享空间，通过矩阵相似度实现并行定位，效率高）
- 自回归多模态大语言模型（MLLM）方法（推理能力强但延迟高）

**核心问题**：现有 REC 模型普遍采用"数据集特定微调"模式，导致模型成为专家模型，跨数据集泛化能力受限。论文指出，将区域-词点积对齐范式扩展到统一多数据集训练时面临两个根本瓶颈：
1. **模型级表示退化**：对比学习目标容易导致低秩多语义瓶颈（low-rank polysemantic bottleneck），使特征方差被压缩到低秩各向异性子空间，损害分布外泛化。
2. **数据级语言缺失**：大规模检测数据集（如 Objects365）仅含离散类别标签，缺乏丰富的自然语言描述。

**核心概念**：论文将"表示多样性"定义为学习到的视觉表示中保留的独立对齐活跃方向（alignment-active directions）的数量。不同训练目标只在共享视觉表示的不同子集上提供监督信号，扩展表示多样性需要互补的监督来逐步扩展对齐活跃子空间。作者明确提出的目标是：学习一个统一的定位模型，能泛化到异构的指称表达分布，而非针对单个基准优化。

## 2. 方法论

论文提出一个**数据-模型协同设计框架**，包含三大核心贡献：

### 2.1 调制注意力-对比头（mACH）

- **定位**：mACH 不是全新的注意力算子，而是标准交叉注意力的一种高效广播计算拓扑实现，适合统一开放词汇定位。
- **技术细节**：
  - 输入：视觉特征图 X ∈ R^{B×M×C}，文本嵌入 W ∈ R^{BNc×L×C}（Nc 为每张图的指称表达数）
  - 视觉特征沿 batch 维度广播，使每张图与每个指称表达配对：Q = Broadcast(X)
  - 通过缩放点积注意力进行跨模态交互：O = Softmax(QK^T/√C)V
  - 使用 FlashAttention-2 消除填充 token 的无效计算
  - 最终定位分数：S = ψ(O)·exp(τ) + b，通过二元交叉熵损失优化

### 2.2 JEPA 辅助流（文本条件）

- **核心思想**：以联合嵌入预测架构（JEPA）作为辅助正则化器，在训练时对共享视觉表示提供重建性监督，推理时完全移除该分支，不增加推理开销。
- **架构**：非对称在线-目标架构，包含学生投影头 Pθ 和 EMA 教师 PEMA（参数通过指数移动平均更新）。
- **关键创新**：与常规 I-JEPA 不同，预测器额外接收语言嵌入作为上下文引导，鼓励被掩码的视觉区域恢复与指称表达相关的语义：ẑ_Ω = F_φ(Z_masked, W_m)。
- **损失函数**：对归一化潜在特征计算余弦相似度和 SmoothL1 的组合。
- **总目标**：L_Total = L_mACH + α·L_JEPA

### 2.3 Objects365-Caption 数据集（O365-Caption）

- **定位**：将 Objects365 的离散类别标签升级为稠密、上下文感知的指称表达，共 638K 图像、960 万条描述。
- **构建流程**（三阶段自动生成管线）：
  1. **粗到细语义消歧**：用 Qwen3-VL-2B 将粗粒度类别标签细化为精确分类，并设置空间覆盖率阈值（γ < 0.05%）防止小目标幻觉。
  2. **上下文感知描述生成**：用 Qwen3-VL-32B 生成融合视觉属性与空间关系的描述性表达。
  3. **跨语言扩展**：通过机器翻译扩展多语言支持。
- **数据特征**：平均长度 4.2 词、597K 唯一短语、形容词占比提升至 22%，打破传统语料中"名词垄断"问题，遵循 Zipf 分布与 Heaps 定律，提供高熵语言变化以防止表示崩溃。

### 2.4 理论分析

论文提供了严格的数学框架来刻画表示多样性：
- **方向对齐能力**：cap(k) = Var_m(x_m^T k) = k^T Ξ_X k，其中 Ξ_X 为视觉 token 的协方差矩阵。
- **梯度子空间维度阶梯**（核心定理）：
  ```
  Nc（对比学习）< N - Nc（mACH）< C（mACH+JEPA）
  ```
  对比学习只监督池化表达子空间；mACH 扩展至中心化 token 子空间（softmax 不变性使每个表达去除一个共模方向）；JEPA 辅助目标在几乎所有方向上提供梯度支持。
- **结论**：只有双流目标几乎必然没有对齐盲方向，保持整个特征空间的表示多样性。

## 6. 主要结论与发现

1. **表示退化是可扩展统一定位模型的关键障碍**。理论分析和频谱实验一致表明，纯判别式目标会将表示约束在低维语言条件下空间（对比学习和 mACH 在约 j≈200 处出现频谱悬崖），而 JEPA 辅助目标能在全部 768 维中保持非消失的频谱尾部。

2. **数据-模型协同设计有效解决双重瓶颈**。O365-Caption 的语言丰富度（+8.3% 提升）和 JEPA 的正则化效果（+1.4% 提升）共同实现了零样本泛化能力的大幅提升。

3. **单检查点统一模型可以超越专家模型**。75M 参数的模型在零样本设置下与 13B/7B 的 MLLM 性能相当甚至更优（参数仅为其 0.6%），同时保持极低延迟（约 26ms/图）。

4. **互补梯度子空间是扩展表示多样性的有效原理**。有效秩从 36（对比学习）→ 44（mACH）→ 83（mACH+JEPA）的单调递增，验证了维度阶梯 Nc < N - Nc < C 的理论预测。

5. **架构无关性**。mACH 可无缝集成到 CNN 和 Transformer（RT-DETR）检测器中，且训练更长（90 轮）能持续提升性能，表明框架具有良好的扩展潜力。

## 7. 主要优点

1. **数据-模型协同设计**：不局限于单一维度的改进，而是同时从架构和数据两个层面解决表示退化问题，视角全面。
2. **理论框架严谨**：提供了从"方向对齐容量"定义到"梯度子空间维度阶梯"的完整数学推导（附录 B），并配套频谱实验验证，实现了理论-实验闭环。
3. **零推理开销**：JEPA 分支训练后完全移除，不增加推理延迟，实用价值高。
4. **高效的计算设计**：广播式 mACH 避免了对每个查询重复提取视觉特征；FlashAttention-2 进一步优化多查询效率；支持 CNN 与 Transformer 双架构。
5. **高质量的数据工程**：O365-Caption 构建管线包含三层质量保障（语义消歧、空间覆盖率阈值、后处理过滤），且人工验证错误率低于 0.1%。
6. **模型紧凑高效**：75M 参数规模远小于对比的 MLLM（7B/13B），适合资源受限设备部署。
7. **广泛适用性**：mACH 是架构无关的通用定位头，不依赖于特定视觉骨干。

## 8. 不足与局限

1. **理论覆盖面有限**（论文作者自述，附录 F）：理论分析刻画的是学习到的视觉特征表示性质而非端到端定位精度；未考虑优化动态、监督质量、分数校准等因素；梯度子空间维度分析基于特定假设（如 Nc < N/2、N - Nc < C），需要数据满足这些条件。

2. **校准问题未解决**（论文作者自述，附录 F）：双流目标虽消除了对齐盲方向，但未显式处理分布偏移下的置信度校准问题，OOD 对象可能仍获得保守（低置信度）的预测。

3. **实验局限**：
   - 零样本评估仅覆盖 RefCOCO/+/g 三个主流基准，未涉及更广泛的异构定位数据集（如 ReferItGame、Flickr30K Entities 等）的 OOD 测试
   - 跨语言能力虽在数据层面支持，但缺少定量基准验证
   - 缺少与更多最新方法（尤其 2025-2026 年的 SOTA）的对比

4. **数据工程依赖**：O365-Caption 构建依赖多个 MLLM（Qwen3-VL-2B/32B、HY-MT-1.5-7B），生成成本较高；虽然人工验证错误率低，但大规模自动生成难免存在系统性偏差。

5. **训练资源需求较大**：约 90.3 GB/GPU 的显存占用对硬件要求较高，可能限制社区复现和进一步扩展。

6. **过度强调泛化而可能牺牲专业性能**：在 benchmark-specific 微调协议下，虽然达到 SOTA 但优势幅度有限（如 RefCOCO+ 的 testA 略低于 PropVG），且部分提升主要来自预训练数据的丰富性而非方法本身的独特贡献。

7. **大规模数据与算力的不可比对性**：由于使用大规模 O365-Caption 预训练数据，与仅使用有限预训练数据的方法对比时，性能增益的来源（是数据贡献还是方法贡献）在部分实验中难以严格解耦。

---

## 总结

总体而言，这是一篇质量较高的视觉定位工作。论文从"表示退化"这一核心问题出发，通过理论分析（梯度子空间维度阶梯）、架构创新（mACH + JEPA）和数据工程（O365-Caption）三位一体的协同设计，实现了用 75M 参数的紧凑模型在统一开放词汇定位中达到与 7B/13B MLLM 相当的性能，具有明确的实用价值。理论框架虽然存在覆盖局限，但"表示多样性"作为一个可量化的设计原则，为后续视觉-语言模型扩展研究提供了有价值的视角和依据。
