## 摘要
近期基于LLM的推荐系统通过将协同嵌入投影到LLM的嵌入空间来整合文本与协同信号。然而，这种投影可能引入模态偏差，扭曲底层协同结构并限制投影嵌入的有用性。为解决此问题，我们提出一种新颖的结构保持投影方法，通过专门的结构保持损失来维持协同嵌入的关系几何。综合实验表明，我们的方法持续提升推荐性能，为基于LLM的推荐提供了更可靠的路径。

## Abstract
Recent LLM-based recommenders integrate textual and collaborative signals by projecting collaborative embeddings into the embedding space of the LLM. However, this projection can introduce modality bias that distorts the underlying collaborative structure and limits the usefulness of projected embeddings. To address this issue, we propose a novel structure-preserving projection approach that maintains the relational geometry of collaborative embeddings through dedicated structure-preserving losses. Comprehensive experiments demonstrate that our approach consistently improves recommendation performance, providing a more reliable path for LLM-based recommendation.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于 LLM 的序列推荐系统（如 CoLLM、LLaRA、A-LLMRec）通过一个投影器（Projector）将预训练序列推荐模型（如 SASRec）学到的协同嵌入（Collaborative Embedding）映射到 LLM 的嵌入空间中，使 LLM 在生成推荐结果时能同时利用文本信息与协同信号。
- **核心问题**：论文指出这类投影存在**模态偏差（Modality Bias）**——LLM 在训练和推理时过度依赖文本信号（如 item 标题），而**并未有效利用投影后的协同嵌入**。原因在于：文本信息（标题）的分布与 LLM 预训练语料天然对齐，而用户行为序列反映的跨域、上下文相关的转换模式与 LLM 表示空间并不自然对齐。投影过程缺乏显式约束，导致协同嵌入的**关系几何（Relational Geometry）被扭曲**，投影后的嵌入更像"通用软提示"而非真正的协同信号。
- **实证证据**：论文通过一个**嵌入洗牌（Embedding Shuffle）诊断实验**（图 1）发现：将 MovieLens 数据集中交互历史里每个 item 的协同嵌入随机替换为其他 item 的嵌入，同时保持标题不变，Direct 和 LLaRA 的 HR@1 几乎不变（Δ ≈ 0.001 和 −0.0065），说明这些基线模型实际并未利用投影嵌入中的协同信息。
- **整体含义**：这一发现揭示了现有 LLM 推荐系统中文本模态对协同模态的"压制"问题，说明仅做简单投影不能保证协同信息被有效利用，需要显式的结构保持机制来缓解模态偏差，使 LLM 真正融合多模态信号。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
提出**结构保持投影（Structure-Preserving Projection）**方法：在投影协同嵌入到 LLM 嵌入空间的过程中，通过两个专用的结构保持损失约束投影器，使投影后的嵌入能够保留原始协同空间中的**关系几何**与**序感知判别结构**，从而确保 LLM 能真正利用协同信息。

### 2.2 模型框架
- **协同嵌入来源**：使用预训练的序列推荐模型（SASRec 或 GRU4Rec）产生每个 item 的协同嵌入 e\_i ∈ R^d。
- **投影器**：一个 MLP 将协同嵌入映射到 LLM 嵌入空间：z\_i = MLP(e\_i)。
- **输入构建**：对于用户交互序列 I = [i₁, i₂, ..., i_t]，将每个 item 的标题 token 嵌入 E^t\_i 与投影协同嵌入 z\_i 交替插入 LLM 提示中：X = {E\_instruction, E^t\_i₁, z\_i₁, ..., E^t\_it, z\_it}。
- **训练目标**：LLM 以 next-token prediction 方式训练，最小化 ground-truth 标题 token 的负对数似然。

### 2.3 两个结构保持目标

**（1）余弦相似度保持（Cosine Similarity Preservation）**
- 定义原始空间中 item i、j 的余弦相似度 S^orig\_ij = cos(e\_i, e\_j)，投影空间中 S^proj\_ij = cos(z\_i, z\_j)。
- 损失函数为两者在 batch 内所有 item 对上的均方误差：
  L\_sim = (1/|B|²) Σ\_{i,j∈B} (S^proj\_ij − S^orig\_ij)²。
- 目的：保持投影前后 item-item 两两相似度结构一致，避免投影器扭曲原始协同空间的全局关系几何。

**（2）对比保持（Contrastive Preservation）**
- 利用序列推荐器学到的偏好排序：序列表示 h\_s 与其真正下一项 e\_p 的相似度应高于随机负样本 e\_n。
- 将三者投影到 LLM 空间后，使用二分类交叉熵损失：
  L\_contrast = −log σ(⟨z\_s, z\_p⟩) − log(1 − σ(⟨z\_s, z\_n⟩))。
- 目的：保留序列感知的判别结构——即投影后序列表示依然与正样本 item 更接近、与负样本 item 更远。

### 2.4 优化与训练流程
- 总损失：L = L\_LLM + α·L\_sim（Cosine-LM）或 L = L\_LLM + α·L\_contrast（Contrastive-LM），其中 α 控制结构保持强度（实验中选择 α = 0.4 和 0.8）。
- **两阶段训练**：
  1. **预训练投影器**：仅用结构保持损失训练 MLP，固定序列推荐器和 LLM，为投影器提供结构感知的初始化。
  2. **联合微调**：联合优化投影器与可训练 LLM 参数（LoRA），保持序列推荐器冻结。结构保持损失继续约束投影，防止语言建模目标过度扭曲协同结构。
- **三阶段组合课程（Combined）**：为了结合两个损失的互补优势，采用课程式训练——Warm-up 阶段（0%–30%）只用余弦保持（α\_sim = 0.4）；Transition 阶段（30%–70%）用余弦插值逐步将 α\_sim 衰减到 0、α\_contrast 增加到 0.8；Refinement 阶段（70%–100%）保持 α\_contrast = 0.8，专注于序感知判别。

## 6. 主要结论与发现

1. **模态偏差确实存在**：基线方法（Direct、LLaRA）在嵌入洗牌后性能几乎不降，证明它们主要依赖文本信号而忽略了投影协同嵌入。
2. **结构保持投影有效**：Cosine-LM 和 Contrastive-LM 在 LastFM 和 MovieLens 上均一致优于 Direct 和 LLaRA。其中 **Contrastive-LM 在两个数据集上都取得最高 HR@1**（LastFM：0.5546，MovieLens：0.4993，SASRec 骨干下）。
3. **余弦保持 vs. 对比保持的权衡**：Cosine-LM 在结构保持指标（Tau、Rho、SIM@10）上远优于 Contrastive-LM，但推荐性能略逊；说明**"忠实保持原始空间"≠"保留对推荐最重要的信息"**，适度的结构重塑（对比判别）对任务更有利。
4. **组合损失具有协同增益**：先几何保持、后对比对齐的三阶段课程（Combined）在两个数据集上均优于单独使用任一损失，说明两者互补。
5. **联合微调骨干进一步增强效果**：解锁 SASRec 后，所有方法都有提升，但结构保持方法的增益更大（如 Contrastive-LM 在 LastFM 从 0.5511 提升到 0.5702），说明几何感知目标与骨干自适应的协同效应。

## 7. 优点

- **问题诊断清晰、有说服力**：嵌入洗牌实验以极简的方式定量揭示了模态偏差问题，这一诊断方法本身对后续研究具有方法论价值。
- **方法设计简洁有效**：两个结构保持损失都有明确的直觉和数学表达，不引入过多复杂模块（仅一个 MLP 投影器 + 辅助损失），易于复现和集成到现有框架。
- **系统性分析完善**：不仅报告最终性能，还从结构保持度（Tau/Rho/SIM@10）、模态依赖（洗牌测试）、损失协同（课程调度）、骨干可训练性（消融）等多维度展开分析，增强了结论的可信度。
- **与视觉-语言模型中的模态偏差研究形成呼应**：将多模态偏见的研究思路引入了 LLM 推荐领域，跨领域启发性较好。

## 8. 不足与局限

- **数据集规模与多样性不足**：仅 LastFM 和 MovieLens-100K 两个小规模数据集，无法验证方法在大规模、真实工业场景下的有效性。数据集中 item 数量仅数千，远小于实际推荐系统百万级 item 规模。
- **统计显著性有限**：MovieLens 上的提升仅达到 p < 0.1 的边缘显著水平，说明结论的稳健性存疑，可能需要更多随机种子或更大样本量来支撑。
- **评估协议偏简**：20-item 候选集远低于实际推荐场景的候选规模；LLM 生成的不确定性也导致 VR 低于 1，部分方法（如 Cosine-LM 在 LastFM 上 VR 为 0.9262）的有效生成率有所下降。
- **模型覆盖范围窄**：仅使用 LLaMA2-7B 一种 LLM 以及 SASRec/GRU4Rec 两种协同骨干，未在更强 LLM（如 LLaMA-3、Mistral）或其他协同模型（如 BERT4Rec、FDSA）上验证泛化性。
