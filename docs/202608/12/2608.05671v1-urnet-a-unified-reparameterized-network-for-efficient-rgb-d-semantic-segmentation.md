## 摘要
以往的RGB-D语义分割方法通常采用双编码器分别处理RGB和深度输入，随后使用专用模块进行跨模态特征融合。然而，此类设计往往无法充分捕获深度表征，从而限制了有效的跨模态交互，同时额外的编码器分支引入了冗余计算，阻碍了轻量化执行。为应对这些挑战，我们提出了URNet，一种统一的重参数化RGB-D网络，在单一编码器内同时进行多模态特征提取和跨模态融合。具体而言，我们采用重参数化策略来紧凑网络架构并促进快速推理。在每个重参数化块（RepBlock）中，引入线性门控注意力（LGA）模块，以在不同特征尺度上充分利用互补的RGB和深度线索。此外，考虑到现有RGB-D分割模型中解码器设计相对未被充分探索，我们开发了一个简洁而有效的通用解码器，称为金字塔合并解码器（PMD）。在多个RGB-D分割基准上的大量实验表明，URNet在保持高效率的同时实现了最先进的性能。代码将在https://github.com/Wild-Stephen/URNet上提供。

## Abstract
Previous RGB-D semantic segmentation methods commonly employ dual encoders to separately process RGB and depth inputs, followed by dedicated modules for cross-modal feature fusion. However, such designs often inadequately capture depth representations and consequently limit effective cross-modal interaction, while the additional encoder branch introduces redundant computation that hinders lightweight execution. To tackle these challenges, we propose URNet, a Unified Reparameterized RGB-D Network that performs simultaneous multi-modal feature extraction and cross-modal fusion within a single encoder. Specifically, we adopt a reparameterization strategy to compact the network architecture and facilitate fast inference. Within each Reparameterized Block (RepBlock), a Linear Gated Attention (LGA) module is introduced to fully exploit complementary RGB and depth cues across different feature scales. Furthermore, considering that decoder design has been relatively underexplored in existing RGB-D segmentation models, we develop a concise yet effective universal decoder, termed the Pyramid Merging Decoder (PMD). Extensive experiments on multiple RGB-D segmentation benchmarks demonstrate that URNet achieves state-of-the-art performance while maintaining high efficiency. Code will be available at https://github.com/Wild-Stephen/URNet.

- **研究背景**：RGB-D语义分割通过同时利用RGB图像（颜色、纹理）和深度图（几何结构、空间关系）进行像素级场景解析。深度信息在低光照、运动模糊、纹理模糊等不利条件下是RGB线索的重要补充。

  - **深度特征建模不足**：深度分支使用RGB预训练权重初始化，与深度模态存在分布偏移，导致深度表征质量低下；

  - **计算冗余**：额外增加一个完整编码器分支，带来大量冗余计算，阻碍轻量化与实时推理。
- **核心问题**：如何在**高效**的前提下，实现充分的**RGB-D跨模态特征提取与融合**？

## 2. 论文提出的方法论：核心思想、关键技术细节

URNet遵循编码器-解码器架构，训练分为两阶段：**阶段一**在RGB-D ImageNet-1k上进行预训练（同时优化分类头），**阶段二**在RGB-D语义分割benchmark上进行微调。

### 2.1 分层编码器（Hierarchical Encoder）

- 输入：RGB图像 \( I_{rgb} \in \mathbb{R}^{H\times W\times 3} \) 和深度图 \( I_d \in \mathbb{R}^{H\times W\times 1} \)。
- 两个并行Stem（各由4个 stride=2 的3×3卷积组成）分别处理RGB和深度，随后进入四阶段堆叠的RepBlock，输出分辨率依次为输入的1/4、1/8、1/16、1/32。
- 四种模型规模：URNet-T/S/B/L，参数量分别为9.2M/19.8M/44.1M/62.2M。

### 2.2 重参数化块（RepBlock）

- **Token Mixer多分支设计**：受RepViT启发，采用三个并行深度可分离卷积分支：3×3 DW卷积、1×1 DW卷积、1×7后接7×1的分解卷积，再加上残差连接。训练时利用重参数化技术将多分支合并，**推理时简化为单一卷积**，消除额外计算开销。相比RepViT，额外引入7×7感受野以增强空间信息聚合。
  
  公式形式（以RGB分支特征 \( f_i^{rgb} \) 为例）：
  \[
  x_i^{rgb} = Conv_{3\times3}^d(f_i^{rgb}) + Conv_{1\times1}^d(f_i^{rgb}) + Conv_{7\times1}^d(Conv_{1\times7}^d(f_i^{rgb})) + f_i^{rgb}
  \]
  其中 \( Conv^d \) 表示深度可分离卷积。

- **线性门控注意力（LGA）**：在RepBlock中间位置插入。其核心是**跨模态门控机制**：
  - 对RGB特征 \( x_i^{rgb} \) 和深度特征 \( x_i^d \) 分别做池化+3×3卷积+sigmoid，生成门控信号 \( g_i^{rgb} \) 和 \( g_i^d \)；
  - 用对方模态的门控信号对当前模态进行元素级调制：
    \[
    \hat{x}_i^{rgb} = x_i^{rgb} + g_i^d \odot x_i^{rgb}, \quad
    \hat{x}_i^{d} = x_i^d + g_i^{rgb} \odot x_i^d
    \]
  - 调制后的特征分别经SE（Squeeze-and-Excitation）模块 recalibrate，再沿通道维度拼接形成融合输出：
    \[
    m_i = Concat(SE(\hat{x}_i^{rgb}), SE(\hat{x}_i^d))
    \]
  - LGA仅涉及线性元素级运算，计算开销可忽略，优于二次复杂度的注意力融合。
- **Channel Mixer**：采用轻量两层的1×1卷积结构。

### 2.3 金字塔合并解码器（PMD）

- 输入为编码器四阶段输出的多尺度特征 \( m_1, m_2, m_3, m_4 \)（\( m_1 \) 分辨率最高）。
- **金字塔自顶向下合并**：对每个低层特征做3×3卷积后，与上一层经下采样后的特征相加，再经上采样逐级传播（公式中的 \( t_k = m_k^c + Ds(t_{k-1}) \) 链条）。
- **逐级池化聚合**：每级融合结果经池化后逐级相加，形成最终聚合表示 \( m_f = s_1 + s_2 + s_3 + s_4 \)。
- **金字塔池化（P-Pooling）**：在 \( m_f \) 上再施加金字塔池化以捕获多感受野上下文，并通过残差连接融合：\( y = m_f + PPool(m_f) \)。
- 整个PMD只包含上/下采样、池化和逐元素加法，参数开销极小。

## 6. 论文的主要结论与发现

1. **统一RGB-D预训练优于传统RGB预训练**：在相同微调设置下，RGB-D预训练比RGB-only预训练在NYUDepth V2上高1.2% mIoU（56.1% vs 54.9%），验证了深度模态参与预训练能带来更好的跨模态对齐。
2. **重参数化Token Mixer高效且有效**：与自注意力相比，精度接近（53.17% vs 53.45% mIoU），但参数量降低约50%（9.26M vs 18.40M）、FLOPs降低约27%（15.35G vs 20.89G）、推理速度提升超过5×（100.35 vs 18.23 FPS）。
3. **LGA融合优于简单加和与拼接**：LGA达到53.17% mIoU，显著高于Add（51.83%）和Concat（52.32%），且计算量与Add相当、低于Concat，证明了门控式线性交互的有效性。
4. **PMD解码器优于MLP和HAM**：PMD在同等FLOPs下取得最高mIoU（53.17%），优于MLP（51.74%）和HAM（52.78%），且计算开销远低于HAM。
5. **URNet编码器泛化能力强**：DFormerV2-L配备HAM可得58.38% mIoU，而URNet-L在参数量少34M的情况下达到58.22%；在PMD解码器下URNet-L甚至超过DFormerV2-L（58.75% vs 58.66%），验证了URNet作为通用编码器的优势。
6. **整体最优精度-效率平衡**：URNet-L在NYUDepth V2上达到58.8% mIoU，SUN-RGBD上53.4%，在相近精度下FLOPs仅为DFormerV2-L的约60%（73.0G vs 124.1G）。

## 7. 优点

- **架构创新性**：
  - 提出**统一RGB-D编码器**范式，从源头解决预训练-微调输入分布错配问题；
  - 将**重参数化**技术引入RGB-D融合领域，在不损失精度的前提下大幅压缩推理开销；

  - **PMD**以极简操作（池化、加法、上下采样）显著提升多尺度聚合效果，填补了解码器设计的研究空白。

  - 消融实验覆盖了预训练、编码器组件、融合模块、解码器四大设计维度，逻辑严谨。
- **实用性**：模型FLOPs和参数量在同类方法中具明显优势，适合资源受限的机器人感知等场景。
