## 摘要
现有的多模态大语言模型（MLLMs）主要依赖图像-文本对进行模态对齐预训练，将全局图像表示映射到长文本描述。然而，这种图像级对齐存在指称歧义：模型难以从全局表示中推断多个视觉对象与文本实体之间的对应关系，导致数据效率低下和语义基础欠佳。为解决这一问题，我们提出多模态语码转换（MMCS），一种新颖的预训练范式，提供显式的对象级监督。受语言学中语码转换现象的启发，MMCS通过将文本实体替换为相应的视觉对象来交织视觉与语言，从而强化局部视觉-语言接地。我们进一步开发了可扩展的数据合成流水线，生成了包含77.3万样本且具有精确对象-实体对应关系的预训练数据集。实验表明，MMCS具有很高的数据效率：仅用5万样本即可匹配或超越在60万图像-文本对上训练的模型。此外，MMCS在不同模型规模下持续提升了视觉接地和感知能力。

## Abstract
Existing Multimodal Large Language Models (MLLMs) predominantly rely on image-text pairs for modality alignment pretraining, mapping global image representations to long textual descriptions. However, this image-level alignment suffers from referential ambiguity: models struggle to infer the correspondences between multiple visual objects and textual entities from the global representation, leading to data inefficiency and suboptimal semantic grounding. To address this, we propose MultiModal Code-Switching (MMCS), a novel pretraining paradigm that provides explicit object-level supervision. Inspired by the linguistic phenomenon of code-switching, MMCS interleaves vision and language by replacing textual entities with their corresponding visual objects, enforcing local vision-language grounding. We further develop a scalable data synthesis pipeline to generate a pretraining dataset of 773K samples with accurate object-entity correspondences. Experiments show that MMCS is highly data-efficient: with only 50K samples, it matches or surpasses models trained on 600K image-text pairs. Furthermore, MMCS consistently improves visual grounding and perception capabilities across varying model scales.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：当前主流多模态大语言模型（MLLMs）普遍采用 ViT-MLP-LLM 架构，通过两阶段训练（模态对齐预训练 + 指令微调）实现视觉-语言理解。其中，模态对齐预训练被视为决定模型多模态能力上限的基础环节。现有主流做法是使用稠密图像描述（dense captions）进行图像级对齐：模型将整张图像编码为全局表示，再基于该全局表示预测长文本序列。
- **核心问题——指称歧义（Referential Ambiguity）**：自然图像通常包含多个对象和复杂背景，稠密描述数据集中每个样本平均包含 6.8–11.0 个不同实体。然而，模型将整个场景压缩为全局表示，必须隐式推断“多个视觉区域”与“多个文本短语”之间的多对多映射关系。这种隐式对齐迫使模型依赖统计共现而非真正语义接地，导致：
  - **数据效率低下**：需要海量数据才能学习到稳健的对象-实体关联；
  - **语义接地次优**：模型难以从全局表征中准确分离出单个视觉概念。
- **整体含义**：本文试图从根本上改变模态对齐的方式，将对齐粒度从图像级下沉到对象级，为 MLLMs 提供一种更高效、更精确的预训练范式。

### 2. 论文提出的方法论

#### 2.1 核心思想：受语言学启发的“多模态语码转换”

- **语码转换（Code-Switching）** 源于语言学，指在同一语句中交织使用两种或多种语言。例如：*“The Klavier is a versatile keyboard instrument.”* 中德语词 *Klavier*（钢琴）嵌入英语语境。
- **核心类比**：将视觉对象视为一种携带语义信息的“语码”，文本为另一种“语码”。MMCS 将文本实体（通常是名词短语）替换为其对应的视觉对象嵌入，强制模型在生成后续文本和重建被替换实体时，直接以局部视觉特征为条件。这就在表征层面建立了显式的对象-实体对应关系，无需模型从全局表示中隐式推断。

#### 2.2 技术细节：序列构造与损失函数

- **交错序列构造**：设原始文本标记序列为 X，文本实体段为 e = [xi, …, xi+m]（起始索引为 i），对应视觉对象表示为 vobject（即与对象边界框空间相交的图像标记集合）。替换实体为视觉对象后，得到交错序列：

  X_MMCS = Concat(X_<i, v_object, X_>i+m)
- **语言建模损失**：仅对文本标记计算交叉熵损失，视觉标记仅作为条件上下文：

  L_LM = −Σ log pθ(x^MMCS_t | X^MMCS_<t)（仅对文本标记求和）
- **实体重建损失**：显式监督对象-实体对应关系，要求在给定视觉对象和上文的情况下，重建被替换的原始实体标记：

  L_entity = −log pθ(e | X^MMCS_<i, v_object)
- **总目标**：L_MMCS = L_LM + L_entity。两项损失不重叠且互补——L_entity 充当“语义锚点”，强制投影器编码具有判别性的对象特征；L_LM 负责上下文整合，训练模型预测视觉对象周围的文本语境。

#### 2.3 数据合成流水线

给定一张输入图像，流水线依次执行四个步骤：

1. **稠密图文描述生成**：使用 Qwen3-VL-32B-Instruct 生成尽可能详尽的对象及属性描述；
2. **文本实体提取**：使用 Qwen2.5-72B-Instruct 从描述中提取名词短语并附带属性描述（用于区分同类不同实例）；
3. **视觉对象接地**：使用 Grounding DINO 将文本实体定位到图像区域，输出边界框、文本标签和置信度；
4. **多级过滤**：置信度阈值（box 0.4 / text 0.3）→ 面积约束（不得小于单个 patch 或超过图像 50%）→ SAM-2.1 生成分割掩码，掩码面积占边界框面积不足 20% 的严重遮挡对象予以剔除。

最终生成 **773K 个预训练样本**（来源图像包括 COCO、Flickr30k、GQA、Objects365、OpenImages、SA-1B），每个样本包含源图像、稠密描述以及配对好的对象边界框与文本实体标签。

1. **数据效率极高**：仅 50K MMCS 预训练样本即可超越 600K 图像-文本对预训练的模型；
2. **持续、稳健的性能提升**：在多种模型规模（3B/8B）、多种视觉编码器（SigLIP2/QwenViT）、多种数据规模（50K/600K/773K/1M）和不同分辨率设置下，MMCS 均一致优于图像级预训练基线；
3. **收益幅度呈任务分化**：平均提升视觉定位 7.9%、感知类任务 2.1%、通用 VQA 增益较小但统计显著（p = 0.028）；

5. **对象级 > patch 级 > 图像级**：对比 SEA、Patch Aligned、Text BBox 均取得优势，说明语义完整的对象作为对齐单元比 patch 更干净，比符号化坐标更直接；
6. **表征对齐改善**：MMCS 在 CKA、CKNNA、Mutual k-NN 三种度量上均优于图像级预训练，注意力图更集中、与文本实体对应更精确；
7. **隐式收益外溢**：对象级接地隐式传播到动作和关系的学习（动词、介词 NLL 显著下降），并在无专门 OCR 数据的情况下带来 OCR 能力提升。

### 7. 优点

- **问题切入精准**：直面稠密描述范式下“多对象-多实体”的指称歧义，诊断清晰有据（给出各数据集实体数量统计）；
- **方法简洁优雅**：基于语码转换的类比自然且富有解释力，无需引入任何新模块或坐标监督，仅改变预训练数据格式和损失函数即可实现对象级对齐，并且模型推理时无额外开销；

- **严谨的变量控制**：与基线共享同一批图像-描述对，归因清晰；
- **机制分析深入**：不仅报告下游分数，还从表征对齐度量、注意力图、词性 NLL 等角度解释收益来源，深化了对“对齐质量决定模型能力”的理解；

### 8. 不足与局限

- **对象类别覆盖有限**：当前焦点是自然图像中的视觉对象，未覆盖图表理解、场景文本识别等更广场景（作者在 Limitations 中明确承认）；
- **数据偏见与隐私风险**：合成数据继承源数据集（COCO/GQA/Flickr30k/Objects365/Open Images/SA-1B）和自动标注模型的偏差，对象类别覆盖率不均；源图像可能包含人脸、车牌、位置线索，发布的标注数据可能继承隐私风险；
- **自动流水线的固有噪声**：Grounding DINO 无法在所有情况下准确定位实体，过滤策略虽能部分缓解，但会丢弃大量样本，可能引入选择性偏差；
- **未涉及关系与动作的显式建模**：MMCS 只替换名词短语，动词/介词仅通过上下文隐式学习，缺少对关系、交互的显式对象级监督；
- **实验规模未达 SOTA 级别**：最大模型仅为 8B 参数、预训练数据为 1M 级，与当前前沿 MLLMs（数十亿至百亿级参数、数亿级预训练数据）相比规模差距仍大；
- **评估集中于英语与常见对象**：未覆盖多语言、长尾对象、文化特定对象等场景；
- **技术滥用风险**：更强的对象定位能力可能被用于监控或追踪系统，需要使用前评估与安全防护。
