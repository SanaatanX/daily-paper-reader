## 摘要
多模态大语言模型（MLLM）日益被部署为多步骤智能体，其中显式推理支持任务分解和工具协调，但也积累了自生成的文本。在长轨迹中，这些文本可能主导上下文并抑制视觉证据，形成文本债务。我们观察到，一旦任务相关的视觉证据得到锚定，推理便变得冗余；而当锚定仍不确定时，过时的假设可能误导后续推断。因此，剪枝必须在不丢弃视觉证据的前提下移除冗余文本。我们提出SPARE，一种基于Kullback-Leibler（KL）散度引导的框架，用于剪枝多模态工具使用智能体中累积的推理。SPARE使用紧凑的任务状态摘要作为特权诊断上下文。对于每个候选片段，它在原始上下文和摘要条件下的上下文中重放同一模型。来自在线策略自蒸馏（OPSD）的反向KL散度随后测试摘要是否充分覆盖该片段而不干扰未来推理。我们进一步通过监督微调（SFT）优化摘要器，实现更紧凑的摘要、更广的覆盖范围和更强的剪枝。在多步视觉工具使用基准测试中，SPARE在剪枝方法中实现了最高的平均准确率，同时移除了37.89%-64.58%的推理令牌。这种有利的准确率-上下文权衡表明，减少文本主导性恢复了对视觉证据的依赖，并缓解了对自生成语言的过度条件化。

## Abstract
Multimodal Large Language Models (MLLMs) are increasingly deployed as multi-step agents, where explicit reasoning supports task decomposition and tool coordination but also accumulates self-generated text. Over long trajectories, this text can dominate the context and suppress visual evidence, creating textual debt. We observe that reasoning becomes redundant once task-relevant visual evidence is grounded, while stale hypotheses can misguide later inference when grounding remains uncertain. Pruning must therefore remove redundant text without discarding visual evidence. We propose SPARE, a Kullback-Leibler (KL)-guided framework for pruning accumulated reasoning in multimodal tool-use agents. SPARE uses a compact task-state summary as privileged diagnostic context. For each candidate segment, it replays the same model under the original and summary-conditioned contexts. Reverse-KL divergence from on-policy self-distillation (OPSD) then tests whether the summary sufficiently covers the segment without disrupting future reasoning. We further fine-tune the summarizer with supervised fine-tuning (SFT), enabling more compact summaries, broader coverage, and more aggressive pruning. Across multi-step visual tool-use benchmarks, SPARE achieves the highest average accuracy among pruning methods while removing 37.89-64.58\% of reasoning tokens. This favorable accuracy-context trade-off shows that reducing textual dominance restores reliance on visual evidence and mitigates over-conditioning on self-generated language.

- **关键洞察**：当早期推理正确捕获了任务相关的视觉证据时，累积文本可能仍是对图像的有效抽象；但当早期推理未能关注到相关视觉区域时，模型可能在未充分锚定的文本状态上进行过度阐述。此时，冗余文本不仅浪费上下文预算，还会造成"过度条件化"（over-conditioning），使模型对自生成语言产生偏置。
- **问题定位**：论文将上下文压缩重新定义为一种**轻量级、保留证据的选择性遗忘**问题——需要在不丢弃视觉证据的前提下，剪除已被任务状态覆盖的冗余推理文本。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 总体框架：SPARE（Selective Pruning of Accumulated Reasoning with Visual Evidence Preservation）

SPARE 是一个 KL 引导的推理剪枝框架，核心思想是：**使用紧凑的任务状态摘要（task-state summary）作为"特权诊断上下文"，而非直接替代历史轨迹**。系统通过重放同一模型在原始上下文和摘要条件化上下文下的表现，利用反向 KL 散度衡量每个历史推理片段的"残余敏感性"（residual sensitivity），从而判断该片段是否已被摘要充分覆盖。

### 2.2 三个核心阶段

#### 阶段一：自适应摘要（Adaptive Summary Trigger）

- 模型自己调用 `summarize_the_task` 工具，生成紧凑的任务状态摘要 σ，包含：原始问题、已完成的工具调用、累积的视觉证据、剩余的不确定性。
- 摘要**仅作为辅助诊断上下文**，不写入持久轨迹，也不直接替换历史片段。
- 采用**自适应触发策略**：短轨迹不产生剪枝开销，长轨迹仅在模型显式产生紧凑状态后才考虑剪枝。

#### 阶段二：摘要条件化覆盖估计（Summary-Conditioned Coverage Estimation）

通过重放同一模型在两种上下文下对候选推理片段 x 的续写分布，计算摘要的覆盖程度。核心公式如下：

- **两种上下文**：
  - 学生上下文：ρ_stu = ρ₀（不包含摘要）
  - 教师上下文：ρ_tea = ρ₀ ∥ σ（包含摘要作为特权信息）
- **两个续写分布**：
  - p_stu_k(u) = P_πθ(u | ρ_stu, x_<k)
  - p_tea_k(u) = P_πθ(u | ρ_tea, x_<k)
- **Top-K 反向 KL 覆盖得分**（K=20）：

  d_k = Σ_{u∈Ω_stu_k} p_stu_k(u) [log p_stu_k(u) − log p_tea_k(u)]

  若 u 不在教师 Top-K 支持中，则 log p_tea_k(u) 设为 −20。
- **归一化**（按剪枝事件内）：

  d̃_k = (d_k − d_min) / (d_max − d_min + ε)，ε = 10⁻¹²

- **解读**：高 KL 值表示该 token 仍对摘要敏感（即摘要未覆盖其信息），应保留；低 KL 值表示摘要已充分解释该 token 的上下文。

#### 阶段三：片段级剪枝与视觉证据保留（Segment-Level Pruning & Evidence Preservation）

- **计数规则决策**：每个推理片段 h_i 若包含至少 κ 个高敏感性 token（d̃_k > τ），则保留并进行视觉证据重构；否则整体删除。

  Preserve(h_i) = { (1/n) | {k ∈ P_i : d̃_k > τ} | ≥ κ }

- **为何用计数规则而非均值**：任务关键证据常是稀疏的（如 OCR 字符串、坐标、边界框、候选标签），均值会稀释这些局部信号，计数规则能识别含稀疏关键证据的片段。
- **默认参数**：τ = 0.2，κ = 2（在所有模型和基准上固定）。
- **证据保留重构**：对高 KL 片段，将冗长推理替换为简洁、可验证的结构化视觉证据（如裁剪位置、识别文本、数值、候选间相对关系）；对低 KL 片段，直接删除推理文本。原始工具调用、工具输出、视觉观测和图像 tokens 均保持不变。
- **KL 引导的裁剪原则**：SPARE 压缩的是"语言脚手架"（linguistic scaffolding），而非任务状态本身。

### 2.4 方法基石：On-policy Self-Distillation（OPSD）

- 论文借鉴 OPSD 的**诊断原则**而非优化目标：同一模型既作为学生也作为教师，通过分布偏移来衡量历史推理片段是否含有摘要未覆盖的信息。
- 与标准知识蒸馏不同，这里不需要外部教师模型，也不做参数优化，仅在推理时进行重放比较。

### 2.5 SFT 强化摘要器

- 收集 376 条 Qwen3-VL-8B 在 VTC-Bench 上的在线策略轨迹，用更强的 Qwen3-235B 生成紧凑任务状态摘要，再对 8B 模型进行监督微调，蒸馏 235B 的摘要能力。
- 更强的摘要器覆盖更多推理信息，使更多片段落入可安全剪枝区域，实现更激进的剪枝。

## 6. 论文的主要结论与发现

### 6.1 核心结果

1. **SPARE 在剪枝方法中实现最高平均准确率**：
   - Qwen3-VL-30B：平均准确率从 44.30% 提升至 49.19%，同时剪除 63.70% 的推理 tokens。
   - Qwen3-VL-8B：保持可比性能（53.47% vs. 54.27%），剪除 37.89% 推理 tokens。
   - Nemotron：在工具能力较弱、完整轨迹效果差的情况下，SPARE 仍优于 Full Trace，剪除 64.58% 推理 tokens。

2. **SPARE 位于帕累托前沿之上**（图 2）：在 BLINK-Jigsaw、GTA、MNMS 聚合结果中，SPARE 达到 50.34% 准确率 + 57.81% 剪枝率，优于全部基线方法的权衡曲线。

3. **KL 选择与证据重构互补**：单独使用 KL 选择（KL-guided）准确但过于保守（仅剪 16.40%）；单独使用无差别证据重构（Visual Evidence-Only）虽有压缩但准确率下降（42.86%）；两者结合实现最佳权衡。

4. **剪枝降低文本干扰**（表 5）：在早期推理与后期证据冲突的受控子集上，SPARE 使准确率提升 27.27 个百分点，陈旧答案复制率同步下降 27.27 个百分点；随机删除的提升更小，证明改善不能仅由上下文缩短解释。

5. **剪枝恢复视觉注意力**（图 3）：剪枝后几乎所有解码器层的文本到图像注意力都增加，支持"减少文本主导性恢复视觉证据依赖"的假设。

6. **更强的摘要器支持更激进剪枝**（表 2）：SFT 摘要器在 VTB 上提高剪枝量 23.8%，在 MNMS 上提高 13.5%，并且两种基准上准确率均提升。

- 首次将"文本债务"概念化为多步 MLLM 智能体的关键失效模式。
- 表明**推断时选择性遗忘**（selective forgetting）是长上下文多模态推理的有效机制。

## 7. 优点：方法与实验设计的亮点

1. **问题定义新颖且具有实际意义**："文本债务"抓住了多步 MLLM 智能体中一个被忽视的真实问题——自生成文本的累积效应。作者不是简单地主张"剪得越多越好"，而是指出文本的功能性随时间变化。

2. **方法设计精巧**：
   - **摘要作为诊断工具而非替代品**：SPARE 不直接覆盖历史，而是将摘要作为"特权上下文"来测试哪些信息已被覆盖，这一思路避免了粗暴压缩带来的信息丢失。
   - **无外部教师模型**：利用 OPSD 的自蒸馏原则，同一模型既是教师又是学生，避免了部署时的额外模型依赖。
   - **计数规则优于均值**：针对任务关键证据稀疏的特性，设计了更敏感的高 KL token 计数规则。
   - **自适应触发**：避免对短轨迹产生不必要的计算开销。

3. **实验设计系统且公平**：
   - 通过 Random-33/50 控制上下文缩短的混淆因素；通过 KL-guided 对照组分离"选择"与"重构"的独立作用。
   - 受控文本干扰诊断独立于基准评估，提供机制层面的因果证据。
   - 剪枝率计算透明，排除了工具调用、观测和图像 tokens 的影响。

4. **消融实验层次分明**：从组件完整性（2.2 节）、触发策略（2.3 节）、参数敏感性（2.4 节）三个维度系统验证设计选择。

5. **结果一致性高**：三个不同骨干、五个基准、多种分析视角（端到端准确率、帕累托曲线、注意力可视化、受控诊断）均支持核心假设。

## 8. 不足与局限

### 8.1 应用范围限制

- **仅适用于多步工具使用智能体**：方法要求存在显式推理、工具调用和可分层的历史结构。对单轮对话或无结构化轨迹的智能体不直接适用（作者在附录 D 中承认）。
- **依赖推理片段与行动块的可分离性**：若模型生成的文本无法清晰划分为"推理"和"行动"，SPARE 的映射机制会失效。

### 8.2 计算开销

- 每次剪枝事件需要生成摘要 + 两次前向重放（学生与教师上下文），引入了额外的推理延迟。虽然自适应触发和上下文复用在长轨迹中摊销了成本，但高频率短轨迹场景下的开销收益比未充分评估。
- 论文未提供端到端延迟的定量对比（作者承认这是未来方向）。

### 8.3 实验覆盖的不足

- **训练时长与硬件细节缺失**：未报告具体训练时长、显存用量、能源消耗等。
- **骨干模型规模上限为 30B**：未验证在更大规模模型（如 70B+）上的表现。
- **SFT 实验范围较窄**：仅在 VTB 和 MNMS 上验证了 SFT 摘要器的效果。
- **注意力可视化仅基于 10 条轨迹**：样本量较小，统计显著性不明确。

### 8.4 潜在偏差风险

- **自适应触发与剪枝效果的耦合**：SPARE 的触发本身依赖模型对任务状态的判断；模型在需要时生成摘要，可能在摘要生成时就已重新关注视觉证据，使得准确率提升部分来自"摘要过程本身"而非"剪枝"。
- **受控诊断子集较小**：文本干扰诊断的样本量未公布（从百分比推断可能仅 11-22 例），统计效力有限。
- **KL 阈值固定**：τ=0.2 和 κ=2 在所有模型和基准上固定，未报告不同模型的最优参数差异；κ=3 时准确率下降，说明参数边界附近存在不稳定性。
- **长轨迹幻觉风险**：对极长轨迹（超过 10 个工具调用），摘要覆盖的累积误差、剪枝的连锁效应未在极端场景下测试。

### 8.5 方法内部局限

- **Top-K 截断的近似性**：K=20 的截断 KL 可能低估尾部 token 的分布差异；对长尾但关键的信息（如罕见 OCR 字符串）可能有遗漏风险。
- **时序耦合未建模**：对每个片段独立评估覆盖度，未显式建模多个片段之间的交互——两个各自低 KL 的片段组合在一起时可能产生摘要未覆盖的新信息。
- **未讨论剪枝对可解释性的影响**：删除推理后，用户难以追溯模型的决策过程。

## 9. 总结评价

SPARE 以"文本债务"这一概念化问题为核心

## 9. 总结评价（续）

SPARE 以"文本债务"这一概念化问题为核心

，提出了一个兼具理论洞察与实践价值的多步 MLLM 智能体上下文管理方案。论文的核心贡献不在于提出新的模型架构或训练范式，而在于重新定义了问题——将长轨迹中的显式推理累积视为一种需要选择性遗忘的"债务"，而非需要尽力保留的"资产"。这一视角转换具有方法论意义上的启发性：它引导研究者关注"模型何时应停止自我阐述、回归证据本身"这一此前被忽视的维度，而不是简单地追求更长的上下文窗口。

从研究质量来看，SPARE 在以下方面表现突出：

- **问题定义具有真实性和普遍性**：所有自回归多模态智能体在长程工具使用中都会面临自生成文本的累积问题，该现象不依赖特定模型或任务，具有广泛适用性。
- **方法设计轻量且可部署**：无需外部教师模型、无需训练时参数更新、无需辅助重排序器，仅依赖模型自身的条件生成分布差异即可完成诊断与剪枝，兼容任意支持工具调用的 VLM。
- **实验验证系统而严谨**：从端到端准确率到帕累托权衡曲线，从受控机制诊断到注意力可视化，形成了"行为—机制—归因"的多层次证据链；三个骨干模型、五个异质基准、多组消融互相印证，结论一致性高。

从学术价值来看，该工作为"推断时上下文压缩"这一方向提供了新的设计范式：用特权摘要作为诊断探针、用反向 KL 散度测量残余敏感性、用计数规则保护稀疏证据、用证据重构替代无差别删除。这种"诊断—选择—重构"的三段式框架具有较强的可迁移性，未来可扩展到代码生成、多轮对话、复杂规划等其他长上下文任务；其"以覆盖度而非相似度衡量信息冗余"的思想，也可能对检索增强生成（RAG）和记忆管理领域产生启发。

从局限来看，论文的即时实用价值受制于两点：其一，计算开销（每次剪枝事件需生成摘要 + 两次前向重放）虽在长轨迹中被摊销，但在短轨迹或低延迟场景下代价仍不可忽视；其二，方法仅适用于具备显式推理文本与可分离行动块的多步智能体架构，对单轮对话或自由形式交互的适用性有限。此外，SFT 强化摘要器的验证范围偏窄、注意力可视化的样本量偏小、KL 阈值（τ=0.2，κ=2）在所有模型和基准上固定而未探索最优区间，以及自适应触发与剪枝效应的耦合难以完全解耦等，都留有后续改进空间。这些不足并不削弱核心结论的有效性——文本债务是真实存在的失效模式，选择性剪枝确实能恢复视觉依赖并提升任务表现。

总体而言，这是一篇问题定义清晰、方法设计精巧、实验验证扎实的高质量工作。它提醒研究者：在追求更长上下文窗口的同时，也需要关注模型"自我对话"对视觉证据的压制效应；有时，学会遗忘比学会记忆更重要——但遗忘必须是有选择的、保留证据的遗忘。SPARE 为多模态智能体的长轨迹推理提供了一条务实且有效的路径，值得该领域的后续工作在此基础上继续深化。若未来能在延迟优化、阈值自适应、更大规模模型验证和更细粒度时序建模上取得进展，该方法有望成为多模态智能体系统部署中的标准组件。
